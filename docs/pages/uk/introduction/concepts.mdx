# Поняття й термінологія

Cosmo-Local Credit поєднує застосунок, відкритий протокол, незалежно керовані Пули та реальні зобов’язання, які представляють ваучери. Ці рівні працюють разом, але не є одним і тим самим.

На цій сторінці визначено терміни, які використовуються в документації. Точні назви дій із застосунку наведено в лапках, якщо інтерфейс використовує коротшу або потенційно неоднозначну назву.

## Рівні продукту й протоколу

| Термін | Значення |
| --- | --- |
| **Cosmo-Local Credit (CLC)** | Сімейство продуктів: CLC App, його документація та ширша робота з об’єднання зобов’язань. |
| **CLC App** | Прогресивний вебзастосунок на [cosmolocal.credit](https://cosmolocal.credit). GEF керує цим інтерфейсом і допоміжними сервісами. |
| **Протокол об’єднання зобов’язань (CPP)** | Багаторазова модель кураторства, оцінювання, обмеження, обміну та відповідального управління. |
| **Protocol v1.1.0** | Перевірений публічний випуск смартконтрактів, описаний у [довідці про Протокол](/uk/protocol/overview). |
| **Пул зобов’язань** | Керована домовленість, що відбирає активи, публікує правила й дає змогу здійснювати обмін. **Пул** — звичайна коротка назва. |
| **`SwapPool`** | Поточний контракт Протоколу, який зберігає токени й виконує прямі обміни. Це одна технічна складова Пулу зобов’язань. |
| **Пропонований токен управління CLC** | Майбутня модель управління з Білої книги. Це не поточний актив застосунку або Protocol v1.1.0. |
| **Пропонований мережевий Пул CLC** | Майбутня модель клірингу й координації на рівні мережі. Це не те саме, що поточний `SwapPool`. |

## Токени, ваучери та Пропозиції

**Токен** — це баланс у блокчейні або цифровий актив. Механіка токена може фіксувати пропозицію, перекази, строк дії та спалювання, але сама по собі не обіцяє товарів, послуг, конвертації в готівку або погашення.

**Ваучер** — це токен або запис, який емітент представляє як зобов’язання, що підлягає погашенню за опублікованими умовами. Ці умови мають визначати, що обіцяно, хто відповідає, де й коли ваучер можна пред’явити, які суттєві обмеження діють, а також порядок виконання й подання скарг.

**Пропозиція** — це запис у каталозі про товари чи послуги, пов’язані з ваучером. Публікація Пропозиції не карбує токени й не доводить доступність або виконання.

Це чотири окремі рівні:

1. токен-контракт і баланси;
2. назва ваучера та опубліковані умови;
3. одна або кілька Пропозицій; і
4. фактичне виконання емітентом у реальному світі.

## Відповідальні ролі й технічний контроль

| Роль або повноваження | Відповідальність або можливості |
| --- | --- |
| **Емітент** | Публікує та виконує зобов’язання за ваучером. Ця відповідальність не переходить автоматично лише через зміну власника контракту. |
| **Власник** | Контролює баланс ваучера. Контроль не доводить виконання, грошову вартість або наявність гарантії. |
| **Постачальник послуг** | Публічна роль. Постачальник послуг стає емітентом, коли публікує зобов’язання за ваучером. |
| **Куратор Пулу** | Відповідальна особа, кооператив, державна установа, федерація, мультипідпис, сервіс або інша структура, що публікує правила Пулу й керує ними. |
| **Власник Пулу** | Адреса з поточними повноваженнями власника `SwapPool`, зокрема для налаштування, збору комісій і виведення доступної ліквідності. |
| **Адміністратор проксі** | Сторона, що може оновити реалізацію контракту, розгорнутого через проксі. Вона може відрізнятися від власника Пулу. |
| **Контролер залежності** | Власник або уповноважений записувач, що контролює реєстр, лімітер, модуль котирування, оракул, політику комісій або контролер протокольної комісії. |
| **Модератор каталогу** | Оператор застосунку, який може виправляти, приховувати або відновлювати записи каталогу без зміни балансів у блокчейні. |
| **Отримувач комісії** | Налаштована адреса, що отримує комісію Пулу або протоколу. Це не обов’язково Куратор Пулу чи власник. |
| **Прихильник або постачальник ліквідності** | Учасник, який вносить активи за окремо розкритими умовами. Поточний `SwapPool` не створює часток Пулу або автоматичних прав на повернення, виведення, винагороду чи управління. |

«Член спільноти» — неформальна суспільна назва. Сама по собі вона не створює прав на допуск, власність, управління, повернення коштів або інших юридичних прав.

## Дії та життєвий цикл

| Термін у застосунку або документації | Значення |
| --- | --- |
| **Створити або опублікувати ваучер** | Розгорнути або налаштувати токен і опублікувати його запис у каталозі та умови. |
| **Випустити або карбувати** | Створити баланс токена за повноваженнями налаштованого власника або записувача. |
| **Опублікувати Пропозицію** | Додати під ваучером запис про товари або послуги. |
| **Надіслати** | Передати баланс токена на іншу адресу. |
| **«Погасити»** | У поточному застосунку відкриває надсилання з попередньо заповненою адресою власника токена. Це пред’являє або повертає токени емітенту, але не доводить виконання. |
| **Виконати** | Емітент надає обіцяні товари, послуги, переваги або інше виконання. |
| **Списати** | Зафіксувати виконані одиниці так, щоб їх не можна було пред’явити повторно, наприклад через отримання, спалювання, скасування або інше вимкнення відповідно до опублікованих умов. |
| **«Вивести ваучер з обігу»** | Приховати ваучер із каталогу застосунку. Баланси й історія залишаються, а адміністратор може відновити запис. Це не спалювання й не скасування. |
| **Депозит або внесок у Пул** | Передати активи до `SwapPool`. Права на повернення, виведення, винагороду чи управління існують лише тоді, коли їх окремо розкрито. |
| **Обмін через Пул** | Обміняти один підтримуваний актив на інший через один `SwapPool`. Це не виконання емітентом і не автоматично позика. |
| **Виведення ліквідності Пулу** | Власник Пулу передає доступні запаси на вибрану адресу. |
| **Збір комісій** | Налаштований отримувач збирає накопичені комісії Пулу. |

Використовуйте **розрахунок за обміном** для переказів у блокчейні та обліку комісій, що завершують обмін через Пул. Використовуйте **пред’явлення для погашення**, **виконання** та **списання** для окремого реального життєвого циклу ваучера.

## Ринок, вартість, ліміти й комісії

**Ринок** у застосунку — це каталог для пошуку ваучерів, Пулів, Пропозицій і публічної інформації. Розміщення не означає автоматично, що це місце обміну, відносини з продавцем, схвалення, оцінка або гарантія.

Розрізняйте такі поняття вартості:

- **ціна Пропозиції:** сума, яку просять за зазначений товар або послугу;
- **заявлена вартість ваучера:** вартість, зазначена в опублікованих умовах емітента;
- **обмінний курс або котирування Пулу:** параметр транзакції, який створює налаштований модуль котирування Пулу;
- **дані оракула:** зовнішні дані, які використовує налаштований модуль оцінювання; і
- **умови погашення:** що та за яких умов обіцяє надати емітент.

Назва **«Кредитний ліміт»** у застосунку означає налаштовану верхню межу балансу токена в Пулі: максимальну кількість цього токена, яку Пул може зберігати після депозиту. Це не особиста кредитна лінія, не перевірка спроможності емітента й не гарантія погашення. Пропоновані в Білій книзі ковзні, облікові та загальномережеві ліміти є іншими механізмами.

Поточний Protocol v1.1.0 може стягувати **комісію Пулу** й додаткову **протокольну комісію**. Пропонована модель у Білій книзі окремо описує майбутню **частку мережі** з комісій Пулу та можливі комісії за маршрутизацію або сервіси. Ці моделі не слід поєднувати під час пояснення поточних витрат або розрахунку майбутніх доходів.

## Захист і докази

Кураторство, внесення до реєстру, ліміт, резерв, видимість у застосунку або блокчейн-транзакція самі по собі не означають схвалення, спроможність емітента, виконання, гарантію чи страхування.

Кожен механізм захисту має визначати зобов’язану сторону, покриту подію, фінансування, верхню межу, винятки, строк дії, докази та порядок подання вимог. Записи в блокчейні можуть показувати адреси, активи, суми, часові позначки й події контрактів. Виконання емітентом, задоволеність, обговорення управління та соціальний вплив потребують окремих розкриттів, звітів, засвідчень або інших доказів.

## Статуси

- **Поточне:** перевірено в CLC App або Protocol v1.1.0, описаних у цій документації.
- **Залежить від розгортання:** доступне лише там, де це дозволяє конкретне розгортання, Пул, постачальник, юрисдикція або опублікована політика.
- **Історичне:** докази або функції попереднього сервісу Sarafu Network.
- **Пропоноване:** механізм дизайну або дорожньої карти, який не представлено як розгорнутий.

У посібнику [Початок роботи](/uk/introduction/getting-started) ці терміни застосовано до поточного застосунку. [Довідка про Протокол](/uk/protocol/overview) описує перевірені контракти, а [Біла книга](/uk/white-paper) — ширший дизайн і пропозиції.

Для додаткового навчання через гру про зобов’язання, розрахунки, потоки ресурсів, обмін і об’єднання перегляньте [навчальні ігри Grassroots Economics](https://grassrootseconomics.org/games/). Це навчальні матеріали, а не визначення поточної поведінки застосунку чи Протоколу.
