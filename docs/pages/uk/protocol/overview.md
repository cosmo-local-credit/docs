# Протокол

**Протокол об’єднання зобов’язань (CPP)** описує, як незалежно керовані Пули добирають Ваучери, публікують правила обміну й уможливлюють обмін. Згодом Власник Ваучера використовує його в Емітента для отримання обіцяних товарів чи послуг. Це окремі кроки з окремою відповідальністю.

Цей сайт пояснює ці поняття й використання CLC App. [Документація програмного забезпечення CLC](https://software.cosmolocal.credit/) є основним довідником із реалізації програмного забезпечення, контрактів, API, розгортання й експлуатації. Наразі вона доступна англійською.

Почніть із [понять і термінології](/uk/introduction/concepts), щоб ознайомитися зі спільними термінами, або з [Білої книги](/uk/white-paper), щоб дізнатися про ширший задум і пропозиції.

## Схема розгортання

Різні спільноти й організації можуть використовувати сумісне програмне забезпечення за власними правилами. Grassroots Economics Foundation керує [публічним CLC App](https://cosmolocal.credit). Кожне розгортання має зазначати своїх операторів, контракти й відповідальні органи.

Адреси контрактів, інструкції з розгортання та перевірку власників і повноважень оновлення описано в розділі [Розгортання й перевірка](https://software.cosmolocal.credit/contracts/deployments). Щодо експлуатації допоміжних служб почніть з [API CLC Core](https://software.cosmolocal.credit/core-api/).

## Компоненти

Використовуйте довідник програмного забезпечення для таких тем:

| Тема | Основна документація програмного забезпечення |
| --- | --- |
| Створення, обсяг випуску й строк дії Ваучерів | [Ваучери](https://software.cosmolocal.credit/contracts/vouchers) |
| Налаштування, депозити, виведення й контроль Пулів | [Пули](https://software.cosmolocal.credit/contracts/pools) |
| Розрахунок обмінних курсів | [Модулі котирування (Quoter)](https://software.cosmolocal.credit/contracts/quoters) |
| Виконання обміну, комісії й записи транзакцій | [Котирування й розрахунок обмінів](https://software.cosmolocal.credit/contracts/swaps) |
| Обмін через кілька Пулів | [Маршрутизація](https://software.cosmolocal.credit/contracts/routing) |
| Пошук і допоміжні контракти | [Реєстри й інструменти](https://software.cosmolocal.credit/contracts/registries) |
| Запити й відповіді API | [Довідник OpenAPI](https://software.cosmolocal.credit/core-api/reference) |
| Налаштування серверних служб і маршрутизації | [Конфігурація](https://software.cosmolocal.credit/core-api/configuration) |

## Обмін за маршрутом на рівні застосунку

Застосунок може допомогти учаснику обміняти активи через кілька Пулів, коли доступний відповідний маршрут. Учасник переглядає котирування й дозволяє обмін. Кожен Пул зберігає власні правила й відповідальних осіб.

У розділі [Маршрути й відповідальність](/uk/protocol/network) пояснено, що це означає для учасників, а в [Реалізації маршрутизації](https://software.cosmolocal.credit/contracts/routing) — як програмне забезпечення розраховує й виконує маршрути.

Програмне забезпечення уможливлює обмін; Емітенти залишаються відповідальними за обіцянки своїх Ваучерів, а Куратори Пулів — за опубліковані правила. Використання публічного Застосунку регулюють [Умови надання послуг](/uk/governance/terms).
