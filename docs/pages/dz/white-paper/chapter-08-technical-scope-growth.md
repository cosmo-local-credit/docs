# 8. ཁྱད་རིག་གི་གནས་ཚད་དང་གོང་འཕེལ་

ལེའུ་འདི་ནང་ལུ་ ད་ལྟོའི་ཐོན་སྐྱེད་ཀྱི་ལམ་སྟོན་གྱི་ཞབས་ཏོག་དང་ གདམ་ཁ་ཅན་ ཡང་ན་ གོང་འཕེལ་འཆར་གཞི་ཚུ་སོ་སོར་སྦེ་བཀོད་དེ་འདུག ད་ལྟོའི་ནུས་ཤུགས་འདི་ མི་མང་གི་ CLC App/Core ལག་ལེན་འཐབ་ནིའི་དོན་ལས་ དམིགས་བསལ་གྱི་ཨིནམ་སྦེ་རང་གནས་ཏེ་ཡོདཔ་ཨིན། འདི་ཚུ་ རང་བཞིན་གྱིས་ Protocol v1.1.0 གི་གན་ཡིག་དང་ ཡང་ན་ལག་ལེན་གཞན་ཚུ་གི་ཁྱད་ཆོས་ཅིག་མེན་པས།

ད་ལྟོའི་ མི་མང་གི་ཁ་སྐོང་ནང་ལུ་:

- སྦྲེལ་མཐུད་འབད་ཚུགས་པའི་ ཕུལ་བཱའིན་ཚུ་ གིརཕ་ལུ་གཞི་བཞག་སྟེ་ འཚོལ་ཞིབ་འབད་ནི་ཨིན།
- བཀྲམ་སྟོན་འབད་ཡོད་པའི་ འགྲུལ་བསྐྱོད་ཐོ་བཀོད་ཀྱི་ ཐབས་ལམ་གྱི་དོན་ལུ་ དབང་འཛིན་གྱིས་ གཞི་བཙུགས་འབད་མི་ མཉམ་སྤྱོད་དངུལ་ཁུངས།་གི་གོང་ཚད་ཚུ་ཨིན།
- སྟབས་རེ་ལུ་ ཨའི་པུ་ལིསི་དང་ བརྒྱུད་ལམ་གྱི་འཐུས་རྩིས་རྐྱབ་ནི་ ཉུང་ཤོས་ཐོན་སྐྱེད་དང་ དུས་ཡུན་ཚུ།
- གྲལ་གཏོགས་ཅན་ཚུ་གིས་ མིང་རྟགས་བཀོད་ནི་དང་ Calibur ལག་ལེན་འཐབ་ནི་ཚུ་ ཡོངས་འབྲེལ་ཐོག་ལས་ བརྟག་ཞིབ་འབད་ནི་ཨིན།
- རྒྱུད་ལམ་གཅིག་ནང་ལུ་ མཉམ་འབྲེལ་གྱི་ཚོང་ལཱ་ཅིག་འབད་ཞིནམ་ལས་ བཏོན་བཏངམ་ཨིན།
- སྡེ་ཚན་བཟོ་ཡོད་པའི་ཐོབ་ཐངས་དང་ སྟབས་གཅིག་སྦེ་ བཀྲམ་སྤེལ་འབད་ཡོད་མི་ འབྱུང་རིམ་ཚུ་གི་དབྱེ་ཞིབ་འབདཝ་ཨིན།

གོང་འཕེལ་འབྱུང་ཚུགས་པའི་ ས་ཁོངས་ཚུ་ཡང་:

- དུས་ཡུན་གཏན་འཁེལ་འབད་ཡོད་པའི་ ཚོད་བསྲེ་དང་ ཡང་ན་ HTLC ཨའི་ཌབ་ཊར་ཚུ་ ས་ཁོངས་སོ་སོ་གི་ཐོག་ལས་ བཏོན་གཏང་ནི་ཨིནམ་ད་ དེ་ནང་ལུ་ རང་བཞིན་གྱི་མཐུན་རྐྱེན་མེད་པ་ཅིན་ཨིན།
- ཐོ་བཀོད་ལས་རིམ་དང་ སྲིད་བྱུས་ཀྱི་བཟོ་རྣམ་ དེ་ལས་ རྒྱུད་ལམ་མཐུད་སྦྲེལ་གྱི་དོན་ལུ་;
- opt-in མཉམ་སྤྱོད་དངུལ་ཁུངས། inventory rebalancing and batch netting བཀྲམ་སྤེལ་འབད་ཡོད་པའི་རྒྱུ་དངོས་ཚུ་ ལོག་གནས་སོར་གཏང་ནི་དང་ མཉམ་བསྡོམས་བཟོ་ནི་
- འབྲེལ་མཐུད་དང་ སྲིད་བྱུས་ཀྱི་ལག་ཆས་ཚུ་ འཛིན་སྐྱོང་ཁང་ཆུང་ ཡང་ན་ རང་རྐྱང་གི་དོན་ལུ་
- ཐོ་བཀོད་འབད་ཚུགས་མི་ ཁྲལ་གྱི་ཐོ་ཡིག་ཚུ་ བརྒྱུད་འཕྲིན་དང་དངུལ་ཁང་ དེ་ལས་ དངུལ་འབྲེལ་གོང་ཚད་ཀྱི་ཐབས་ལམ་ཚུ་གི་དོན་ལུ་ རིན་བསྡུར་འཐབ་ཚུགསཔ་ཨིན།
- བགོ་བཀྲམ་འབད་ནིའི་ཐད་ལུ་ འབྲེལ་བ་ཡོད་པའི་ སྐྱིན་འགྲུལ་མཁོ་སྤྲོད་མཁོ་སྤྲོད་མིདང་ ཐོ་བཀོད་འབད་ཐངས་ དེ་ལས་ འོས་འབབ་ཀྱི་ཚད་འཛིན་ཚུ་
- འོག་གི་དངུལ་ཁང་ཚུ་ནང་ དངུལ་འབྲེལ་མཐུན་རྐྱེན་གྱི་དོན་ལུ་ བགོ་བཀྲམ་འབད་ནི་དང་ སྐྱིན་འགྲུལ་སྤྲོད་ནི་ དེ་ལས་
- སྲིད་བྱུས་དང་འབྲེལ་བའི་ དངུལ་རྩིས་བསྒྱུར་བཅོས་ཀྱི་དོན་ལུ་ ཆ་འཇོག་གྲུབ་མི་ ཁྲལ་གྱི་ཁེ་རྒུད་ ཡང་ན་ བྱ་སྟབས་མ་བདེཝ་ཚུ་གི་དོན་ལུ་ བསྒྱུར་བཅོས་འབདཝ་ཨིན།

ཕྱིའི་ཚོང་འབྲེལ་གྱི་གོང་ཚད་ཚུ་གིས་ དངུལ་ཕོགས་སྤྲོད་མི་ཅིག་གིས་ ཁས་བླངས་ཀྱི་གནས་སྟངས་དང་འཁྲིལ་ ག་དེ་སྦེ་ བུ་ལོན་བཏབ་ཡོདཔ་ཨིན་ན་ བཀྲམ་སྟོན་མི་ཚུགས་ནི་ཨིནམ་ད་ སྡེ་ཚན་གྱིས་ འཁྲུན་ཆོད་ཅན་གྱི་ རྒྱུ་དངོས་ཚུ་གི་དོན་ལུ་ ཉེན་སྲུང་ཡོད་པའི་ ཕྱི་ཕྱོགས་ཡིག་ཆ་ལག་ལེན་འཐབ་ཚུགས་རུང་ སྤོ་བཤུད་འབད་ཡོད་མི་དངུལ་བརྗེ་སོར་གི་ ཐབས་ལམ་དང་ ངེས་གཏན་ཚུ་ ཁྲལ་དང་ ཅ་དམ་དེ་ཚུ་ དེ་ལས་ ཐོན་ཡོདཔ་ཨིན་པས།

## **8.1 ད་ལྟོའི་ལམ་འགྲུལ་ཞབས་ཏོག་དང་ སྤྱིར་བཏང་གནས་ཚད་ཚུ་**

**Discovery.** CLC Core གིས་ གྲ་སྒྲིག་འབད་ཡོད་པའི་ཐོ་ཡིག་དང་ ཐོ་བཀོད་ལས་རིམ་གྱི་འབྲེལ་བ་ དེ་ལས་ མཉམ་སྤྱོད་དངུལ་ཁུངས། གི་ཚད་གཞི། རིན་གོང་། དུམ་གྲ་རེ་དང་ གྱངས་ཁ་ཚུ་ བསྡུ་ལེན་འབདཝ་ཨིན། དེ་ནང་ལུ་ session wallet ཅིག་གིས་ག་དེ་འབད་ཚུགས་གའི་ཚོད་རྩིས་བཏོན་ཏེ་ གནས་སྡུད་རྙིངམ་ཚུ་ཐོ་བཀོད་འབདཝ་ཨིན། སྤྱིར་བཏང་སྒྲིག་གཞི་འདི་གིས་ མཉམ་སྤྱོད་དངུལ་ཁུངས།་གསུམ་ཚུན་ཚོད་ཀྱི་ ལམ་འདི་འཚོལ་ཚུགས། ཞིབ་འཚོལ་འདི་ ལཱ་འབད་ཚུགས་པའི་ ཁས་བླངས་མེན་པས།

CLC Core གིས་ གདམ་ཁ་རྐྱབ་ཡོད་པའི་ལམ་འགྲུལ་གྱི་དོན་ལུ་ བཅའ་མར་གཏོགས་མི་ Pool ཚུ་ པིན་བོརཀ་གཅིག་ནང་ལུ་ བསྐྱར་བཟོ་འབད་ཞིནམ་ལས་ རྒྱབ་སྐྱོར་འབད་མི་ལུ་ ལེགས་བསྒྱུར་འབདཝ་ཨིན། `SwapPool` ཨང་རྩིས་རིག་པ། ཁོ་གིས་ མཉམ་སྤྱོད་དངུལ་ཁུངས། དང་ protocol གི་འཐུས་ཚུ་ གསལ་བཀོད་འབད་ཡོདཔ་དང་ hop རེ་ལུ་ཉུང་མཐའི་ཐོན་སྐྱེད་དང་ དུས་ཡུན་གཏན་འབེབས་བཟོཝ་ཨིན། དེ་ལས་ wallet calls འདི་ གྲ་སྒྲིག་འབད་དེ་ བཀྲམ་སྟོན་འབདཝ་ཨིན། རྒྱབ་སྐྱོར་མེད་མི་ ཐོ་ཀེན་དང་ ཀོཊ་བཱའིན་ཌིང་ ཡང་ན་ པོ་ལར་གི་གནས་སྟངས་ཚུ་ ཆ་བཞག་ནི་མེདཔ་ཨིན།

**འ་ནི་ལས་ཀ་འདི་གིས་ ད་ལྟོའི་བར་ནའི་གནས་སྟངས་ནང་ལུ་ ལག་ལེན་འཐབ་ཚུགསཔ་ཨིན།** བཅའ་མར་གཏོགས་མི་གིས་ ཀ་ལི་བུར་ (Calibur) བཀྲམ་སྤེལ་འབད་ཡོད་པའི་གུ་ མཚན་རྟགས་བཀོད་དེ་ཡོདཔ་དང་ འདི་ནང་ གོ་སྐབས་བསྐྱར་གསོ་འབད་ནི་དང་ གོ་བརྡ་སྤྲོད་ནི་ དེ་ལས་ སྦྲགས་ཏེ་ཡོད་མི་ཚུ་ ལེན་ནིའི་དོན་ལས་ ཐུམ་སྒྲིལ་འབདཝ་ཨིན། ཚད་འཛིན་འབད་མི་ཅིག་གིས་ ཐིག་ཁྲམ་གཅིག་དང་ `revertOnFailure` ལྕོགས་ཅན་བཟོ་ཡོདཔ་ཨིན། འདི་གིས་ ད་ལྟོའི་ལམ་འགྲུལ་གྱི་དོན་ལུ་ ལག་ལེན་གནས་ཚད་ཀྱི་ བྱ་སྤྱོད་ག་ར་ ཡང་ན་ ག་ནི་ཡང་ བྱིན་མི་ཚུགས། ཐིག་ཁྲམ་འདི་ ཀྲོསི་ཅེན (Cross-chain) ཟེར་མི་འདི་མེན་ HTLC ཡང་ན་ ཨེས་ཀི་རོ་ལམ་སྟོན་འབད་ནི་དང་ རང་བཞིན་གནས་ཚད་བསྐྱར་གསོ་འབད་ནི་ དེ་ལས་ ནཊི་ནི་ཚུ་ཨིན།

**ཐོ་བཀོད་དང་ལས་རིམ་ཚུ་.** ལག་ལེན་འདི་གིས་ འགྲུལ་བསྐྱོདཔ་ཅིག་ནང་ལུ་ སྦྲེལ་མཐུད་ཨང་རྟགས་གཅིག་བཙུགས་ཏེ་ གན་ཡིག་གི་གནས་སྟངས་དང་ hop order,མཉམ་སྤྱོད་དངུལ་ཁུངས་ཚུ།,token pairs, quoted and settled amounts, མཉམ་སྤྱོད་དངུལ་ཁུངས། fees,protocol fees དེ་ལས་ བར་གྱི་ལྷག་ལུས་ཚུ་ཐོ་འགོད་འབདཝ་ཨིན། ཞབས་ཏོག་འདི་གིས་ གིརེཕ་གསརཔ་དང་ ལམ་འགྲུལ་གྱི་གྱངས་ཁ་བཀོད་ནི་དང་ གྲུབ་འབྲས་ཚུ་དང་ སིམ་ལུཊ་གི་འཛོལ་བ་ དེ་ལས་ མོས་མཐུན་བཟོ་ནིའི་དུས་ཡུན་དང་ བསྒྱུར་བཅོས་འབད་མ་བཏུབ་མི་དང་ ཡང་ཅིན་ ཀླད་ཀོར་ནང་མེད་མི་ ཡང་ན་ ངོ་མ་ཤེས་པའི་ཡན་ལག་ཚུ་ ལྟ་རྟོག་འབདཝ་ཨིན། ལས་འགུལ་གྱི་རྒྱང་མཐོང་ཚད་འཛིན་གྱིས་ སྐྱིན་འགྲུལ་བྱིན་མི་གིས་ དགོས་མཁོ་ཚུ་གྲུབ་ཡོདཔ་ ངེས་བདེན་བཟོ་མི་ཚུགས་པས།

**network profiles.** བརྒྱུད་འཕྲིན་ཅིག་གིས་ ཐོ་བཀོད་ཡིག་ཚང་གི་རྩ་བ་ ཡང་ན་ སྲིད་བྱུས་ profile གཅིག་ལས་ལྷག་སྟེ་ རྒྱབ་སྐྱོར་འབད་ཚུགས། འདི་གིས་ བཅའ་མར་གཏོགས་མི་ཚུ་ལུ་ རིམ་ལུགས་ག་བཟུམ་ཅིག་དང་ ཁས་ལེན་པ་ག་ཚུ་ སྦྱར་སྤྱོད་འབད་ཡོདཔ་ཨིན་ན་ བཀག་འཛིན་འབད་མི་ དེ་ལས་ འགན་ཁུར་ཅན་གྱི་ ཞབས་ཏོག་མགྲོན་པོ་ཚུ་གི་སྐོར་ལས་སླབ་འོང་། ཕྲ་རིང་གི་ལམ་འདི་ འོས་ལྡན་གྱི་ hop གི་གནས་སྟངས་ཚུ་ཆ་མཉམ་ལུ་ ངོས་ལེན་འབད་དགོཔ་ཨིན།

**ལམ་གྱི་ སྲིད་བྱུས་.** འགན་ཁུར་འབག་མི་ལས་སྡེ་ཅིག་གིས་ ཉེན་སྲུང་མེད་པའི་ འབྲེལ་བ་ཡོད་མི་ས་སྒོ་དང་ རྒྱབ་སྐྱོར་འབད་མི་ཚུ་ ཆ་མེད་གཏང་ནི་དང་ ལམ་འགྲུལ་གནས་ཚད་ཀྱི་ ས་སྒ་ཚུ་ལག་ལེན་འཐབ་ནི་ གསརཔ་གི་དགོས་མཁོ་ དེ་ལས་འཕྲོད་བསྟེན་བརྟག་དཔྱད་ཚུ་ འབད་བཏུབ། འ་ནི་བརྡ་སྟོན་ཚུ་གིས་ གྲོས་ཐག་བཅད་ནི་ལུ་ རྒྱབ་སྐྱོར་འབད་ཚུགས་ནི་ཨིན་རུང་ འདི་ཚུ་འགྲུབ་ནི་དང་ ཡང་ཅིན་ གྱོང་རྒུད་ཕོག་ནི་ལས་ ཉེན་སྐྱོབ་འབད་མི་ཚུགས།

**གླ་འཐུས་དང་ཚད་གཞི་ཚུ་.** ད་ལྟོའི་འཆར་གཞིའི་ནང་ མཉམ་བསྡོམས་ཀྱི་དངུལ་ཕོགས་དང་ ཐོ་བཀོད་རིམ་ལུགས་ཀྱི་ དངུལ་ཕོགས་རེ་ལུ་ རིམ་པ་བཞིན་དུ་བཀོད་དེ་འདུག ཡོངས་འབྲེལ་ལག་ལེན་འདི་ ད་རེས་ནངས་པར་ རུ་ཊར་ཞབས་ཏོག་གི་འཐུས་ཁ་སྐོང་མེདཔ། མ་འོངས་པ་ལུ་ ཞབས་ཏོག་གི་འཐུས་ཚུ་སོ་སོར་སྦེ་ གསལ་སྟོན་འབད་ནི་ཨིན། ལག་ལེན་འདི་ དུས་ཡུན་ཚང་མི་དང་ ས་མཚམས་བརྒལ་མི་ཚུ་ ཆ་མེད་གཏང་ནི་ཨིན་མས།

**Cross-domain atomicity and recovery.** ཤུལ་མའི་ལམ་འདི་ ད་རེས་ཀྱི་ same-chain atomic batch ལག་ལེན་འཐབ་མ་ཚུགསཔ་ལས་ HTLCs ཡང་ན་ escrow གི་ཚབ་ལུ་ལག་ལེན་འཐབ་པ་ཅིན་ ཞབས་ཏོག་འདི་གིས་ timeouts, abort paths, responsible controllers, incident procedures དེ་ལས་ residual riskཚུ་ གསལ་སྟོན་འབད་འོང་།

**གདམ་ཁ་ཅན་གྱི་ཞབས་ཏོག་གིས་ ཚད་གཞི་བསྐྱར་གསོའི་འཆར་གཞི་ཚུ་བསྡུ་ལེན་འབད་ཞིནམ་ལས་ མཉམ་འབྲེལ་ཡོད་པའི་འཁོར་ལོ་དང་ཐིག་ཁྲམ་ཚུ་འཚོལ་ཚུགས།** དེ་སྦེ་འབད་བ་ཅིན་:
