# 5. ཟུར་བཞག་ཡོད་པའི་མཉམ་སྤྱོད་དངུལ་ཁུངས་ཚུ་ལས་ འབྲེལ་མཐུད་འབད་ཡོད་མི་དྲ་ལམ་ཅིག་ལུ་

ད་ལྟོའི་གློག་རིམ་ v1.1.0 གིས་ ཐད་ཀར་དུ་ལག་ལེན་འཐབ་ནི་ལུ་ རྒྱབ་སྐྱོར་འབདཝ་ཨིན། `SwapPool` གསལ་བཀོད་འབད་ཡོད་པའི་ཚིག་ཡིག་ཚུ་རྐྱངམ་ཅིག་ གྲ་སྒྲིག་འབདཝ་ཨིན། `SwapRouter`. བཟོ་སྐྲུན་གྱི་ CLC App དང་CLC Core ཚུ་གིས་ བཅའ་མར་གཏོགས་མི་གིས་འགོ་འདྲེན་འཐབ་པའི་ མཉམ་འབྲེལ་ལམ་ལུགས་ཚུ་ གྲ་སྒྲིག་འབད་དོ་ཡོདཔ་ཨིན། ཁག་འབག་གི་གན་ཡིག་ཚུ་ནང་ མང་ཤོས་ཅིག་གིས་ སྦྲེལ་མཐུད་ལམ་སྟོན་འབད་མི་དང་ ད་ལྟོའི་ App/Core གི་རིམ་ལུགས་ནང་ལུ་ ཡོངས་འབྲེལ་གྱི་ HTLCs དང་ escrow ལམ་སྟོན་ དེ་ལས་ རང་བཞིན་གྱིས་ མཉམ་སྤྱོད་དངུལ་ཁུངས། སླར་གསོ་བཏོན་ནི་དང་ བཀྲམ་སྤེལ་འབད་ཐངས་ ཡང་ན་ ཡོངས་ཁྱབ་ཡོངས་འབྲེལ་ཐོག་ལས་ རྩིས་སྤྲོད་འབད་ནི་ཚུ་མེདཔ་ཨིན།

ལེའུ་འདི་ནང་ལུ་ ད་ལྟོའི་མཉམ་ཞུགས་པའི་ལམ་ལུགས་ཀྱི་འགྲེལ་བཤད་འབད་ཡོདཔ་དང་ འདི་ཡང་ Poolགི་དབང་ཆ་གསརཔ་ དགོཔ་ཡོད་པའི་ གྲོས་འཆར་བཀོད་མི་མཐུན་འབྲེལ་ལས་ དབྱེ་བ་ཕྱེ་ཡོདཔ་ཨིན། གནད་དོན་འདི་གཉིས་ཆ་ར་ལུ་ རང་དབང་ཅན་གྱི་སྡེ་ཚན་གྱིས་ ཁོང་རའི་འཛུལ་ཞུགས་དང་ གནས་གོང་ཚད་འཛིན་ནི་ ས་མཚམས་དང་གླ་འཐུས་ དེ་ལས་ ཐོ་བཀོད་འབད་ཡོད་པའི་ཅ་ཆས་ཚུ་ གནང་བ་བྱིན་ནི་དང་ བདག་སྐྱོང་གི་ཁྲིམས་ལུགས་ཚུ་ཡང་ བཞག་སྟེ་ཡོདཔ་ཨིན།

## **5.1 བརྗེ་སོར་དང་ བསྒྲུབ་ཐབས་ཀྱི་ ཐབས་ལམ་ཁག་ཆེ་ཤོས་**

ཐོ་བཀོད་འབད་མི་འདི་གིས་ དངོས་པོ་ཚུ་ཐོབ་ཚུགསཔ་བཟོ་ཚུགས་ དེ་འབདཝ་ད་ འདི་གིས་ འཛིན་ཤོག་འདི་ གཅིག་ཁར་བསྡོམས་ཏེ་ སྲོག་གནས་རིམ་བརྗེ་སོར་མི་འབདཝ་ཨིན། འ་ནི་བྱུང་རིམ་ཚུ་སོ་སོ་སྦེ་བཞག་དགོཔ་ཨིན།

1. རྒྱང་ལམ་ཅིག་བཏོན་དགོ།
2. མཉམ་འབྲེལ་མཐུན་རྐྱེན་གཅིག་ ཡང་ན་མང་ཤོས་ཅིག་གིས་ ལྕགས་ཐག་ནང་ལུ་ལག་ལེན་བསྟར་སྤྱོད་དང་ གྲོས་བསྡུར་འབདཝ་ཨིན།
3. དངུལ་ཁང་གི་ཚོང་འབྲེལ་འཐབ་མི་ཅིག་གིས་ བརྒྱུད་འཕྲིན་ཨང་ཚུ་ ཕྱིར་བཏོན་འབདཝ་ཨིན།
4. ཕྱིར་ཚོང་འཐབ་མི་གིས་ ཁས་བླངས་འབད་མི་དེ་ བསྒྲུབས་ཡོདཔ་མ་ཚད་
5. བཀྲམ་སྤེལ་འབད་ཡོད་པའི་ ཡུ་ནིཊ་ཚུ་ བཙུགས་ཚར་ཡོདཔ་ཨིན།

ཟད་ཐོ་མང་ཤོས་ཅིག་དང་ ཡང་ཅིན་ ལག་ལེན་བསྟར་སྤྱོད་འབད་ཡོད་པའི་ལམ་སྒོ་ཚུ་ མཐར་འཁྱོལ་ཅན་སྦེ་སྟོན་མི་ཚུགས། སྙན་ཞུ་འདི་ནང་ གྲོས་བསྡུར་, དུས་ཡུན་, རྒྱུ་དངོས་, བརྩི་འཇོག་གི་ཐབས་བྱུས་དང་ དུས་ཚོད་ཐོ་བཀོད་, ཆ་མེད་གཏང་ནི་དང་ བསྒྱུར་བཅོས་འབད་ནི་ དེ་ལས་ འབྲེལ་མཐུད་ C ལུ་ དགོཔ་འབད་མི་ evidence འདི་ཡང་བཀོད་འོང་།

དཔེ་འབད་བ་ཅིན་ སློབ་གྲྭ་ཅིག་ནང་ ཀེ་བ་གི་ལག་ཁྱེར་ཡོད་རུང་ སྐྱེལ་འདྲེན་གྱི་ ལག་ཁྱེར་ཚུ་ དགོཔ་ཨིན་མས། CLC Core གིས་ མཉམ་འབྲེལ་ཅན་གྱི་ མཉམ་སྤྱོད་དངུལ་ཁུངས། inventories ངོས་འཛིན་འབད་ཚུགས་ནི་ཨིནམ་དང་ བཀྲམ་སྟོན་འབད་མི་ལམ་འདི་ མཉམ་སྤྱོད་དངུལ་ཁུངས།་གཅིག་ནང་ལུ་བཀོད་དེ་ཡོདཔ་མ་ཚད་ སློབ་གྲྭ་གི་དངུལ་ཁུག་གི་དོན་ལུ་ ཐད་ཀར་གྱི་འབོད་སྐུལ་ཚུ་ གྲ་སྒྲིག་འབདཝ་ཨིན། ལག་ལེན་འདི་ མཐར་འཁྱོལ་ཅན་ཅིག་སྦེ་འཐོན་ནི་ཨིན་པ་ཅིན་ འཕུར་འགྲུལ་རེ་ལུ་ རིན་གོང་དང་ཚད་གཞི་ དེ་ལས་འཐུས་དང་ ཅ་ཆས་ཀྱི་གྱངས་ཁ་ དེ་ལས་ རྒྱབ་སྐྱོར་ཅན་གྱི་བྱ་སྤྱོད་དང་ སྲིད་བྱུས་ཚུ་གི་ནང་འཁོད་ལུ་ བཞག་ཚུགསཔ་ཨིན། འབྱུང་འགྱུར་གྱི་གན་རྒྱ་འདི་གིས་ བཀྲམ་སྤེལ་པ་ཅིག་གིས་ ཤུལ་ལས་ ཁས་བླངས་པའི་བཱའིན་ཆི་ཚུ་ གྲུབ་ཡོདཔ་ ངེས་བདེན་སྦེ་སྟོན་མི་ཚུགས།

## **5.2 དེང་སང་གི་མཉམ་ཞུགས་པའི་ལམ་སྟོན་དང་ བརྟག་དཔྱད་འབད་ནིའི་འཆར་གཞི་**

ལས་སྣ་གཉིས་ལུ་ དབང་ཚད་སོ་སོ་དགོཔ་ཨིན།

**ད་ལྟོའི་མཉམ་ཞུགས་པ་གིས་འགོ་འདྲེན་འཐབ་མི་ ལག་ལེན་.** ནང་བསྐྱོད་དང་ཐོན་སྐྱེད་ལག་ཁྱེར་ དེ་ལས་ དངུལ་ཀྲམ་ཚུ་བྱིན་ཞིནམ་ལས་ CLC Core གིས་ བཅའ་མར་གཏོགས་མི་ཚུ་གི་ འོས་འབབ་དང་ལྡནམ་སྦེ་ཡོད་པའི་རྒྱུ་དངོས་ཚུ་ལས་ ལམ་འགྲུལ་གྱི་ཚོད་དཔག་འབདཝ་ཨིན། སེལ་འཐུ་འབད་ཡོད་པའི་ལམ་འགྲུལ་གྱི་དོན་ལུ་ ཁོ་གིས་ མཉམ་སྤྱོད་དངུལ་ཁུངས།་ཚུ་ཨེབ་གཏང་འབད་མི་ས་ཁོངས་གཅིག་ནང་ལུ་ བསྐྱར་ཞིབ་འབད་དེ་ བཟོ་སྐྲུན་འབད་ནི་དང་ གནས་གོང་གཏན་འཁེལ་བཟོ་ནི་ དེ་ལས་ ཨེཆ་བིཊི་ཧོབ་རེ་ལུ་ ཀོལ་༣ གྲ་སྒྲིག་འབདཝ་ཨིན། `SwapPool.withdraw`. བཅའ་མར་གཏོགས་མི་གིས་ཐོ་བཀོད་འབད་ཞིནམ་ལས་ བརྒྱུད་འབྲེལ་པ་གིས་ ཀ་ལི་བུར་གྱི་ཚོང་ལཱ་གཅིག་ དང་གཅིག་ཁར་ `revertOnFailure` ལྕོགས་ཅན་བཟོ་ཡོདཔ་ཨིན། འགྲུལ་འཕྲིན་ཨང་བཏགས་མ་ཚུགས་པ་ཅིན་ ཐབས་ལམ་ག་ར་ལོག་གཏང་འོང་། ལས་རིམ་དེ་གིས་ ཚོང་འབྲེལ་དང་ རིན་བསྡུར་ཚུ་ འཐོབ་ལམ་གཅིག་ནང་ གཅིག་ཁར་སྤེལ་ཚུགས་ནི་ཨིན་མས།

སྒོང་རྡོག་རེ་ལུ་ རང་སོའི་འགན་ཁུར་ཡོད་པའི་ མཉམ་སྤྱོད་དངུལ་ཁུངས།་དང་ རིན་བསྡུར་ནང་བཙུགས་ཐངས་ ངོས་ལེན་གླ་འཐུས་ཚད་འཛིན་ དེ་ལས་ དངོས་རིགས་ཚུ་ བཞག་ནི་ཨིན་མས། ད་ལྟོའི་ལག་ལེན་འདི་གིས་ ལམ་འགྲུལ་ཞབས་ཏོག་གི་འཐུས་སོ་སོར་མི་སྣོན། ད་ལྟོའི་གློག་རིམ་འདི་གིས་ App-compatible EOA/Calibur wallet ཚུ་རྒྱབ་སྐྱོར་འབད་དོ་ཡོདཔ་དང་ Safes ཡང་ན་ གཞན་གན་ཡིག་གི་དངུལ་ཁུག་འདི་མིན་འདུག

- ངོས་ལེན་འབད་མི་དང་ ཆ་མེད་གཏང་མི་ མཉམ་འབྲེལ་ཚོགས་པ་, རྒྱུ་དངོས་ཚུ་, བཀྲམ་སྤེལ་འབད་མི་ཚུ་ དེ་ལས་ལམ་ལུགས་ཚུ་ གསལ་སྟོན་འབདཝ་ཨིན།

## **5.3 གྲོས་འཆར་ཅན་གྱི་ གློག་ཐག་ར་བ་དང་ ཞབས་ཏོག་གི་འཐུས་ཀྱི་རྣམ་གཞག་**

### **5.3.1 དངུལ་རྐྱང་གི་མཐུན་རྐྱེན་དང་ རང་བཞིན་གྱི་ཐོབ་ཐོ་བཀོད་**

དངུལ་རྐྱང་གི་ཐོབ་ཐངས་ཚུ་དངུལ་གྱི་མཐུན་རྐྱེན་ལུ་ཆ་བཞག་མི་ ཅ་ཆས་དང་ ཡང་ན་ ཁས་བླངས་ཁྲལ་ དེ་ལས་ རང་བཞིན་གནས་སྟངས་ནང་ཡོད་པའི་ རྒྱུ་དངོས་གཞན་ཚུ་ནང་འོང་ཚུགས། རང་བཞིན་པའི་བིན་ཚབ་ཁྲལ་ཚུ་གིས་ མ་དངུལ་ཀྱི་འཐུས་མ་སྤྲོད་ནི་དང་ ཉེན་སྲུང་གི་འཛོལ་བ་ཡང་ མཁོ་སྒྲུབ་འབད་མི་ཚུགས་ཡོདཔ་ཨིན། བརྗེ་སོར་འབད་ནི་དང་ བསྒྱུར་བཅོས་ག་ཅི་ར་ཨིན་རུང་ ངོས་འཛིན་, ལག་ལེན་ཅན་གྱི་བཅའ་ཡིག་, གསལ་སྟོན་འབད་མི་ ས་སྒོ་, ཐོ་བཀོད་དང་ དོན་དངོས་སུ་སྦེ་ལག་ལེན་འཐབ་དགོཔ་ཨིན།

`χ` གིས་ དངུལ་ཕོགས་ཐོབ་ཐོའི་ཆ་ཤས་ཅིག་ཨིནམ་ལས་ སྲིད་བྱུས་བཀག་དམ་དང་ བསྒྱུར་བཅོས་མ་བྱུང་པའི་ཤུལ་ལུ་ ཏི་རུ་ལོག་སྤྱོད་འབད་ཚུགསཔ་ཨིན།

F_cash ≈ χ · F

འཆར་དངུལ་དང་ བཀྲམ་སྤེལ་གྱི་བརྟག་དཔྱད་དེ་ འགྲུབ་ཚུགས་པའི་ `F_cash` ལག་ལེན་འཐབ་ནི་ཨིནམ་ལས་ ནང་འཁོད་ཐོ་ཡིག་གི་འཐུས་ (gross quoted fees) ཡང་ན་ རང་བཞིན་གནས་གོང་ཀྱི་ གནས་གོང་མེདཔ། མ་འོངས་པ་ལུ་ ལས་རིམ་ཅིག་ནང་ གྲོང་གསེབ་ཁྲལ་ (Gross Pool fee) ཚུ་ སྙན་ཞུ་འབད་ནི་ཨིན་ དེ་ལས་ ཡོངས་འབྲེལ་འབྱུང་ཁུངས་ཐོབ་ཐངས་ (network-rake receipts), ཞབས་ཏོག་གླ་ཆ་ (service fees), རྒྱུ་དངོས་བཟོ་དབྱིབས་ (asset composition), བསྒྱུར་བཅོས་ཐོན་སྐྱེད་ (conversion results) དང་ ཏི་རུ་རྒྱུན་སྤྱོད་འབད་བཏུབ་མི་ ཐོབ་ཐངས་འདི་ཚུ་སོ་སོ་སྦེ་ སྙན་སྟོན་འབདཝ་ཨིན།
