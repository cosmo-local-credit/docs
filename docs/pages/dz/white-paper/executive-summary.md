# འགོ་འཁྲིདཔ་དང་པའི་བཅུད་བསྡུད་

** ཁེ་བསང་བསྡུ་གསོག་འབད་ནི་གི་ཁྲིམས་ལུགས་(CPP)**འདི་གིས་ རང་དབང་གི་ཐོག་ལས་འཛིན་སྐྱོང་འཐབ་མི་ ཁས་ལེན་མཉམ་སྤྱོད་དངུལ་ཁུངས་ཚུ།འདི་གིས་ ག་དེ་འབད་ བརྗེ་སོར་འབད་བཏུབ་པའི་ ཁེ་ཕན་ཚུ་བདག་འཛིན་འབད་ཚུགས་ནི་དང་ སྒྱུར་རྩིས་ཀྱི་གནས་ཚད་ཀྱི་ཐབས་ལམ་དང་ཚད་གཞི་དཔར་བསྐྲུན་འབད་ནི་ དེ་ལས་ ཅ་ཆས་ཚུ་བཞག་སྟེ་ འགན་ཁུར་འབག་ནི་ལ་སོགས་པ་ཚུ་གསལ་བཀོད་འབདཝ་ཨིན། ཐོན་སྐྱེད་འབད་མི་ཚུ་གིས་ ཁོང་རའི་དངུལ་འབྲེལ་གྱི་ཁེ་ཕན་ཚུ་ལུ་ འགན་ལེན་འབད་དགོཔ་ཨིན། མཉམ་སྤྱོད་དངུལ་ཁུངས་ཀྱི་འཛིན་སྐྱོང་པ་ཚུ།འདི་གིས་ སྡེ་ཚན་གྱི་ཁྲིམས་ལུགས་དང་ ཁོང་གི་ངོས་ལེན་འབད་མི་ འགན་སྲུང་ག་ཅི་བཟུམ་ཅིག་འབད་རུང་ འགན་ལེན་འབད་དགོཔ་ཨིན། CLC Appདང་GEFགཉིས་ཆ་ར་ སྤྱིར་བཏང་གི་འགན་འཛིན་མེན།

Protocol v1.1.0 གིས་ ད་རེས་ནངས་པའི་ ཐད་ཀར་དུ་འགྱུར་བཅོས་འབད་ནི་གི་ སྒྲིང་ཁྱིམ་བཟོ་བཀོད་ཚུ་བྱིན་དོ་ཡོདཔ་ཨིན། `GiftableToken` དང་ `SwapPool` གདམ་ཁ་རྐྱབ་ཚུགས་པའི་ཐོ་གཞུང་དང་ བརྩི་མཐོང་མུ་མཐུད་དང་ པོ་ལི་ཀྲོ་ཀེན་ཁེ་འབབ་ཀྱི་ཚད་གཞི་ པོ་ལིས་ཀྱི་ཁྲལ་ ཁྲིམས་ལུགས་ཁ་སྐོང་གི་ཁྲལ་དང་ quotation-only Solidity `SwapRouter` བཟོ་བསྐྲུན་CLC App དང་སི་ཨེལ་ཨེསི་ཀོར་ཟེར་མི་འདི་གིས་ ད་རེས་ནངས་པར་ སྡེ་ཚན་གསུམ་ལས་ལྷག་སྟེ་ ལམ་རིམ་ཅོག་འཐདཔ་སྦེ་འཚོལ་ཞིབ་འབད་དོ་ཡོདཔ་མ་ཚད་ བགོ་བཤའ་རྐྱབ་ཏེ་ཡོད་མི་ཚུ་ཡང་བཏོན་དོ་ཡོདཔ་མས། ཆིངས་ཡིག་ནང་ལུ་ ད་རེས་ནངས་པའི་གནས་སྟངས་ཀྱི་གྲུབ་འབྲས་ཚུ་ཐོ་བཀོད་འབད་དེ་མེདཔ་དང་ འཕྲུལ་རིག་གི་ཐོག་ལས་ དངུལ་འབྲེལ་གྱི་ཞབས་ཏོག་སྤྲོད་མི་ཚུ་གི་ བགོ་བཤའ་བཟོ་ནི་དང་ ཀོརསི་ཅེན་རེའུ་ཀྲི་གི་ལམ་རིམ་བཟོ་ནི་ ཡང་ན་ བེཆ་ནེ་ཊིང་འབད་ནི་ དེ་ལས་ སྤྱིར་བཏང་གི་བཀག་ཆ་དང་ འགན་སྲུང་ ཡང་ན་ ཉེན་སྲུང་བྱིན་ནི་ལ་སོགས་པ་ཚུ་ཡོདཔ་ཨིན།

འ་ནི་ཨང་གྲངས་ཚུ་ ཚད་འཇལ་ནི་གི་སྒོ་སྒྲིག་ཅིག་གི་དོན་ལས་ དྲེསི་བཱོཌ་གི་དཔར་བསྐྲུན་འབད་དེ་ཡོད་མི་མིང་རྟགས་ཚུ་ཨིན་མས། “ལག་ལེན་པ་”, “ལཱ་འབད་མི་”, “འཕོ་སོར་” དེ་ལས་ པཱུལ་ཨིསི་ཝེབ་ཀྱི་འབོར་ཚད་ནང་ལུ་ ཨེ་ཡུ་ཨེསི་གི་བསྒྱུར་བཅོས་འདི་ དཀའ་ངལ་བསལ་ཐབས་དང་ བརྩི་མཐོང་གི་ཐབས་ལམ་ལུ་རག་ལས་དོ་ཡོདཔ་དང་ འདི་ཚུ་ག་ར་ སྤྱིར་བཏང་ཨེསི་ཨེལ་སི་ཀི་པི་ཨའི་ངེས་ཚིག་བཟུམ་མེན་པས། འ་ནི་གཏན་མཛོད་འདི་གིས་ གནས་སྡུད་བསྡུ་གསོག་འབད་མི་འདི་ རང་དབང་གི་ཐོག་ལས་ ལོག་སྟེ་རྩིས་བཏོན་མི་ཅིག་མེན་པས། བསྐྱར་ལག་ལེན་འཐབ་མི་ག་ཅི་བཟུམ་ཅིག་འབད་རུང་ དུས་ཚོད་དང་ འབྱུང་ཁུངས་ཀྱི་འབྲེལ་བ་ རྟགས་མཚན་ དེ་ལས་ བྱུང་རབས་ཀྱི་ཁྱད་ཚད་ཚུ་ ཉམས་སྲུང་འབད་ནི་འདི་ཨིན། [ ཁ་སྐོང་ཨེསི་] (/white-paper/appendix-c-kpi-definitions) ནང་ལུ་གྲོས་འཆར་བཀོད་མི་གི་འཇལ་ཚད་དགོས་མཁོ་འདི་ མ་འོངས་སྙན་ཞུ་ཚུ་གི་དོན་ལས་ གནམ་མེད་ས་མེད་ཁག་ཆེ་ཤོས་ཅིག་ཨིན་མས།
