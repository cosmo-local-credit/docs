# C. གྲོས་འཆར་ KPI གི་འགྲེལ་བཤད་ཚུ་

འ་ནི་ KPI ཚུ་གིས་ གྲོས་འཆར་ཅན་གྱི་ཚད་འཇལ་ཐོ་བཀོད་བཟོ་དོ་ཡོདཔ་ལས་ ད་ལྟོའི་ App ཡང་ན་ Protocol གིས་ དགོས་མཁོ་ཅན་བྱུང་རྐྱེན་ཆ་མཉམ་ ཐོ་བཀོད་ཀྱི་གསལ་སྒྲགས་མེན་པས།

དཔར་བསྐྲུན་འབད་མི་ KPI འདི་ནང་ལུ་:

- འབྲེལ་ཡོད་གསལ་སྒྲགས་འབད་མི་དང་ གནད་སྡུད་འབྱུང་ཁུངས་
- འབྱུང་རྐྱེན་ ཡང་ན་ གནས་སྟངས་ཀྱི་འགྲེལ་བཤད་;
- ཚད་འཇལ་ནིའི་དུས་ཡུན་ ཡང་ན་ བརྟག་ཞིབ་ཀྱི་དུས་ཚོད་;
- ཡུ་ནིཊ་དང་ དངུལ་རྩིས་ཀྱི་ ཐབས་ལམ་;
- ཚད་འཛིན་གྱི་དུས་ཚོད་ཐིག་ཁྲ།
- བཅའ་ཡིག་དང་ སྒྲིག་གཞི་ཚུ་
- གནད་དོན་ཁག་ཆེ་ཤོས་དང་ སྐྱོན་བརྗོད་ཅན་གྱི་ ཡིག་ཆ་ཚུ་ བསྐྱར་ཞིབ་འབད་དགོཔ་ཨིན།
- དགོས་མཁོ་ཅན་གྱི་ རྒྱང་སྒྲིལ་གྱི་ཕྱི་ཁར་ཡོད་པའི་ གསལ་སྟོན་དང་ལག་ཁྱེར་ཚུ་
- བསྐྱར་ཞིབ་ཀྱི་ལོ་རྒྱུས་དང་ གནས་སྡུད་གི་གནས་ཚད་ལུ་ ཐོ་ཕོག་མི་ཚུ་; དེ་ལས་
- གྲུབ་འབྲས་དེ་ ལྕགས་ཐག་ནང་ཡོད་མེད་དང་ སྙན་ཞུ་འབད་ཡོདཔ་ཨིན་ན་ ཡང་ཅིན་ བདེན་ཁུངས་བཀལ་ཡོདཔ་ཨིན་ན་ ཡང་ན་ རང་དབང་གིས་བརྟག་ཞིབ་འབད་དེ་ བརྟག་དཔྱད་འབད་མི་ཡང་ན་ གཏང་བཀོད་འབདཝ་ཨིན།

| **ངོས་འཛིན་ཅན་གྱི་ གྲུབ་མཐའ་ཚུ་** | དུས་ཡུན་ཅིག་ནང་ དངུལ་ཁང་གི་ཕྱིར་བཏོན་གྱི་ བྱ་རིམ་ནང་ལུ་ འཛུལ་ཞུགས་འབད་ཡོད་པའི་ ཨང་གྲངས་དང་ ཡན་ལག་ཚུ་ | ངོ་སྤྲོད་གི་ངོ་རྟགས་དང་ ཨེམ་སི་ཊི་ཡཱན་ དེ་ལས་ ལག་ལེན་གྱི་ཆོག་ཐམ་ དངུལ་ཕོགས་ དུས་ཚོད་ གནས་སྟངས་ ཐོ་བཀོད་འབད་མི་ཚུ་ ཆ་མེད་གཏང་ནི་ |
| **བསྒྲུབ་ཐབས་ཀྱི་གོང་ཚད་** | བསྡུ་སྒྲིག་འབད་ཡོད་པའི་གནས་གོང་ཚུ་ དབྱེ་བ་ཕྱེ་སྟེ་ སྐྱེ་ལྡན་སྡེ་ཚན་གཅིག་གི་དོན་ལུ་ གནས་གོང་ཅན་གྱི་གནས་གོང་ཨིན། | ཨེམ་ཏི་ཡེར་གྱི་གྲུབ་འབྲས་དང་འབྲེལ་བའི་ གནད་དོན་ཁག་ཆེ་ཤོས་ཚུ་ སྙན་ཞུ་འབད་དགོ |
| **ཐོ་བཀོད་མཇུག་བསྡུ་ནི་** | གྲུབ་འབྲས་ཚུ་ མཇུག་བསྡུ་ཡོདཔ་དང་ ཆ་མེད་གཏང་པའི་ཐོ་ཡིག་འདི་ བསྡུ་སྒྲིག་འབད་ཡོད་པའི་ནང་འཁོད་ལུ་བགོ་བཤའ་རྐྱབ་ཡོདཔ་ཨིན། | མཚམས་འཇོག་འབད་ནི་དང་ ཆ་མེད་གཏང་ནི་ དེ་ལས་ ལག་ལེན་མ་བཏུབ་པའི་ གནད་དོན་གཞན་ཚུ་ |
| **བསྒྲུབ་ནིའི་དུས་ཡུན་** | གྲུབ་མཐའ་དང་ བརྒྱ་ཆ་༩༠ པ་ཚུ་ མཇུག་བསྡུ་ནིའི་དུས་ཚོད་ | ཕྱིར་བཏོན་འབད་ནི་དང་ ཉོ་ཚོང་འཐབ་ནི་ཚུ་ བསྒྱུར་བཅོས་མ་འབད་ |
| **འཛིན་སྐྱོང་གི་དུས་ཡུན་** | ཚད་འཛིན་དང་ བཀྲམ་སྤེལ་འབད་ཐངས་ཚུ་ | ཉོ་ལེན་གྱི་བྱུང་རྐྱེན་ཚུ་ ངོས་འཛིན་འབད་ཞིནམ་ལས་ ཤེས་རྟོགས་མེད་པའི་ ཉོ་གཏུགས་ཀྱི་དུས་ཚོད་ཚུ་ ཕྱི་ཁར་བཏོན་དགོ། |
| **འོས་འབབ་ཅན་གྱི་ ཁས་བླངས་མ་དངུལ་ཚུ་** | འོས་འབབ་ཅན་གྱི་ གསུམ་པ་གི་ ཁས་བླངས་ཚུ་ ངེས་གཏན་འབད་མི་ བཀག་ཆ་ཚུ་གི་ཤུལ་ལས་ བཞག་ཚུགསཔ་ཨིན། | ཕྱིར་བཏོན་མི་གི་ངོ་རྟགས་དང་ གནས་སྟངས་; འཁྲུན་ཆོད་མཇུག་བསྡུ་ནི་, མཚམས་འཇོག་འབད་ནི་, ཐོ་བཀོད་འབད་དགོཔ་དང་ བརྟག་དཔྱད་འབད་ནི་ དེ་ལས་ ཁས་བླངས་མ་འབད་མི་ tokensཚུ་ ཆ་མེད་གཏང་དགོ། |
| **ཐད་ཀར་དངུལ་ཁང་གི་གན་ཡིག་བརྗེ་སོར་གྱི་ཚད་གཞི་** | གནས་གོང་གསལ་བཀོད་འབད་ཡོད་པའི་ རིན་ཐང་གི་ཐབས་ལམ་ཅིག་ལུ་བརྟེན་ མཉམ་སྡེབ་ཀྱི་ཚོང་འབྲེལ་སྦེ་འགོ་བཙུགས་མི་ བརྗེ་སོར་གྲུབ་པའི་རིན་གོང་། | ཐིག་ཁྲམ་ནང་ཐོ་བཀོད་འབད་ཡོད་པའི་གན་རྒྱ་ཚུ་ ཚད་གཞི་འབྱུང་ཁུངས་དང་ དུས་ཚོད་ལུ་རྩིས་སྟོན་མ་འབད་ |
| **ལམ་འཚོལ་ནིའི་ཐབས་ལམ།** | དུས་ཡུན་ཅིག་གི་རིང་ལུ་ འཐོབ་ཚུགས་པའི་ འཛིན་ཤོག་ཚུ་དང་ ཡང་ན་ ངོས་ལེན་འབད་ཡོད་པའི་ལམ་འཚོལ་ནིའི་དོན་ལས་ ནུས་ལྡན་གྱི་ ཞུ་ཡིག་ཚུ། | ཌའི་ལོག་གི་རྣམ་པ་, ཨང་བཏགས་ཡོད་པའི་སྒྲོམ་, གསརཔ་སྦེ་རང་ཡོད་, ཡན་ལག་ཡིག་ཚང་གི་ཁྱབ་ཚད་, དགོས་མཁོ་ཅན་གྱི་གཏིང་རིམ། དོ་འགྲན་འབད་མི་གྱངས་ཁ་ ཡང་ན་ བརྟག་ཞིབ་འཆར་དངུལ་གྱི་གནས་སྟངས་; ངེས་བདེན་ཨིན་པའི་བཀོད་རྒྱ་མེན། |
