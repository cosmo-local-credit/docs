## **6. གྲོས་འཆར་ཅན་གྱི་དྲ་ལམ་གི་གནས་ཚད་ནང་ ལི་ཀིཌ་ཊེཀ་དང་ གཞུང་སྐྱོང་**

བྱུང་རབས་ཀྱི་ Sarafu Network ལས་ཐོབ་མི་ཉམས་མྱོང་འདི་གིས་ བཟོ་བཀོད་གི་དྲི་བ་སྦོམ་གཉིས་ལུ་ བརྟག་ཞིབ་འབད་ནི་ལུ་ སེམས་ཤུགས་བསྐྱེད་ཡོདཔ་ཨིན།

1. རང་རང་སོ་སོར་སྦེ་ གཞུང་སྐྱོང་འབད་མི་སྡེ་ཚན་ཚུ་གིས་ ལི་ཀའིན་ཌིཊ་དང་ རུ་ཊའི་གི་ཞབས་ཏོག་ཚུ་ ག་དེ་སྦེ་ གཅིག་སྒྲིལ་འབད་ཚུགས་ནི་ཨིན་ན; དེ་ལས་
2. མཉམ་འབྲེལ་གྱི་ཞབས་ཏོག་ཚུ་ གྱངས་ཁ་ཡར་སེང་འགྱོ་བའི་བསྒང་ལས་ འགན་འཁྲི་འབག་ནི་དེ་ ག་དེ་སྦེ་ར་ བཞག་ཚུགསཔ་ཨིན་ན?

གྲོས་འཆར་ CLC བཟོ་བཀོད་ཅིག་གིས་ **གྲོས་འཆར་བཀོད་ཡོད་པའི་ CLC Network Pool ** གྲྭ་ཚང་གི་གནས་ཚད་ཀྱི་གཙང་སྦྲ་དང་ འཆར་དངུལ་ཚུ་ མཉམ་འབྲེལ་འབད་ནིའི་མཐུན་རྐྱེན་ཅིག་ཨིནམ་ད་ ** གྲོས་འཆར་ཅན་གྱི་ CLC གཞུང་སྐྱོང་གི་བརྡ་མཚོན་**ད་ལྟོའི་ App ཡང་ན་ Protocol v1.1.0ནང་ལུ་མེད་ འབྲེལ་ཡོད་ལག་ལེན་གཞན་ཚུ་གིས་ མཉམ་ལས་ཚོགས་སྡེ་དང་ གཞུང་གི་ཡིག་ཚང་ དེ་ལས་ཞལ་འཛོམས་ དེ་ལས་ ལས་སྣ་མང་ཤོས་ཅིག་ ཞབས་ཏོག་འཛིན་སྐྱོང་འཐབ་མི་ ཡང་ན་ རྩིས་སྤྲོད་འབད་ཚུགས་པའི་ སྒྲིག་གཞི་གཞན་ཚུ་ ལག་ལེན་འཐབ་སྟེ་འབད་རུང་ གྲོས་འཆར་དེ་ ཆ་འཇོག་མ་འབད་བར་བཞག་ཡོདཔ་ཨིན།

### **6.1 downside controls དང་ གདམ་ཁ་རྐྱབས།**

ད་ལྟོའི་ Protocol v1.1.0གིས་ Pool token balances caps དང་ inventory checks ལག་ལེན་འཐབ་ཚུགས། འ་ནི་ཚད་འཛིན་འདི་ཚུ་གིས་ གདམ་ཁ་ཅན་གྱི་གན་ཡིག་གི་བྱ་རིམ་ཚུ་ བཀག་ཆ་འབད་དོ་ཡོདཔ་ཨིན། འདི་ཚུ་གིས་ emitter གྱི་གྲུབ་འབྲས་མ་ཐོན་པའི་ཧེ་མར་ དངུལ་ཕོགས་རློག་གཏང་ནི་དང་ key loss ཡང་ན་ contract failure དེ་ལས་གཞན་ཡང་མེདཔ་ཐལ་འགྱོ་ནི་ལས་བཀག་མི་ཨིན།

མ་འོངས་པ་ལུ་ གཞི་བཙུགས་འབད་ནི་དེ་གིས་ གློག་ཐག་ར་བ་ མགྱོགས་དྲགས་སྦེ་ བཏོན་གཏང་ནི་དང་ དུས་ཚོད་བཀག་ནི་ དེ་ལས་ ཉེན་སྲུང་དང་རྒྱབ་སྐྱོར་ཚུ་ བཙུགས་དགོཔ་ཨིན། སྲུང་སྐྱོབ་ཀྱི་དོན་ལས་ འགན་འཁྲི་འབག་མི་ ངོ་ཤེས་ཅན་ཅིག་ དགོངསམ་ཨིན་པའི་ཁར་ འབྱུང་རྐྱེན་ཚུ་གི་དོན་ལུ་ རྒྱབ་སྐྱོར་འབད་དགོ་པའི་ ཁེ་ཕན་ཡོདཔ་མ་ཚད་ དངུལ་ཕོགས་ཚུ་ཡང་ བཀག་ཆ་འབད་དགོཔ། ཟད་འགྲོ་བཏང་དགོཔ། དུས་ཡུན་འགོར་དགོཔ། དཔྱད་ཡིག་བཏུབ། ཐོབ་སྐལ་གྱི་ བྱ་རིམ་དང་ གནས་སྟངས་དང་འཁྲིལ་ཏེ་ཨིན་མས།

གཞུང་སྐྱོང་འཆར་གཞིའི་ནང་ ཐོ་བཀོད་དང་ ཞབས་ཏོག་གི་དབང་ཤུགས་ཚུ་ དུམ་གྲ་ཅིག་སྦེ་བཞག་ནི་དང་ བསྐྱར་ཞིབ་འབད་ཚུགསཔ་བཟོ་དགོཔ་ཨིན། སྤྱིར་བཏང་བྱ་རིམ་ཚུ་གིས་ དྲན་གསོའི་གསལ་སྒྲགས་, མཚམས་འཇོག་, གནད་དོན་སྙན་བསྒྲགས།, མཐོ་གཏུགས་འབད་ནི་དང་ བཅོ་ཁ་ཐེག་པའི་ བྱ་རིམ་ཚུ་ལག་ལེན་འཐབ་ཚུགས། དགོས་མཁོ་ཅན་གྱི་བྱ་རིམ་གྱིས་ རྐྱེན་ངན་གྱི་ཐོ་ཡིག་བཏོན་ཏེ་ དུས་ཡུན་ཚང་བའམ་ ཆ་འཇོག་གྲུབ་མི་ སྲིད་བྱུས་དང་འཁྲིལ་ བསྐྱར་བཅོས་ཐོབ་དགོ།

བསྡུ་ལེན་ལམ་ལུགས་མཐུན་རྐྱེན་གྱིས་ Pools གི་ནང་འཁོད་ལུ་ འབྲེལ་གཏད་མང་རབས་ཅིག་འབད་ཚུགས་ནི་ཨིན་མས། Multi-hop ལག་ལེན་འཐབ་ནི་དང་ netting འདི་གི་དོན་ལུ་ ད་རུང་མཉེན་ཆས་དང་ ངོས་འཛིན་ དེ་ལས་ཚད་གཞི་ཚུ་ དགོཔ་ཨིན་པའི་ཁར་ འཛོལ་བ་ལག་ལེན་འབད་ནི་དང་ གཞུང་སྐྱོང་ཡང་ དགོངསམ་ཨིན། གོང་གསལ་སྦེ་བཀོད་མི་ ཡང་ན་ འགོ་བཙུགས་འབད་མི་ swaps དེ་ཚུ་གིས་ རང་གིས་རང་ལས་ ཁས་བླངས་ཀྱི་གྲུབ་འབྲས་དང་ མི་སྡེ་ལུ་ ཕན་ཐོགས་འབྱུང་མི་ཚུགས་པས།
