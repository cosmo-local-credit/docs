# འགོ་བཙུགས་ནི་

Cosmo-Local Credit (CLC) གིས་ མི་ཚུ་གིས་ག་ཅི་བྱིན་ཚུགསཔ་ཨིན་ན་བཤད་ནི་ ག་ཅི་དགོཔ་ཨིན་ན་གསལ་བསྒྲགས་འབད་ནི་དང་ རང་སོའི་སྐྱོང་སྲིད་ཡོད་མི་ཁས་ལེན་མཉམ་སྤྱོད་དངུལ་ཁུངས་བརྒྱུད་དེ་འཛིན་ཤོག་བརྗེ་སོར་འབད་ནི་ལུ་ཕན་ཐོགས། འགོ་བཙུགས་ནི་ལུ་ [CLC App](https://cosmolocal.credit) ཁ་ཕྱེ།

གཞི་རྩའི་བསམ་གཞི་འདི་འཇམ་ཏོང་ཏོ་ཨིན།

1. ཁྱོད་ཀྱིས་བྱིན་ཚུགས་པའི་ཅ་ཆས་ཡང་ན་ཞབས་ཏོག་དོན་ལུ་ གསོལ་རས་ཤོག་བྱང་བཟུམ་མའི་འཛིན་ཤོག་བཟོ།
2. མི་ཚུ་གིས་འབྲེལ་ཡོད་ཅ་ཆས་དང་ཞབས་ཏོག་འཚོལ་ཚུགས་ནི་ལུ་ འབུལ་བའི་ཐོ་ (Offering) གསལ་བསྒྲགས་འབད།
3. བརྗེ་སོར་གྱི་ཆ་རོགས་འཚོལ་ནི་ལུ་ དགོས་མཁོ་ (Want) གསལ་བསྒྲགས་འབད་ ཡང་ན་འདི་ལུ་ལན་བྱིན།
4. གསལ་བསྒྲགས་འབད་མི་ལམ་ལུགས་འོག་ལུ་ ངོས་ལེན་འབད་མི་འཛིན་ཤོག་བརྗེ་སོར་འབད་ནི་ལུ་ ཁས་ལེན་མཉམ་སྤྱོད་དངུལ་ཁུངས་ལག་ལེན་འཐབ།
5. གནས་ཚིག་ནང་ཁས་བླངས་པའི་ཅ་ཆས་ཡང་ན་ཞབས་ཏོག་དོན་ལུ་ གསར་བཏོན་པ་ལུ་འཛིན་ཤོག་ལག་ལེན་འཐབ།

གློག་རིམ་ནང་གི་ “ཡིད་རྟོན།” (Credit) གིས་ ངོས་ལེན་འབད་མི་ཁས་ལེན་དང་འཛིན་ཤོག་བརྗེ་སོར་གྱི་ནུས་པ་ལུ་གོཝ་ཨིན། འདི་རང་བཞིན་གྱིས་སྒེར་གྱི་བུ་ལོན་ བུ་ལོན་ལེན་ནིའི་ཚད་ཡང་ན་དངུལ་སྔོན་བྱིན་གྱི་ཁས་ལེན་མེན།

ངེས་ཚིག་ཆ་ཚང་དོན་ལུ་ [གོ་དོན་དང་ཚིག་མཛོད](/dz/introduction/concepts) ལྷག།

## གློག་རིམ་ནང་འགོ་དང་པའི་རིམ་པ་

### 1. ཚོང་ར་དང་དགོས་མཁོ་བལྟ་ནི་

ག་ཅི་ཡང་མ་བཟོ་བའི་ཧེ་མ་ [CLC App](https://cosmolocal.credit) བལྟ། **ཚོང་ར།** འདི་འཚོལ་ཞིབ་ཀྱི་ཐོ་གཞུང་ཨིན། འདི་རང་བཞིན་གྱིས་བཙོང་མི་ བརྗེ་སོར་ས་གནས་ རྒྱབ་སྣོན་ཡང་ན་འགན་ལེན་མེན།

འཛིན་ཤོག་བསྐྱར་ཞིབ་འབདཝ་ད་ འོག་གི་གནད་དོན་ཚུ་བལྟ།

- ག་གིས་གསར་བཏོན་འབད་ཡོདཔ་ཨིན་ན།
- ཅ་ཆས་ཡང་ན་ཞབས་ཏོག་ག་ཅི་ཁས་བླངས་ཡོདཔ་ཨིན་ན།
- ག་ཏེ་ ནམ་དང་ག་དེ་སྦེ་ལག་ལེན་འཐབ་ཚུགས་ནི།
- ཚད་ དུས་ཡུན་ འབྲེལ་བ་འཐབ་ཐངས་དང་ཉོག་བཤད་བྱ་རིམ།
- མཉམ་སྤྱོད་དངུལ་ཁུངས་ག་གིས་ངོས་ལེན་འབདཝ་ཨིན་ན།

**དགོས་མཁོ་ (Want)** གིས་ག་ཅི་དགོཔ་ཨིན་ན་སྟོནམ་ཨིན། འདི་གསལ་བསྒྲགས་འབད་ནི་ཡང་ན་ལན་བྱིན་ནི་གིས་ འཛིན་ཤོག་ངོས་ལེན་ ཅ་ཆས་བཀག་བཞག་ བརྗེ་སོར་གནང་བ་ཡང་ན་འགན་ཁུར་རང་བཞིན་གྱིས་མི་བཟོ། གཞན་ལུ་འབྲེལ་བ་འཐབ་ནི་ཡང་ན་འཕྲིན་བཏང་ནི་གིས་རྐྱངམ་ཅིག་ འཛིན་ཤོག་གི་ཁས་ལེན་བཟོ་ནི་ བསྒྲུབ་ནི་ཡང་ན་མཇུག་བསྡུ་ནི་མི་འབད།

### 2. རྩིས་ཐོ་དང་དངུལ་ཁུག་བཟོ་ནི་ཡང་ན་འཛུལ་ནི་

གློག་རིམ་གྱིས་ རང་དོན་གསལ་བཤད་དང་འཛུལ་ཞུགས་ཀྱི་དོན་ལུ་རྩིས་ཐོ་ལག་ལེན་འཐབ་ཨིན། **དངུལ་ཁུག** འདི་ blockchain གི་གནང་བ་དོན་ལུ་ཨིན། ཁྱོད་ཀྱི་ passkey ཤོག་བྱང་དངུལ་ཁུག་གི་རྒྱུ་ཆ་ སླར་གསོ་བརྡ་དོན་ འཕྲུལ་ཆས་དང་ངོ་རྟགས་གཞན་ཚུ་སྲུང། སྤྲོད་ལེན་ངེས་གཏན་མ་བཟོ་བའི་ཧེ་མ་ ཁ་བྱང་ རྒྱུ་དངོས་ གྲངས་འབོར་ དངུལ་ཁུངས་ གླ་འཐུས་དང་གནང་བ་ག་ར་བསྐྱར་ཞིབ་འབད།

གློག་རིམ་ནང་འགོ་དང་པ་འཛུལཝ་དང་ འཛིན་ཤོག་ཡང་ན་དངུལ་ཁུངས་གསལ་བསྒྲགས་མ་འབད་བའི་ཧེ་མ་ གནས་ཚིག་ངེས་གཏན་བཟོ་དགོ་ཟེར་སླབ་ཨིན། མ་འཕྲོ་མཐུད་པའི་ཧེ་མ་ [ཞབས་ཏོག་གི་ཁ་ཚིག](/dz/governance/terms) དང་ [སྒེར་དོན་བརྡ་བསྐུལ](/dz/governance/privacy) ལྷག།

### 3. འཛིན་ཤོག་དང་འབུལ་བའི་ཐོ་བཟོ་ནི་

ཁྱོད་ཀྱིས་ངོ་མ་སྦེ་བྱིན་ཚུགས་པའི་ཅ་ཆས་ཡང་ན་ཞབས་ཏོག་དོན་ལུ་འཛིན་ཤོག་བཟོ། རང་གི་གསོལ་རས་ཤོག་བྱང་བཟོ་དོ་བཟུམ་སྦེ་ འདི་གིས་ག་ཅི་སྟོནམ་ཨིན་ན་དང་ལག་ལེན་གྱི་གནས་ཚིག་བཤད་དགོ།

འཛིན་ཤོག་ཆ་ཚང་ནང་ བང་རིམ་སོ་སོ་ཡོད།

1. ཊོ་ཀེན་གན་རྒྱའི་ལག་ལེན་དང་ལྷག་ལུས།
2. གསར་བཏོན་པ་གིས་གསལ་བསྒྲགས་འབད་མི་འཛིན་ཤོག་གནས་ཚིག།
3. འབྲེལ་ཡོད་ཅ་ཆས་ཡང་ན་ཞབས་ཏོག་བཤད་མི་ **འབུལ་བའི་ཐོ་ (Offering)** གཅིག་ཡང་ན་ལེ་ཤ།
4. གསར་བཏོན་པ་གིས་འཛམ་གླིང་ངོ་མ་ནང་ཁས་ལེན་སྒྲུབ་ནི།

ཊོ་ཀེན་བཟོ་ནི་ཡང་ན་གསར་བཏོན་འབད་ནི་གིས་ འབུལ་བའི་ཐོ་ཡོད་ཟེར་ གསར་བཏོན་པ་ལུ་ནུས་པ་ཡོད་ཟེར་ ཡང་ན་ Grassroots Economics Foundation (GEF) གིས་ཁས་ལེན་སྒྲུབ་ནིའི་འགན་ལེན་འབག་ཡོད་ཟེར་མི་སྒྲུབ།

### 4. དགོས་མཁོ་གསལ་བསྒྲགས་འབད་ནི་ཡང་ན་ལན་བྱིན་ནི་

དགོས་མཁོ་ནང་ ཁྱོད་ཀྱིས་འཚོལ་མི་དང་ གྲངས་འབོར་ ས་གནས་ དུས་ཚོད་དང་འབྲེལ་བ་འཐབ་ཐངས་འོས་འབབ་ཅན་བཀོད། བཅའ་མར་གཏོགས་མི་གཞན་གྱིས་འདི་མཐོང་སྟེ་ ཁྱོད་ཀྱི་མི་མང་ལུ་སྟོན་མི་འཛིན་ཤོག་དང་འབུལ་བའི་ཐོ་བསྐྱར་ཞིབ་འབད་དེ་ འབྲེལ་བ་འཐབ་ནི་ཨིན་ན་ཐག་བཅད་ཚུགས།

གྲོས་བསྟུན་དང་འགན་ཁུར་གསལ་ཏོག་ཏོ་བཞག། འཕྲིན་གྱིས་ཅ་ཆས་སྐྱེལ་ནི་ སྔོན་བཀག་དང་གནད་དོན་གཞན་ལུ་གྲོས་འཆམ་བཟོ་ནི་ལུ་ཕན་ཐོགས། ཨིན་རུང་ ཁས་ལེན་འདི་ འཇུག་མི་འཛིན་ཤོག་གནས་ཚིག་དང་སོ་སོ་སྦེ་གྲོས་འཆམ་བཟོ་མི་སྤྲོད་ལེན་གནས་ཚིག་གིས་ཐག་བཅདཔ་ཨིན།

### 5. ཁས་ལེན་མཉམ་སྤྱོད་དངུལ་ཁུངས་འཚོལ་ནི་ཡང་ན་བཟོ་ནི་

ཁས་ལེན་མཉམ་སྤྱོད་དངུལ་ཁུངས་ཀྱིས་ འཛིན་ཤོག་གདམ་ཁ་རྐྱབ་སྟེ་བརྗེ་སོར་འབད་ཚུགསཔ་བཟོཝ་ཨིན། ལག་ལེན་འཐབ་ནི་ཡང་ན་རྒྱབ་སྐྱོར་མ་འབད་བའི་ཧེ་མ་ འོག་གི་གནད་དོན་ཚུ་བསྐྱར་ཞིབ་འབད།

### 7. གསར་བཏོན་པ་ལུ་འཛིན་ཤོག་ལག་ལེན་འཐབ་ནི་

## འགན་ཁུར་དང་ཁག་ཆེ་བའི་ཚད་

[Grassroots Economics Foundation](https://grassrootseconomics.org/about/) གིས་གློག་རིམ་དང་རྒྱབ་སྐྱོར་གཞི་རྟེན་ལག་ལེན་འཐབ་ཨིན། GEF གིས་སྤྲོད་ལེན་དམིགས་བསལ་དོན་ལུ་འགན་ཁུར་གཞན་ལེན་ནི་གསལ་རི་རི་སྦེ་ཁས་ལེན་མ་འབད་བར་ འདི་ལག་ལེན་པ་གི་འཛིན་ཤོག་གསར་བཏོན་པ་ དངུལ་ཁུངས་ཀྱི་འཛིན་སྐྱོང་པ་ རྒྱུ་དངོས་བདག་གཉེར་པ་ བུ་ལོན་བྱིན་མི་ བུ་ལོན་ལེན་མི་ འགན་ལེན་པ་ ཉེན་བཅོལ་པ་ཡང་ན་འཛིན་ཤོག་ལོག་ལེན་མི་མེན།

སྤྲོད་ལེན་མ་འབད་བའི་ཧེ་མ་ འོག་གི་གནད་དོན་སེམས་ཁར་བཞག།

- གནས་ཚིག་གི་ལོ་ཚད་ ཁྲིམས་ཀྱི་ནུས་པ་དང་ས་ཁོངས་དགོས་མཁོ་ཚུ་ཚང་དགོ།
- གསར་བཏོན་པ་ཚུ་རང་སོའི་འཛིན་ཤོག་ཁས་ལེན་ལུ་འགན་ཁུར་ཡོད།
- འཛིན་སྐྱོང་པ་ཚུ་རང་སོའི་གསལ་བསྒྲགས་ལམ་ལུགས་དང་ཁས་བླངས་པའི་འགན་ལེན་ལུ་འགན་ཁུར་ཡོད།
- ཐོ་གཞུང་ བསམ་བཀོད་ ལམ་ ཚད་ ཟུར་གསོག་ཡང་ན་ blockchain ཐོ་འདི་ རང་བཞིན་གྱིས་རྒྱབ་སྣོན་ གནས་གོང་བཀོད་ནི་ ཁས་ལེན་སྒྲུབ་པའི་ཐོ་ འགན་ལེན་ ཉེན་བཅོལ་ཡང་ན་དངུལ་སྨར་ལུ་བརྗེ་ནིའི་ཁས་ལེན་མེན།
- དངུལ་སྤྲོད་ཞབས་ཏོག་ གསོལ་རས་ ཕན་འདེབས་གནས་ཚིག་དང་ཞབས་ཏོག་གཞན་གྱི་འབྲེལ་མཐུད་ཚུ་ གཞི་བཙུགས་དང་འཁྲིལ་ཏེ་སོ་སོ་ཨིནམ་དང་ རང་སོའི་གསལ་བསྒྲགས་དགོ།

གློག་རིམ་གྱིས་ ཡོད་པའི་ས་ལུ་དངུལ་ཁུངས་གཅིག་བརྒྱུད་དང་ལམ་བརྒྱུད་བརྗེ་སོར་རྒྱབ་སྐྱོར་འབདཝ་ཨིན། བོ་ལོག་ཆེན་སོ་སོ་བརྒྱུད་ལམ་ རང་བཞིན་གྱིས་མཛོད་ཆས་ཆ་སྙོམས་བཟོ་ནི་ བསྡམས་ཚན་ནང་ཕན་ཚུན་བསྡུ་རྩིས་ (netting) མཉམ་རུབ་ཉེན་བཅོལ་ གྲོས་འཆར་གྱི་སྐྱོང་སྲིད་རྒྱུ་དངོས་ ཡོངས་འབྲེལ་གྱི་རྒྱུ་དངོས་ལས་རིམ་དང་ཁྲིམས་དང་འཁྲིལ་པའི་དངུལ་སྤྲོད་ལམ་ཚུ་ གྲོས་འཆར་ཡང་ན་གཞི་བཙུགས་ལུ་བརྟེན་ཡོད། གཞི་བཙུགས་དམིགས་བསལ་གྱིས་ལག་ལེན་ཡོད་ཟེར་མ་བཀོད་པ་ཅིན་ ད་ལྟོ་ཡོད་ཟེར་བརྩི་ནི་མེན།
