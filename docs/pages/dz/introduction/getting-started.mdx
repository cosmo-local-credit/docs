# འགོ་བཙུགས་ནི་

Cosmo-Local Credit (CLC) འདི་ རང་དབང་གིས་སྐྱོང་འཐབ་མི་བརྒྱུད་ལས་ དངོས་གནས་དངུལ་ཕོགས་ཚུ་རྩིས་ཏེ་ ཨང་གྲངས་ཀྱི་རྒྱུ་དངོས་བཟོ་ནི་དང་ བསྡུ་ལེན་འབད་ནི་ དེ་ལས་ གཏོར་སྤྲོད་ནི་དང་བརྗེ་སོར་འབད་ནི་གི་ འགྲུལ་འཕྲིན་ཨིན་ཁས་ལེན་མཉམ་སྤྱོད་དངུལ་ཁུངས་ཚུ།འདི་ནང་ལུ་CLC Appཚོད་བསྲེ་ཚུ་ [cosmolocal.credit](https://cosmolocal.credit).

[Grassroots Economics Foundation](https://grassrootseconomics.org/about/) GEF གིས་ དམིགས་བསལ་གྱི་ གྲོས་འདེབས་དང་མ་དངུལ་གི་དོན་ལུ་ འགན་འཁྲི་གཞན་ཅིག་ཁས་ལེན་མ་འབད་བར་ ལག་ལེན་འཐབ་མི་གིས་བཟོ་ཡོད་པའི་ ཁས་བླངས་ཡིག་རྟགས་ཀྱི་ ཨེམ་སི་ཨོ་པཱ་ཀེཊ་༢༠༠༡ འི་ཨེམ་ཤི་ཡཱནཌིཀ་ (མཉམ་སྤྱོད་དངུལ་ཁུངས་ཀྱི་འཛིན་སྐྱོང་པ།) འདི་ལག་ལེན་འཐབ་མི་ཚུ་གིས་བཟོ་མིའི་སྡེ་ཚན་ཅིག་གི་ དངུལ་རྩིས་བློན་པོ་, སྐྱིན་འགྲུལ་སྐྱོརཔ་,བུ་ལོན་སྤྲོད་མཁན། ཉེན་བཅོལ་པ་ ཡང་ན་ (GEF) གིས་ Appདང་ རྒྱབ་སྐྱོར་མཐུན་རྐྱེན་ཚུ་ལག་ལེན་འཐབ་དོ་ཡོདཔ་ཨིན། སྐྱབས་མཛད་མི་འདི་ཨིན། བཀྲམ་སྤེལ་ཁང་ཚུ་གིས་ ཁོང་རའི་ ཁས་བླངས་ཚུ་གི་དོན་ལུ་ འགན་འཁྲི་འབག་དོ་ཡོདཔ་དང་ མཉམ་སྤྱོད་དངུལ་ཁུངས་ཀྱི་འཛིན་སྐྱོང་པ་ཚུ། གིས་ ཁོང་གི་བཅའ་ཁྲིམས་ཀྱི་འགན་ཁུར་བསྐྱེདཔ་ཨིན།

ཀློག་ཐེངས། [བསམ་འཆར་དང་ཚིག་ཡིག་ཚུ་](/dz/introduction/concepts) བཟོ་སྐྲུན་གྱི་ཐིག་ཚད་དང་ འགན་འཁྲི་ཚུ་ ལས་སྣ་ཚུ་གི་གནས་གོང་ དེ་ལས་འཐུས་དང་ གནས་སྟངས་ཀྱི་དོན་ཚན་ཚུ་ནང་ ལག་ལེན་འཐབ་ཡོདཔ་ཨིན།

རྩིས་ཁྲ་བཟོ་ནི་དང་ ཚོང་འབྲེལ་འཐབ་པའི་ཧེ་མར་ [ཞབས་ཏོག་གི་གནས་སྟངས་](/dz/governance/terms) དམིགས་བསལ་དུ་:

- ཁྱོད་ཀྱིས་ལོ་ ༡༨ ལང་མི་ དགོས་མཁོ་ཅན་ཅིག་དང་ ཁྲིམས་མཐུན་གྱི་ནདཔ་ཚེ་རིང་ལུ་ ཕེབས་ཡོདཔ་མ་ཚད་ ཆིངས་ཡིག་གི་བཅའ་ཁྲིམས་ནང་ བཅའ་མར་གཏོགས་ཚུགསཔ་ཨིན།
- ཁྱོད་རའི་རྩིས་ཁྲ་, ཅོ་ཨོན་ ( voucher) ཚུ་དང་ དངུལ་རྐྱང་གི་མཐུན་རྐྱེན་ ཡང་ན་ ཚོང་འབྲེལ་འདི་ ཁྲིམས་མཐུན་སྦེ་ཡོད་མི་འདི་ ངེས་བདེན་འབད་ནི་གི་འགན་ཁུར་ཡོདཔ་ཨིན།
- དངུལ་ཁུག་གི་མིང་ཐོ་ཚུ་ ཉེན་སྲུང་འབད་དགོཔ་ཨིན། GEF གིས་ བརླག་སོང་མི་དངུལ་ཁོག་ཅིག་སླར་ལོག་འབད་ནི་དང་ ཡང་ན་ ངོས་ལེན་ཅན་གྱི་ཚོང་འབྲེལ་འདི་ ལོག་བསྒྱུར་གཏང་མི་ཚུགས་འོང་།
- མི་མང་གི་སྦྲེལ་མཐུད་ལྡེ་མིག་ཚུ་དང་ ཐོ་བཀོད་ཚུ་ཡང་ མཐོང་ཚུགས་ནི་ཨིནམ་མ་ཚད་ ཡུན་རིངམོ་སྦེ་ཡོདཔ་མ་ཚད་ བསྒྱུར་བཅོས་འབད་ཐབས་མེདཔ་ཡང་ཨིན།
- ཨེཔ་ནང་ལུ་ཐོ་ཡིག་བཀོད་ནི་དེ་ GEF རྒྱབ་སྐྱོར་ ཡང་ན་ བགོ་བཀྲམ་འབད་ནི་གི་ ཉེན་ཁ་དང་གོང་འབད། ལི་ཀའིཌ་ཏིག་དང་། འགྱུར་བཅོས་འབད་ནི་དང་ དངུལ་ཕོགས་བསྡུ་ལེན་གྱི་མཐུན་རྐྱེན་མེདཔ།

## ད་ལྟོའི་ App ལས་འགོ་བཙུགས་

### 1. ཚོང་འབྲེལ་ནང་ལུ་བལྟ་

སྒོ་ཕྱུག [cosmolocal.credit](https://cosmolocal.credit) མི་སེར་ཚུ་ལུ་འཚོལ་ཞིབ་འབད་ནིའི་དོན་ལུ་ **ཚོང་འབྲེལ་** ཨེཔི་གི་མངོན་གསལ་བཟོ་ཐངས་འདི་ བསྐྱར་ཞིབ་འབད་ འབྲེལ་ཡོད་བཙོང་མི་དང་ ཁས་བླངས་ཅན་གྱི་ ཅ་ཆས་དང་ ཞབས་ཏོག་ཚུ་ དེ་ལས་ ས་གནས་དང་ འཐོབ་ཚུགསཔ་འབད་ནི་ དེ་ལས་ དཔར་བསྐྲུན་འབད་མི་ གནས་སྟངས་ཚུ་ལུ་བལྟ་དགོ། ཚོང་ལམ་གྱི་ཐོ་ཡིག་དེ་ རང་བཞིན་གྱིས་ དངུལ་བརྗེ་སོར་ཁང་དང་ བཙོང་པ་ཚུ་གི་བར་ན་ མཐུད་སྦྲེལ་འཐབ་ནིའི་ གོ་སྐབས་མེདཔ་ཨིན།

### 2. རྩིས་ཁྲ་དང་དངུལ་ཁུག་བཟོ།

ཌའི་ལོག་གི་ཁ་བྱང་དང་ཨེབ་གཏང་འབད་ནིའི་དོན་ལས་ ལག་ལེན་གྱི་ཐོ་ཡིག་ཅིག་ལག་ལེན་འཐབ་ཨིན། ཁྱོད་ཀྱིས་ Passkey, Paper-wallet དངོས་པོ་, Recovery Information, Devices དང་གཞན་འབྲེལ་ཆ་རྐྱེན་ཚུ་ སྲུང་སྐྱོབ་རྐྱབས། ཚོང་ལཱ་མ་སྒྲུབ་པའི་ཧེ་མ་ རྒྱུ་དངོས་ཡོངས་བསྡོམས་, གནས་སྡུད་, ཡི་གུ་, pool, fee དེ་ལས་ Authorization འདི་ཡང་ བསྐྱར་ཞིབ་འབད།

### 3. བརྒྱུད་འཕྲིན་བཟོ་ནི།

ཁས་བླངས་རྟགས་འདི་ ཐིག་ཁྲམ་ཁྱད་པར་ཅན་དག་པ་ཅིག་མཉམ་འབྲེལ་འབདཝ་ཨིན།

1. རྟགས་མཚན་གྱི་འཆམ་ཡིག་གི་ཅ་ཆས་དང་ དངུལ་རྐྱང་ཚུ་
2. བརྒྱུད་འཕྲིན་གྱི་མིང་ཐོ་དང་ གསལ་བསྒྲགས་འབད་ཡོད་པའི་གནས་ཚིག་ཚུ་
3. འབྲེལ་ཡོད་ཅ་ལ་དང་ ཞབས་ཏོག་ཚུ་གི་དོན་ལུ་ རིན་བསྡུར་གྱི་ཐོ་ཡིག་གཅིག་ ཡང་ན་ མང་ཤོས་ཅིག་ དེ་ལས་
4. དངུལ་ཁང་གི་དངོས་གནས་འཇིག་རྟེན་ནང་ལུ་ འགྲུབ་ཚུགསཔ་ཨིན།

ཌོག་ཊར་ཅིག་བཟོ་ནི་དང་ བཙུགས་ནི་དེ་ རང་གིས་རང་ལུ་ རིན་བསྡུར་འབད་ཡོད་པའི་ མངོན་གསལ་མེད་གཏང་མི་ཚུགས་ ཡང་ན་ དངུལ་ཁང་གི་ཚོང་འབྲེལ་འཐབ་མི་འདི་ ལྕོགས་གྲུབ་ཡོདཔ་ཨིན་ན་ ཡང་ཅིན་ GEF གིས་ འཁྲུན་ཆོད་བྱིན་ཚུགས་པའི་ གསལ་སྟོན་མེདཔ།

### 4. ཁས་ལེན་མཉམ་སྤྱོད་དངུལ་ཁུངས། བཟོ་ནི་དང་ བསྐྱར་ཞིབ་འབདཝ་ཨིན།

Aཁས་ལེན་མཉམ་སྤྱོད་དངུལ་ཁུངས།འདི་ཡང་ གཞུང་སྐྱོང་སྒྲིག་གཞི་ཅིག་ཨིན་ དེ་གི་གནས་སྟངས་དེ་ ད་རེས་ནངས་པར་`SwapPool`ལས་འཆམ་ནང་ རྒྱབ་སྐྱོར་ཅན་གྱི་ ཊོ་ཀིན་གྱི་རྩིས་ཐོ་ཚུ་བཞག་ནི་དང་ ཐད་ཀར་དུ་ བསྒྱུར་བཅོས་འབད་ཚུགས། ལག་ལེན་འཐབ་ནི་དང་ ཡང་ན་ གཅིག་ལུ་འཐོབ་ནིའི་ཧེ་མ་ ལྟ་རྟོག་:

- རྩིས་ཁྲ་སྤྲོད་མི་ མཉམ་སྤྱོད་དངུལ་ཁུངས་ཀྱི་འཛིན་སྐྱོང་པ།དང་ ད་ལྟོའི་གན་ཡིག་གི་ཇོ་བདག་;
- སྲིད་འཛིན་གྱི་འགན་ཁུར་དང་ འགན་འཁྲི་བཅའ་ཡིག་ཚུ་ བསྡུ་སྒྲིག་འབདཝ་ཨིན།
