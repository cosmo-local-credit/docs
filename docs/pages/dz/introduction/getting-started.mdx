# འགོ་བཙུགས་ནི་

Cosmo-Local Credit (CLC) གིས་ མི་ཚུ་ལུ་ ཁོང་གི་ཐོབ་དབང་གི་སྐོར་ལས་ འགྲེལ་བཤད་རྐྱབ་ནི་དང་ ཁོང་རའི་དགོས་མཁོ་ཚུ་ དཔར་བསྐྲུན་འབད་ནི་ དེ་ལས་ རང་དབང་གི་ལམ་ལུགས་ཀྱི་ཐོག་ལས་ ཁས་ལེན་མཉམ་སྤྱོད་དངུལ་ཁུངས་ཚུ། བགོ་བཤའ་བཙུགས་ནི་ལུ་ ལྷན་ཐབས་འབདཝ་ཨིན། འགོ་བཙུགས་ནི་གི་དོན་ལས་ [CLC App](https://cosmolocal.credit) འདི་ སྒོ་ཕྱེ་དགོཔ་ཨིན།

གཞི་རྩའི་བསམ་འཆར་འདི་ འཇམ་ཏོང་ཏོ་སྦེ་ཡོདཔ་དང་ འདི་ཡང་ སྤྱིར་བཏང་གི་མནོ་ལུགས་དང་འཁྲིལཔ་ད་ འ་ནི་འདི་ ཐ་དད་ཅིག་ཨིན་མས།

1. ཁྱོད་ཀྱིས་ག་ཅི་འབྱིན་ཚུགས་ནི་གི་དོན་ལས་ བོ་ཝཱནསི་ཅིག་བཟོ་འོང་། ཅ་ཆས་ཀྱི་ཤོག་བྱང་བཟུམ་ཅིག་ཨིན་མས།
2. མི་ཚུ་གིས་ ཅ་ཆས་དང་ཞབས་ཏོག་གི་སྐོར་ལས་ཤེས་ནི་གི་དོན་ལས་ བཀྲམ་སྤེལ་འབད་མི་གི་སྙན་ཞུ་འདི་དཔར་བསྐྲུན་འབད།
3. ཚོང་འབྲེལ་གྱི་མཉམ་རོགས་འོས་འབབ་ཡོད་མི་ཅིག་འཚོལ་ནི་ཨིན་མས།
4. དཔར་བསྐྲུན་འབད་མི་ཁྲིམས་ལུགས་ཀྱི་འོག་ལུ་ རྒྱབ་སྐྱོར་ཐོབ་ཡོད་པའི་ ཝུའུ་ཀཱན་ཚུ་བརྗེ་སོར་འབད་ནི་གི་དོན་ལས་ ཁས་ལེན་མཉམ་སྤྱོད་དངུལ་ཁུངས། འདི་ལག་ལེན་འཐབ་ཨིན།
5. གནང་བ་བཏོན་མི་དང་ཅིག་ཁར་ ཁེ་བསང་ཤོག་ངོས་འདི་ལག་ལེན་འཐབ་ཏེ་ འདི་གི་ཐ་སྙད་ནང་ལུ་ ག་ཅི་ར་འབད་དགོཔ་ཨིན་ན་བཀོད་དེ་ཡོདཔ་ཨིན་མས།

ཨེ་པཱལ་གྱི་ནང་ལུ་ “credit” ཟེར་མི་འདི་གིས་ ངོས་ལེན་འབད་དེ་ཡོད་མི་ལས་འགུལ་དང་ བགོ་བཤའ་བསྒྱུར་བཅོས་འབད་ནི་གི་ལྕོགས་གྲུབ་ཚུ་ལུ་སླབ་ཨིན། འདི་ཡང་རང་རྐྱངམ་ཅིག་ སྒེར་གྱི་དངུལ་ཁང་ཅིག་སྦེ་མེན་པས།

ངེས་ཚིག་གཏན་ཏོག་ཏོ་གི་དོན་ལས་ [བསམ་གཞི་དང་ཚིག་མཛོད་](/dz/introduction/concepts)བལྟ།

## ཨེ་པི་ཨེཔ་གི་ཐོག་ལས་ འགྲུལ་སྐྱོད་འགོ་དང་པ་འདི་ གློག་བརྙན་འཁྲབ་སྟོན་ནང་ལུ་འབད་ཡོདཔ་ཨིན།

### 1། ཚོང་འབྲེལ་དང་དགོས་མཁོ་ཚུ་དབྱེ་ཞིབ་འབད་ནི།

ཅ་ཆས་བཟོ་ནི་གི་ཧེ་མ་ [CLC App](https://cosmolocal.credit)བལྟ། **ཚོང་འབྲེལ་**འདི་ གསར་བཏོད་ཀྱི་ཐོ་གཞུང་ཅིག་ཨིནམ་དང་ འདི་ནང་ལུ་ གནམ་མེད་ས་མེད་ཉོ་མི་དང་ བརྗེ་སོར་འབད་ནི་ དེ་ལས་ ངོས་ལེན་འབད་ནི་དང་ ཡང་ན་ འགན་སྲུང་འབད་ནི་ཚུ་ཚུདཔ་ཨིན་མས།

ཤོག་བྱང་བསྐྱར་ཞིབ་འབད་བའི་སྐབས་ལུ་ བརྟག་དཔྱད་འབད།

- འདི་ཚུ་ག་ཅི་གིས་བཏོན་ཡོདཔ་ཨིན་ན་དང་ འ་ནི་འདི་ག་དེ་སྦེ་ཐོ་བཀོད་འབད་ཡོདཔ་ཨིན་ན་ དེ་ལས་ ག་དེ་ཅིག་གི་རིང་ལུ་བཞག་སྟེ་ཡོད་ནུག།
- ཅ་ཆས་དང་ཞབས་ཏོག་གི་ཐད་ཁར་ཡང་ འ་ནི་འདི་གིས་ ཁེ་བསང་སྦོམ་སྦེ་ར་ཡོདཔ་དང་ འདི་ཡང་ ཚོང་འབྲེལ་འཐབ་མི་ཚུ་ལུ་ ཁེ་ཕན་སྦོམ་ཤོས་ཅིག་ཐོབ་ནི་ཨིན་མས།
- འ་ནི་འདི་ག་སྟེ་དང་ གནམ་ལས་ དེ་ལས་ ག་དེ་སྦེ་ལག་ལེན་འཐབ་འོང་ག་དང་ འདི་ཚུ་ག་ཅི་གི་དོན་ལས་ལག་ལེན་འཐབ་ཨིན་ན་ དེ་ལས་ ལག་ལེན་གྱི་ཐད་ཁར་ལྷོདཔ་ད་ ག་ཅི་འབད་དགོཔ་ཨིན་ན་ཚུ།
- འདི་གི་ཚད་འཛིན་ཚུ་དང་ ཡལ་འགྱོ་ནི་གི་དུས་ཚོད་ འབྲེལ་བ་འཐབ་ནི་གི་ཐབས་ལམ་དང་ སྐྱོན་བརྗོད་འབད་ནི་གི་བྱ་རིམ་ དེ་ལས་ བཀག་ཆ་འབད་མི་གི་བྱ་རིམ་ཚུ་ཨིན་མས།
- འདི་ལུ་རྒྱབ་སྐྱོར་འབད་མི་ ཁས་ལེན་མཉམ་སྤྱོད་དངུལ་ཁུངས་ཚུ། འདི་ཨིན་མས།

**ཝཱན་ཀྲི་**འདི་གིས་ དགོ་འདོད་བཀོདཔ་ཨིན། དཔར་བསྐྲུན་འབད་ནི་དང་ ཡང་ན་ ལན་གསལ་འབད་མི་འདི་གིས་ གློག་ཆས་ཀྱི་ཐོག་ལས་ ཤོག་བྱང་ངོས་ལེན་འབད་ནི་དང་ ཅ་ཆས་བཞག་ནི་ དེ་ལས་ བརྗེ་སོར་འབད་བཏུབ་པའི་དབང་ཚད་འཐོབ་ནི་ ཡང་ན་ ལཱ་འགན་ཅིག་བཟོ་ནི་གི་དོན་ལས་མེན་པས། གཞན་མི་བཅའ་མར་གཏོགས་མི་ཚུ་དང་འབྲེལ་བ་འཐབ་ནི་དང་ཡང་ན་ བརྡ་འཕྲིན་བཏང་ནི་ཚུ་གིས་ ཁོང་ར་གིས་ ཤོག་གྲངས་ཀྱི་ལཱ་འགན་འདི་བཟོ་ནི་དང་ འདི་ཚུ་གྲུབ་ནི་ ཡང་ན་ མཇུག་བསྡུ་ནི་གི་གོ་སྐབས་མེདཔ་ཨིན་མས།

### 2. གྱངས་ཁ་རྐྱབ་ནི་དང་/ཡང་ན་ འཛུལ་ནི་དང་ Wallet ཟེར་མི་དངུལ་ཁང་ཅིག་བཙུགས་དགོཔ་ཨིན།

ཨེ་པཱལ་འདི་གིས་ ཁྱད་རྣམ་དང་ དུས་རིམ་ནང་ལུ་འཛུལ་ནི་གི་དོན་ལས་ རྩིས་ཁྲ་ལག་ལེན་འཐབ་དོ་ཡོདཔ་མ་ཚད་ ** དངུལ་ཁང** འདི་ བི་ལི་ཀེན་འཕྲུལ་ཆས་ཀྱི་ངོས་ལེན་འབད་ནི་གི་དོན་ལས་ལག་ལེན་འཐབ་དོ་ཡོདཔ་ཨིན། ཁྱོད་ཀྱི་གསང་ཚིག་དང་ ཤོག་གུའི་དངུལ་ཁང་གི་དངོས་པོ་ ལོག་ཐོབ་ནི་གི་བརྡ་དོན་ འཕྲུལ་ཆས་དང་ གཞན་མི་ངོ་རྟགས་ཚུ་ཉེན་སྲུང་འབད་དེ་བཞག་དགོཔ་ཨིན། གནས་ས་ག་ར་དང་ རྒྱུ་དངོས་ གྲངས་འབོར་ སྡེ་ཚན་ ཁྲལ་ དེ་ལས་ འབྲེལ་གཏོགས་ཅིག་ངེས་བདེན་བཟོ་ནི་གི་ཧེ་མ་ལས་ དབང་ཚད་ཚུ་བསྐྱར་ཞིབ་འབད་འོང་།

གློག་འབྲེལ་མཐུན་ལམ་འདི་ནང་ལུ་འཛུལ་ནི་གི་སྐབས་དང་ ཤོག་བྱང་ཡང་ན་སྡེ་ཚན་དཔར་བསྐྲུན་མ་འབད་བའི་ཧེ་མ་ ཁྲིམས་ལུགས་ཚུ་ངོས་ལེན་འབད་དགོཔ་སྦེ་སླབ་ཨིན། འཕྲོ་མཐུད་དེ་འགྱོ་ནི་གི་ཧེ་མ་ [ཞབས་ཏོག་གི་ཁྲིམས་ལུགས་](/dz/governance/terms)དང་ [སྒེར་གྱི་བརྡ་མཚོན་](/dz/governance/privacy)བལྟ།

### 3། ཤོག་བྱང་བཟོ་བསྐྲུན་འབད་ནི་དང་ བཀྲམ་སྤེལ་འབད་ནི།

[Grassroots Economics Foundation](https://grassrootseconomics.org/about/)འདི་གིས་ ཨེ་པི་ཨེསི་དང་རྒྱབ་སྐྱོར་གྱི་གཞི་བཀོད་ཚུ་ལག་ལེན་འཐབ་དོ་ཡོདཔ་ཨིན། GEFགིས་ དམིགས་བསལ་གྱི་ཚོང་འབྲེལ་གྱི་དོན་ལས་ གཞན་མི་འགན་འཁུར་ཅིག་ངོས་ལེན་འབད་མ་ཚུགས་པ་ཅིན་ འདི་གིས་ ལག་ལེན་པ་གིས་བཟོ་མི་ ཝའུ་ཀུ་གི་ཐོན་སྐྱེད་འབད་མི་ཅིག་ཨིན་མས། ཡང་ན་ ལག་ལེན་འཐབ་མི་གིས་བཟོ་ཡོད་མི་ པོ་ལར་གྱི་བདག་སྐྱོང་འབད་མི་དང་ བདག་འཛིན་འཐབ་མི་ དངུལ་འབབ་བསྡུ་གསོག་འབད་མི་ ཉེན་སྲུང་འབད་མི་ ཡང་ན་ བརྗེ་སོར་འབད་མི་ཅིག་ཡང་མེན།
