# འབྱུང་རབས་

[Grassroots Economics Foundation](https://grassrootseconomics.org/about/) (GEF) བཟོ་སྐྲུན་དང་བདག་འཛིན་འབད་མི་ལུ་བརྟེན་Sarafu Networkད་ལྟོ་ལཱ་འབད་དོ་ཡོདཔ་CLC Appཌི་ཇི་ཊཱལ་ལམ་ལུགས་མ་ཐོན་པའི་ཧེ་མར་ མི་སེར་ཚུ་གིས་ གཅིག་གིས་གཅིག་ལུ་ ཁས་བླངས་ཚུ་འབད་ཡོདཔ་མ་ཚད་ ཁོང་རའི་དྲན་རྟེན་དང་འབྲེལ་བ་ དེ་ལས་ ས་གནས་ཀྱི་རྩིས་སྤྲོད་ཐོག་ལས་ བསྡུ་ལེན་འབད་ནི་ལུ་བརྟེན་ ཀེན་ཡ་གི་སྡེ་ཚན་དང་གཅིག་ཁར་སྡོད་ནི་དང་ ཤེས་ཡོན་སྦྱང་བའི་སྐབས་ལུ་ གོང་འཕེལ་བྱུང་ཡོདཔ་ཨིན། [གཞི་རྟེན་དཔལ་འབྱོར་: མནོ་བསམ་གཏང་ནི་དང་ ལག་ལེན་འཐབ་ནི་](https://grassrootseconomics.org/book/) འདི་ ཁས་བླངས་ཀྱི་མཐུན་རྐྱེན་ཅིག་ཨིནམ་སྦེ་བཤད་དོ་ཡོདཔ་ཨིན། ཁེ་རྒུད་ཚུ་ གཅིག་ལས་མེད་རུང་ བརྗེ་སོར་འབད་ནི་དང་ མཇུག་བསྡུ་ནི་ དེ་ལས་བསྐྱར་གསོ་འབད་ཚུགས་པའི་ ཁས་ལེན་ཨིན།

ལས་རིམ་འདི་ འགོ་དང་པ་ སྤྱི་ཚོགས་གྱི་དངུལ་ཀྲམ་ཚུ་ཐོག་ལས་ གསལ་སྟོན་འབད་ཡོདཔ་ད་ ས་གནས་ཀྱི་ལམ་ལུགས་ཚུ་གིས་ རྒྱལ་ཡོངས་དངུལ་ཀྲམ་གྱི་དཀའ་ངལ་སེལ་ཐབས་ལུ་ བཏང་དོ་ཡོདཔ་ཨིན། དྭངས་གསལ་བའི་སྦྱོང་བརྡར་དེ་ དམིགས་བསལ་གི་ དངུལ་རྐྱང་ཅིག་མེན་རུང་ ཚད་འཛིན་འབད་ནི་དང་བགོ་བཤའ་རྐྱབ་ནི་གི་ ཐབས་ལམ་གཅིག་ཨིནམ་ལས་ གོང་འཕེལ་གཏང་ནི་ དེ་ལས་མཐུན་རྐྱེན་ཚུ་གི་ ཉེན་སྲུང་གི་དོན་ལུ་ ངེས་གཏན་སྦེ་ཐོ་བཀོད་འབདཝ་ཨིན། སློབ་སྦྱོང་དེ་གི་ཐོག་ལས་ ཁས་བླངས་མཐུན་རྐྱེན་གྱི་ གྲོས་ཆོད་ (CPP) གཞི་བཙུགས་འབད་ཡོདཔ་ཨིན།

## བྱུང་རབས་ཀྱི་ནང་ལས་Sarafu Networkའབད་ནི་Cosmo-Local Credit

བྱུང་རབས་ཀྱི་Sarafu Networkའབུ་ཊ་གི་དོན་ལུ་ལག་ལེན་གྱི་སློབ་སྦྱོང་གནས་སྟངས་སྦེ་ ཕྱག་ཞུ་ཡོདཔ་མ་ཚད་ཁས་ལེན་མཉམ་སྤྱོད་དངུལ་ཁུངས་ཚུ།སྤྱི་ཚོགས་, སློབ་གྲྭ་,སྨན་ཁང་ཚུ་ནང་། སོ་ནམ་ཞིང་པ་ཚུ་ནང་དང་ མཉམ་འབྲེལ་ལས་སྡེ་ དེ་ལས་ ས་གནས་ཀྱི་ ལས་སྣ་གཞན་ཚུ་ནང་ལུ་GEFའདི་བཟུམ་གྱི་ཉམས་མྱོང་ལུ་བརྟེན་ རང་དབང་གིས་སྐྱོང་འཐབ་མི་ ཁས་བླངས་ཚུ་ གཅིག་ཁར་བསྡོམས་ཚུགསཔ་བཟོ་ནི་དང་ དེ་ཚུ་ལུ་ དབུ་འཛིན་འབད་ཡོད་པའི་ཚོང་འབྲེལ་གཅིག་ནང་ འགྱུར་བ་མ་འབྱུང་བར་ ཡང་ན་ ས་གནས་ཀྱི་འགན་ཁུར་འདི་ བཏོན་གཏང་ནི་མེད་པར་ ག་དེ་སྦེ་ མཐུད་སྦྲེལ་ཚུགས་ག་ ཞིབ་འཚོལ་འབད་ནུག

ཞབས་ཏོག་དེ་ ཧེ་མ་གི་Sarafu Networkགནས་སྤོ་འགྱོ་མི་CLC Appནང་ལུ་ [cosmolocal.credit](https://cosmolocal.credit) GEFགིས་ལག་ལེན་འཐབ་དོ་ཡོདཔ་ཨིན། འདི་ཡང་ མི་མང་གི་ཞབས་ཏོག་དང་ ལཱ་ཀྱི་ལཱ་འདི་ འཕྲོ་མཐུད་དེ་ར་འབད་ཡོདཔ་ཨིན། དེ་གིས་མ་དོ་བར་ ས་རཱ་ཕུའི་རྩིས་ཁྲ་, དངུལ་ཁུག་, ཐོ་བཀོད་རྟགས་, ཁས་བླངས་དངུལ་རྐྱང་, བཞག་ཐངས་, སྙན་ཞུ་, བཅའ་མར་གཏོགས་མི་ ཡང་ན་འགན་ཁག་ཚུ་ཆ་མཉམ་ ད་ལྟོའི་ Appནང་ལུ་ སྤུས་ཚད་བཟུང་སྟེ་བཞག་ནུག

Cosmo-Local Creditརྒྱུད་འབྱུང་། སློབ་སྦྱོང་། སྒོ་ཕྱེ་མི་མཉེན་ཆས་དང་ ཁས་བླངས་མཉམ་འབྲེལ་གྱི་ལཱ་ཚུ་འབད་ཐངས་ཡར་རྒྱས་འགྱོ་དོ་ཡོདཔ་ཨིན། ད་ལྟོའི་ཐོན་སྐྱེད་བཟའ་ཚན་ནང་ལུ་CLC Appའདི་ཡང་ རང་དབང་གིས་སྐྱོང་འཐབ་མི་ ཝའུ་ཅཱོན་ཚུ་གི་དོན་ལུ་ ཐོ་བཀོད་དང་སྒོ་ཕྱེ་ཡོད་པའི་གཞུང་ལམ་ལུགས་ དེ་ལས་ཁས་ལེན་མཉམ་སྤྱོད་དངུལ་ཁུངས་ཚུ།དངུལ་ཁང་གི་དངུལ་རྩིས་བློན་པོ་ཚུ་གིས་ ཁས་བླངས་འབད་མི་ཚུ་གི་དོན་ལུ་ འགན་འཁྲི་འབག་སྟེ་སྡོད་དོ་ཡོདཔ་ཨིན།མཉམ་སྤྱོད་དངུལ་ཁུངས་ཀྱི་འཛིན་སྐྱོང་པ་ཚུ།ཁོང་རའི་ཁྲིམས་ལུགས་དང་ ཁོང་གིས་ཁྱབ་བསྒྲགས་འབད་མི་མཐུན་རྐྱེན་ཚུ་གི་དོན་ལུ་ འགན་འཁྲི་འབག་སྟེ་སྡོད་ནི་དང་ དེ་ལས་ མི་སྡེ་དང་ གཙུག་ལག་ཚུ་གིས་ རང་སོའི་གནས་སྟངས་ལུ་ འོས་འབབ་ཡོད་པའི་ གཞུང་སྐྱོང་ཐབས་ལམ་ཚུ་ ལག་ལེན་འཐབ་ཚུགས།

ཐབས་ལམ་གཅིག་ལས་ ཡུདཔ་ཅིག་ལུ་:

1. ཁྲོམ་སྡེའི་དངུལ་ཀྲམ་ཚུ་གིས་ ས་གནས་ཀྱི་མཐུན་རྐྱེན་ཚུ་མཐོང་ཚུགསཔ་བཟོ་ཡོདཔ་ད་ དངུལ་རྐྱང་ཉུང་དྲགས་ཅིག་ཨིན་མས།
2. ཁས་བླངས་མཐུན་སྒྲིལ་གིས་ བཟོ་སྐྲུན་འབད་ཡོདཔ་ ཚད་འཛིན་འབད་ནི་དང་ བཀག་ཆ་འབད་ནི་ དེ་ལས་ ལོག་སྟེ་ར་ ལག་ལེན་འཐབ་ཚུགས་པའི་ བྱ་རིམ་སྒྲིག་གཞི་གི་ཡན་ལག་ཚུ་ནང་ བརྗེ་སོར་འབདཝ་ཨིན།
3. བྱུང་རབས་ཀྱི་ Sarafu Network གིས་ མི་སྡེ་དང་ ལས་ཚོགས་ཚུ་གི་ནང་འཁོད་ལུ་ བསམ་འཆར་ཚུ་ བརྟག་དཔྱད་འབད་དེ་ དབྱེ་ཞིབ་འབད་ཡོདཔ་ཨིན།
4. ཞབས་ཏོག་དེ་ Cosmo-Local Credit ལུ་ སྤོ་བཤུད་འབད་ཡོདཔ་ལས་ ཧེ་མ་གི་ལག་ལེན་འཐབ་མི་ཚུ་དང་ རྒྱུ་དངོས་ཚུ་ ཐོ་བཀོད་འབད་ནི་དང་ འགན་ཁུར་འདི་ཚུ་ བཏབ་ནི་མེདཔ་ཨིན་པས།
5. ད་ལྟོའི་ App གིས་ རྒྱབ་སྐྱོར་འབད་ཡོད་པའི་ Wallet, voucher, Pool དང་ direct-swap གྱི་ལཱ་རྒྱུན་ལམ་ཚུ་ གྲོགས་རམ་འབད་ཡོདཔ་ཨིན། རུ་ཊི་སྤེལ་ཐངས་མང་ཤོས་ཅིག་དང་། བཀྲམ་སྟོན་ཐབས། ལི་ཀའིཌ་ཏིག་། འཇམ་གསོག་དང་ གཞུང་སྐྱོང་གི་ཅ་ཆས་ཚུ་ གྲོས་འཆར་བཀོད་མི་ལུ་བརྟེན་ ཡང་ན་ གཞི་བཙུགས་འབད་ནི་ལུ་བརྟེན་ཏེ་ཨིན་མས།

ཀློག་ཐེངས། [བསམ་འཆར་དང་ཚིག་ཡིག་ཚུ་](/dz/introduction/concepts) ཌོག་ཊར་ཚུ་ནང་ལག་ལེན་འཐབ་མི་ ཚགས་ཁལ་དང་གནས་གོང་གི་ཚིག་དོན་ཚུ་གི་དོན་ལུ་ཨིན། [ཞབས་ཏོག་གི་གནས་སྟངས་](/dz/governance/terms) CLC App གི་ལག་ལེན་འཐབ་ནི་ [ཁྲི་དེབ་དཀརཔོ་](/dz/white-paper) བཟོ་བཀོད་དང་ ཞིབ་འཚོལ་ དེ་ལས་ ལམ་སྟོན་འཆར་གཞི་ཚུ་ གསལ་བཀོད་འབདཝ་ཨིན།
