# ལག་ལེན་འཐབ་བཏུབ་པའི་ ཅ་ཁྲལ་གྱི་དཔེ་ཚུགས།

དཔེ་འདི་ གྲོང་གསེབ་བརྗེ་སོར་གྱི་ཐོག་ལས་ བཀྲམ་སྤེལ་འབད་ཡོདཔ་ལས་ འཁྲུན་ཆོད་སྤྲོད་ནི་དང་ མཇུག་བསྡུ་ནི་དང་ ཐོ་བཀོད་འབད་ནི་ཚུ་ཨིན། འདི་ནང་ཚུད་མི་ འགན་ཁུར་འདི་ཚུ་ གསལ་སྟོན་འབདཝ་ཨིན་ དེ་གིས་ ཁས་བླངས་ཅིག་མེན་རུང་ ཁྱད་དུ་ལྡན་པའི་ འབུམ་སྡེ་ཚན་ ཡང་ན་ འགྲོ་འགྲུལ་ལམ་ཡང་ན་ གྲུབ་འབྲས་དེ་ ལག་ལེན་འཐབ་ཚུགས་ཟེར་ཨིན་པས།

འདི་ནང་ལུ་ལག་ལེན་འཐབ་མི་འགྲེལ་བཤད་ཚུ་བལྟ་ [བསམ་འཆར་དང་ཚིག་ཡིག་ཚུ་](/dz/introduction/concepts).

## 1. དངུལ་བཏོན་མི་ཅིག་གིས་ ཁས་བླངས་གསལ་བསྒྲགས་འབདཝ་ཨིན།

མི་སྡེ་གིས་ བཟོ་གྲྭ་ཁང་ཅིག་ནང་ ཌི་ཇི་ཊཱོལ་གྱི་ བཞེས་སྒོ་གི་རྟགས་མཚན་བཟོ་ཞིནམ་ལས་ བཙུགས་མ་གཏང་པའི་ཧེ་མར་ བཟའ་ཆས་ཁང་འདི་གིས་ འོས་འབབ་ཅན་གྱི་ གྲོས་ཐག་བཅད་ནིའི་དོན་ལུ་ དགོས་མཁོ་ཡོད་པའི་ བརྡ་དོན་ཚུ་ དཔར་བསྐྲུན་འབདཝ་ཨིན།

- བཟོ་ཁང་གི་ངོ་རྟགས་དང་ བརྡ་དོན་ཚུ་
- བཞེས་སྒོ་དང་ ཡང་ན་ གྲོགས་རམ་གཞན་ཅིག་ ཤོག་ལེབ་གཅིག་གིས་ངོ་ཚབ་འབད་ཡོདཔ་ཨིན།
- supply, unit, declared value དེ་ལས་ བཟོ་ཁང་གི་ལཱ་འབད་ནིའི་ལྕོགས་གྲུབ་
- ས་གནས་ག་ཏེ་དང་ དུས་ཚོད་ག་དེམ་ཅིག་ནང་ བཏང་ཚུགས་ནི་ཨིན་ན?
- དུས་ཡུན་ཚང་བའི་ཚེས་གྲངས་དང་ ཐོ་བཀོད་འབད་ཐངས་ དེ་ལས་འཐུས་ཁྲལ་ ཡང་ན་ བགོ་བཀྲམ་འབད་ནིའི་བཀག་དམ་ཚུ་;
- གསལ་སྟོན་འབད་ཐངས་དང་ བསྒྲུབ་ཐངས་ དེ་ལས་ ཉོགས་བཤད་ཚུ་ བསྐྱིན་ཚབ་འབད་ནི་ ཐབས་ལམ་གཞན་ཚུ་ཡང་ ག་དེ་སྦེ་ ལག་ལེན་འཐབ་དོ་ཡོདཔ་ཨིན་ན?

བཟོ་ཁང་འདི་ ཐོན་སྐྱེད་འབད་མི་དེ་ཨིན། དེ་གིས་ བརྡ་དོན་ཚུ་ ངེས་བདེན་སྦེ་བཞག་དགོཔ་དང་ རང་གི་ནུས་པ་ཚད་ལས་བརྒལ་ བཏང་མི་དགོ་ དེ་ལས་ ལག་ལེན་འཐབ་མི་ཚུ་གིས་ ཐོབ་ཡོད་པའི་གནས་སྟངས་དང་འཁྲིལ་ཏེ་ ཅ་དམ་འདི་ཚུ་ གུས་ཞབས་འབད་དགོཔ་ཨིན། ཌོག་ཊར་བཟོ་ནི་དང་ ཡང་ན་ གྲོས་འདེབས་གསལ་སྒྲགས་འབད་ནི་དེ་གིས་ དེ་བཟུམ་གྱི་ནུས་ཤུགས་ལུ་ གསལ་སྟོན་མ་འབདཝ་མ་ཚད་ GEF འདི་ emitterབཟོཝ་མེན།

## 2. མཉམ་སྤྱོད་དངུལ་ཁུངས་ཀྱི་འཛིན་སྐྱོང་པ། གིས་ འགྲེམ་ཐོག་ཁས་ལེན་འདི་ངོས་འཛིན་འབདཝ་ཨིན།

བཟའ་འཐུང་གི་ ཉེན་སྲུང་ཁས་ལེན་མཉམ་སྤྱོད་དངུལ་ཁུངས།བཟོ་ཁང་དང་ ཅ་དམ་གྱི་གནས་སྟངས་ དེ་ལས་ ཆུ་མཛོད་ཀྱི་དོན་རྐྱང་ཚུ་ བསྐྱར་ཞིབ་འབདཝ་ཨིན།མཉམ་སྤྱོད་དངུལ་ཁུངས་ཀྱི་འཛིན་སྐྱོང་པ།གནས་སྟངས་འདི་ ག་དེ་སྦེ་ཡོདཔ་ཨིན་ན་ གསལ་སྟོན་འབདཝ་ཨིན།

- སྦ་སྒོར་གྱི་འགན་ཁུར་བཀལ་མི་;
- ད་ལྟོ་ཡོད་མི་ `SwapPool` གི་ཇོ་བདག་དང་ བཀྲམ་སྤེལ་འབད་ནིའི་དོན་ལས་ འཛིན་སྐྱོང་འཐབ་མི་ དེ་ལས་ མཁོ་ཆས་ཚུ་གི་བཅའ་མར་གཏོགས་མི་ཚུ་
- ཆ་འཇོག་གྲུབ་མི་ རྒྱུ་དངོས་ཚུ་
- དངུལ་བརྗེ་སོར་གྱི་གནས་གོང་ ཡང་ན་ གྲོས་འདེབས་གི་ཐབས་ལམ་ཚུ་;
- ཐོ་བཀོད་འབད་ཡོད་པའི་ གྱངས་ཁ་ཚུ་ **ཁེ་རྒུད་ཀྱི་ཚད་འཛིན་ཚུ་** Appནང་ལུ་;
- ཟད་འགྲོ་དང་མཐུན་རྐྱེན་གྱི་འཐུས་;
- ཐོ་བཀོད་དང་ ལི་ཀུ་ཌིཊ་ཕྱིར་བཏོན་འབད་ནིའི་དབང་ཆ་;
- རང་གིས་རང་སོ་སོར་སྦེ་དངུལ་རྒྱབ་སྐྱོར་འབད་མི་ ཁེ་ཕན་དང་ རྒྱབ་སྐྱོར་གྱི་མཐུན་རྐྱེན་ཚུ་ཨིན།

འཛུལ་ཞུགས་ཀྱི་དོན་ལས་ Pool གིས་ གཞི་སྒྲིག་འབད་ཡོད་པའི་ཁྲིམས་ལུགས་ཚུ་གིས་ ཁས་བླངས་དངུལ་གྱི་རྟགས་འདི་བྱིན་ཚུགསཔ་བཟོཝ་ཨིན། འདི་གིས་གྲུབ་འབྲས་ལུ་ བརྟག་ཞིབ་འབད་ནི་དང་ དངུལ་རྐྱང་གི་གོང་ཚད་བཏོན་ནི་ དེ་ལས་ ཉེན་བཅོལ་བཟོ་མི་ཚུགས།

## 3. བཅའ་མར་གཏོགས་མི་ཅིག་གིས་ ཐོན་སྐྱེད་ཚུ་ གྲོགས་རམ་འབདཝ་ཨིན།

གྲོགས་རམ་བྱིན་མི་ཅིག་གིས་ བཞེས་སྒོ་གི་རྟགས་མཚན་དང་ ཡང་ན་ རྒྱབ་སྐྱོར་འབད་མི་ རྒྱུ་དངོས་གཞན་ཚུ་ `SwapPool` ལུ་ འབྲེལ་ཡོད་གསལ་བསྒྲགས་འབད་ཡོད་པའི་གནས་སྟངས་དང་འཁྲིལ་ཏེ་ གནས་སྤོ་བཞག་འབདཝ་ཨིན། དེ་ནང་བཙུགས་མི་དེ་གིས་ འོང་འབབ་ཀྱི་གོང་ཚད་ཡར་སེང་འགྱོ་དོ་ཡོདཔ་ཨིན།

གནས་སྤོ་དེ་གིས་ རང་བཞིན་གྱིས་ Pool share, refund claim, withdrawal right, reward ཡང་ན་ governance power འབྱུང་མི་མེན། འ་ནི་ཐོབ་ཐངས་ཚུ་ གསལ་སྟོན་འབད་ཡོད་པའི་ གྲོས་ཆོད་སོ་སོར་ལས་འབྱུང་དགོཔ་ཨིན།

## 4. ལག་ལེན་པ་ཅིག་གིས་ Pool བསྒྱུར་བཅོས་འབདཝ་ཨིན།

ལག་ལེན་པ་གིས་ རྒྱབ་སྐྱོར་ཅན་གྱི་ རྒྱུ་དངོས་ཅིག་ལུ་ བཞེས་སྒོ་གི་ལྡེ་མིག་ཚུ་ཐོག་ལས་བརྗེ་སད་འབདཝ་ཨིན། ཨེབ་གཏང་འབད་མི་འདི་ གྲོས་འདེབས་བཟོ་མི་གིས་ བཟོ་སྐྲུན་འབད་མི་ ཚོང་འབྲེལ་གྱི་གནས་ཚད་ཨིནམ་ལས་ ཅ་ཆས་ཀྱི་དངུལ་ཀྲམ་དང་ ཟ་ཁང་གི་ཐོན་སྐྱེད་ཚུ་གི་ཁུངས་མེན་པས།

ཐད་ཀར་དུ་ Pool ཨིསི་བེཌ་དེ་ནང་ཐོ་བཀོད་འབད་ནི་དང་ ཐོན་སྐྱེད་ཚུ་ བསྒྱུར་བཅོས་འབད་བའི་ཐོག་ལས་ གྲོང་གསེབ་ལུ་གནས་སྤོ་འབདཝ་ཨིན། འདི་ཨ་རྟག་ར་ སྐྱིན་འགྲུལ་མ་དངུལ་ ཡང་ན་ emitter redemption ཡངན་ real world fulfillmentམེན་ཨིན།

## 5. ལག་ལེན་པ་གིས་ ཁས་བླངས་རྟགས་འདི་ གྲུབ་སྤྲོད་འབདཝ་ཨིན།

ད་ལྟོའི་ལག་ལེན་ནང་ལུ་ གདམ་ཁ་རྐྱབས་ **Redeem”** ཌོག་ཊར་གི་ཨང་གྲངས། ༡༣༨/༡༢༧ བཀྲམ་སྤེལ་འབད་ནིའི་དོན་ལས་ གྲོས་བསྡུར་དང་འབྲེལ་བའི་ ཐོ་བཀོད་འབདཝ་ཨིན།

བཟོ་ཁང་གིས་ སྤུས་ཚད་འདི་བརྟག་ཞིབ་འབད་ཞིནམ་ལས་ བཞེས་སྒོ་དེ་ གསལ་བསྒྲགས་འབད་མི་གནས་སྟངས་དང་འཁྲིལ་ཏེ་ གྲ་སྒྲིག་འབདཝ་ཨིན།

## 6. ཨེམ་སི་ཊི་ཨོན་གྱིས་ བསྡུ་ལེན་དང་ ཐོ་བཀོད་འབད་ཐབས།

བཞེས་སྒོ་བྱིན་ཚར་བའི་ཤུལ་ལས་ ཕྱིར་བཏོན་མི་དེ་གིས་ འོང་འབབ་ཐོབ་མི་ ཨང་གྲངས་ཚུ་ ཐོ་བཀོད་འབད་ཡོདཔ་ལས་ དེ་གཉིས་ཆ་ར་ ངོ་སྤྲོད་འབད་མི་ཚུགས། དཔར་བསྐྲུན་འབད་བའི་ བྱ་རིམ་དང་འཁྲིལ་བ་ཅིན་ འདི་ནང་ ལོག་འོང་མིའི་ ཏཱ་ལེན་དེ་ ལེན་ནི་དང་ མཚམས་འཇོག་འབད་ནི་དང་ ཡང་ན་ ཆ་མེད་གཏང་དགོཔ་ཨིན།

གལ་སྲིད་ བཟོ་ཁང་གིས་ ཁས་བླངས་དེ་མ་སྒྲུབ་པ་ཅིན་ ལག་ལེན་པ་འདི་གིས་ དངུལ་རྩིས་བློན་པོ་གི་སྙན་ཞུ་དང་ ཉེས་བྱ་བསྡུ་བའི་ལམ་ལུགས་ དེ་ལས་ ཁྲིམས་ཀྱི་འོག་ལུ་ཡོད་མི་ ཐོབ་དབང་ཚུ་ལག་ལེན་འཐབ་ཨིན།GEFཡང་ན་མཉམ་སྤྱོད་དངུལ་ཁུངས་ཀྱི་འཛིན་སྐྱོང་པ།བཀྲམ་སྤེལ་འབད་མི་དེ་ App གིས་ ཝའུ་ཕོར (coucher) འདི་བཏོན་ཡོདཔ་ལས་ ཡང་ན་ Pool གིས་ ས་ཚབ་འདི་བཟོཝ་ཨིན།

གདམ་ཁ་རྐྱབས་ **འཛིན་ཤོག་ལག་ལེན་ལས་བཏོན།** འདི་ Appནང་ལུ་ཁྱད་པར་ཅན་ཅིག་ཨིན། དེ་གིས་ catalogues གི་ཐོ་ཡིག་འདི་སྦ་བཞག་སྟེ་ཡོདཔ་ད་ balance དང་ history ཚུ་ བཞག་སྟེ་ཡོད་མི་དེ་ཡང་ admins གིས་ སླར་ལོག་འབད་ཚུགས་ཡོདཔ་ཨིན། བཏོན་གཏང་ནི་དང་ མཚམས་འཇོག་འབད་ནི་དང་ burning ཡང་ན་ cancellationམེན་པས།

## འགན་འཁྲི་ཚུ་ འགོ་དང་པ་

- **བཀྲམ་སྤེལ་འབད་མི་:** གསལ་བཀོད་དང་ བཀྲམ་སྟོན་ཐོ་བཀོད་འབད་ཡོདཔ་ཨིན།
- **མཉམ་སྤྱོད་དངུལ་ཁུངས་ཀྱི་འཛིན་སྐྱོང་པ།:** འཆར་གཞི་༡༢ པའི་ནང་ གྲོས་བསྡུར་དང་འབྲེལ་བའི་ ལས་སྣ་ཚུ་ འགོ་འདྲེན་འཐབ་ནི་ཨིན་པས།
- **འགོ་འདྲེན་འཐབ་མི་:** དངུལ་རྐྱང་ཕྱིར་ཚོང་འཐབ་མི་དང་ ཅ་དམ་ཡིག་གི་གནས་སྟངས་ དེ་ལས་ གྲོང་གསེབ་ཀྱི་ཁྲིམས་ལུགས་ཚུ་ བསྐྱར་ཞིབ་འབདཝ་ཨིན།
- **ལག་རྩལ་འཛིན་སྐྱོང་པ་:** ཁོང་རང་ལུ་བཅོལ་བའི་ཆིངས་ཡིག་དང་ འགན་འཁྲི་ ཡར་དྲག་གཏང་ནི་དང་ ཐོ་བཀོད་འབད་ནི་ ཡང་ན་འཐུས་སྤྲོད་ནི་གི་ དབང་ཚད་ཚུ་རྐྱངམ་གཅིག་ ལག་ལེན་འཐབ་དགོ།
- **GEF:** CLC Appདང་ རྒྱབ་སྐྱོར་མཐུན་རྐྱེན་ཚུ་ལག་ལེན་འཐབ་དོ་ཡོདཔ་ད་ [ཞབས་ཏོག་གི་གནས་སྟངས་](/dz/governance/terms) རང་བཞིན་གྱིས་ འགན་ཁུར་གཞན་ཚུ་འབག་མི་ཚུགས།

## མ་འོངས་པའི་ སྐྱིན་འགྲུལ་གྱི་མཐུན་རྐྱེན་ཚུ་

མ་འོངས་པ་ལུ་ Pool ཡང་ན་ འགན་འཁྲི་འབག་མི་སྡེ་ཚན་གཞན་ཅིག་གིས་ ཕྱིར་འཐེན་འབད་ཚུགས་པའི་ སྔོན་གོང་, ཉེན་སྲུང་ཅན་གྱི་མཐུན་རྐྱེན་དང་ཡང་ན་ སྐྱིན་འགྲུལ་གྱི་ཐོན་སྐྱེད་གཞན་ཅིག་སྦེ་ ཚོང་འབྲེལ་འདི་སོ་སོར་སྦེ་ གྲོས་འདེབས་འབད་ནི་ཨིན། འདི་བཟུམ་མའི་ཚོང་ཆས་དེ་གིས་ ཁག་འབགཔ་ཚུ་ ངོ་སྤྲོད་འབད་བའི་ རྒྱབ་སྐྱོར་དང་ བྱ་བའི་གནད་སྤྱོད་ཀྱི་གནས་སྟངས་ དེ་ལས་ དངུལ་ཕོགས་དང་ དུས་ཡུན་ཚང་ཐོ་བཀོད་ཁྲལ་དང་ ཁེ་སང་ཚུ་གི་རྩིས་ཞིབ་དང་ བགོ་བཀྲམ་འབད་བ། ཟད་འགྲོ་མ་དངུལ་ལངམ་ ཡང་ཅིན་ རྩིས་འཛུལཝ་གི་ གནད་དོན་འདི་ཚུ་ གསལ་སྟོན་འབདཝ་ཨིན།

སྤྱིར་བཏང་གཏེར་ཁ་གཏང་ནི་དང་ གཏན་འཇགས་དངུལ་ཀྲམ་སྤྲོད་ནི་ དེ་ལས་ དངུལ་རྐྱང་བརྗེ་སོར་དང་ ཅ་དམ་རྟགས་ཚུ་ ངོ་སྤྲོད་འབད་ནི་ ཡང་ན་ བགོ་བཀྲམ་འབད་མི་དེ་གིས་ རང་གིས་རང་ལུ་ ཁས་བླངས་ཀྱི་འགན་ཁག་འདི་བཟོ་མི་ཚུགས།
