# བསམ་འཆར་དང་ཚིག་ཡིག་ཚུ་

Cosmo-Local Credit གིས་ལག་ལེན་དང་སྒོ་ཕྱེས་པའི་ཡིག་ཆའི་སྒྲིག་གཞི་ དེ་ལས་ རང་རང་སོ་སོ་སྦེ་འཛིན་སྐྱོང་འབད་མི་ pools ཚུ་དང་ ཐོ་བཀོད་ཐོག་ལས་ངོ་སྤྲོད་འབད་ཡོད་པའི་ ངོ་མ་གི་འགན་ཁུར་འདི་ཚུ་ མཐུད་སྦྲེལ་འབདཝ་ཨིན། འ་ནི་ཐེམ་པ་དེ་ཚུ་གིས་ གཅིག་ཁར་ལཱ་འབདཝ་ཨིན་རུང་ ཁོང་གཉིས་ཆ་ར་འདྲ་མཉམ་མེདཔ།

འ་ནི་ཤོག་ལེབ་འདི་ ཡིག་ཆ་ནང་ལག་ལེན་འཐབ་མི་ཚིག་ཡིག་ཚུ་ གསལ་བཀོད་འབདཝ་ཨིན། ཨེཔི་གི་མིང་རྟགས་དག་པ་ཅིག་ ངེས་པར་དུ་ཨེབ་གཏང་འབད་ཡོད་པའི་བརྡ་དོན་ནང་ལུ་མཐོང་དོ་ཡོདཔ་ད་ ཡོངས་འབྲེལ་འདི་གིས་ མིང་ཐུང་ཀུ་ ཡང་ན་ དབྱངས་ཅན་སྦེ་བཟོ་ཡོདཔ་ཨིན།

## ཏཱ་ལེན་དང་ ཅ་ཆས་ཚུ་

A **ཐོ་བཀོད་འབད་** ཐོ་ཀིན་འཕྲུལ་ཆས་ཚུ་གིས་ ཅ་དངོས་དང་ཞབས་ཏོག་ཚུ་ བསྒྱུར་བཅོས་འབད་ནི་དང་ དངུལ་ཕོགས་ལོག་སྤྲོད་ནི་ཚུ་ གཏང་ཚུགས་རུང་ ཁོང་རང་གིས་ ཁས་བླངས་མི་འབདཝ་ཨིན།

A **ཤོག་ལེབ་ཚུ་** འཁྲུན་ཆོད་དང་འཁྲིལཝ་ད་ གྲོས་བསྡུར་འབད་ནིའི་དོན་ལས་ ཐོ་བཀོད་འབད་མི་ཡིག་ཆ་ཚུ་ ངེས་གཏན་སྦེ་ བཙུགས་དགོཔ་ཨིན།

གཅིག་ **མཆོད་པ་ཕུལ་ནི་** ཅ་ཆས་དང་ ཞབས་ཏོག་ཚུ་གི་དོན་ལུ་ ཐོ་བཀོད་འབད་ཡོད་པའི་ཐོ་ཡིག་འདི་ཨིན། གྲོས་འདེབས་ཅིག་ གསར་བསྐྲུན་འབད་ནི་དེ་གིས་ ཌོག་ཊར་ཚུ་བཟོ་ནི་མེད་ ཡང་ན་ འཐོབ་ཚུགསཔ་སྦེ་སྟོན་ནི་དང་ ཡང་ཅིན་ བཀྲམ་སྤེལ་བྱུང་མི་དེ་ གསལ་བཀོད་མེདཔ།

འདི་ཚུ་དབྱེ་ཁག་བཞི་ཨིན།

1. གྲུབ་རྟགས་ཀྱི་འཆམ་ཡིག་དང་ གཏན་འཁེལ་ཚུ་
2. ཤོག་ལེབ་ཀྱི་མིང་དང་ གསལ་བསྒྲགས་འབད་ཡོད་པའི་གནས་ཚིག་ཚུ་
3. གྲོས་འདེབས་གྱི་ཐོ་ཡིག་གཅིག་ ཡང་ན་མང་ཤོས་ཅིག་དང་
4. དངུལ་ཁང་གི་དངོས་གནས་ཀྱི་ཐོན་སྐྱེད་ཚུ་
