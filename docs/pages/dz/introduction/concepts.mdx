## བཅའ་མར་གཏོགས་མི་འཚོལ་ནི་དང་འབྲེལ་བ་འཐབ་ནི་

ཚོང་ར་གིས་ འཛིན་ཤོག་ འབུལ་བའི་ཐོ་ དགོས་མཁོ་དང་དངུལ་ཁུངས་འཚོལ་ནི་ལུ་ཕན་ཐོགས། ཐོ་ཡོད་ནི་གི་གོ་དོན་འདི་ གློག་རིམ་གྱིས་ཐོ་སྟོན་ཚུགསཔ་ཨིན། བརྡ་དོན་ངོ་མ་ཨིན་ཟེར་ མཛོད་ཆས་ཡོད་ཟེར་ཡང་ན་སྤྲོད་ལེན་འགྲུབ་ངེས་ཟེར་མི་སྒྲུབ།

བཅའ་མར་གཏོགས་མི་གིས་དགོས་མཁོ་གསལ་བསྒྲགས་འབད་ཚུགས། ཡོད་པའི་འབྲེལ་བ་དང་འཕྲིན་ཞབས་ཏོག་ལས་གཞན་ལུ་འབྲེལ་བ་འཐབ་ཚུགས། འབྲེལ་བའི་ཞུ་བ་ འཕྲིན་ སྔོན་བཀག་གྲོས་བསྟུན་ཡང་ན་དགོས་མཁོ་ལུ་ལན་བྱིན་ནི་གིས་རྐྱངམ་ཅིག་ འོག་གི་ལཱ་ཚུ་མི་འབད།

- འཛིན་ཤོག་ཡང་ན་འབུལ་བའི་ཐོ་ངོས་ལེན་འབད་ནི།
- སྤོ་ནི་ཡང་ན་དངུལ་ཁུངས་བརྗེ་སོར་གནང་བ་བྱིན་ནི།
- ཅ་ཆས་སྐྱེལ་ཡོདཔ་ཡང་ན་ཡིད་ཚིམས་ཡོདཔ་སྒྲུབ་ནི།
- འཛིན་ཤོག་ཁས་ལེན་སྒྲུབ་ནི་ཡང་ན་མཇུག་བསྡུ་ནི།
- བཅའ་མར་གཏོགས་མི་གི་གྲོས་འཆམ་ནང་ GEF ཆ་ཤས་ཅིག་སྦེ་བཟོ་ནི།

## འཛིན་ཤོག་ ཊོ་ཀེན་དང་འབུལ་བའི་ཐོ་

**ཊོ་ཀེན** འདི་ blockchain ནང་གི་ལྷག་ལུས་ཡང་ན་ཌི་ཇི་ཊལ་རྒྱུ་དངོས་ཨིན། ཊོ་ཀེན་གྱི་ཐབས་ལམ་གྱིས་ བཏོན་པའི་གྲངས་འབོར་ སྤོ་ནི་ དུས་ཡུན་རྫོགས་ནི་དང་མེདཔ་གཏང་ནི་ཐོ་བཀོད་འབད་ཚུགས། འདི་ཚུ་གིས་རྐྱངམ་ཅིག་ ཅ་ཆས་ ཞབས་ཏོག་ དངུལ་སྨར་ལུ་བརྗེ་ནི་ཡང་ན་ལག་ལེན་ལུ་ལོག་ལེན་ནིའི་ཁས་ལེན་མི་བྱིན།

**འཛིན་ཤོག** འདི་ གསར་བཏོན་པ་གིས་གསལ་བསྒྲགས་གནས་ཚིག་འོག་ལུ་ལག་ལེན་འཐབ་ཚུགས་པའི་ཁས་ལེན་སྦེ་སྟོན་མི་ཊོ་ཀེན་ཡང་ན་ཐོ་ཨིན། གནས་ཚིག་ནང་ ཁས་ལེན་ག་ཅི་ འགན་ཁུར་ག་ལུ་ ག་ཏེ་དང་ནམ་ཕུལ་ཚུགས་ནི་ ཁག་ཆེ་བའི་ཚད་དང་ཁས་ལེན་སྒྲུབ་ནི་དང་ཉོག་བཤད་བྱ་རིམ་བཀོད་དགོ།

**འབུལ་བའི་ཐོ་ (Offering)** འདི་ འཛིན་ཤོག་དང་འབྲེལ་ཡོད་ཅ་ཆས་ཡང་ན་ཞབས་ཏོག་གི་ཐོ་གཞུང་ཐོ་ཨིན། སྤྱིར་བཏང་ཁ་སླབ་ནང་གི་ “འབུལ་བ” འདི་མི་གཅིག་གིས་ཕུལ་མི་གྲོས་འཆར་ལུ་གོཝ་ཨིན། **Offering** འདི་གློག་རིམ་གྱི་ཐོའི་མིང་ཨིན།

## འགན་འཁྲི་ཅན་གྱི་འགན་ཁུར་དང་འཕྲུལ་རིག་དབང་འཛིན་

| --- | --- |
| **གསར་བཏོན་པ** | འཛིན་ཤོག་ཁས་ལེན་གསལ་བསྒྲགས་འབད་དེ་བསྒྲུབཔ་ཨིན། གན་རྒྱའི་ཇོ་བདག་སོར་ནི་གིས་རྐྱངམ་ཅིག་ འགན་ཁུར་འདི་རང་བཞིན་གྱིས་མི་སྤོ། |
| **དངུལ་ཁུངས་ཀྱི་འཛིན་སྐྱོང་པ** | ལམ་ལུགས་གསལ་བསྒྲགས་དང་འཛིན་སྐྱོང་འབདཝ་ཨིན། དངུལ་ཁུངས་ཀྱིས་གསལ་རི་རི་སྦེ་བཀོད་མི་འགན་ལེན་ལུ་འགན་ཁུར་གནས་སྡོདཔ་ཨིན། |
| **དངུལ་ཁུངས་ཀྱི་ཇོ་བདག** | ད་ལྟོ་ `SwapPool` ཇོ་བདག་གི་དབང་ཆ་ཡོད་མི་ཁ་བྱང། སྒྲིག་སྟངས་ གླ་འཐུས་བསྡུ་ནི་དང་ཡོད་པའི་རྒྱུ་དངོས་ཕྱིར་བཏོན་ནི་ཚུ་ཚུདཔ་ཨིན། |
| **མཚན་རྟགས་མང་པོ་བཀོད་མི** | མཚན་རྟགས་མང་པོ་ཅན་གྱི་དངུལ་ཁུག་ལུ་བྱིན་མི་འཕྲུལ་རིག་དབང་ཆ་བགོཝ་ཨིན། མཚན་རྟགས་བཀོད་མི་ཡང་ན་དགོས་མཁོའི་གྲངས་སོར་ནི་གིས་ གསར་བཏོན་པ་གི་འགན་ཁུར་ འཛིན་སྐྱོང་པ་གི་ལཱ་འགན་ཡང་ན་ཁྲིམས་ཀྱི་བདག་དབང་གསང་བའི་ཐོག་ལས་མི་སྤོ། |
| **བརྒྱུད་ཚབ་བདག་སྐྱོང་པ** | བརྒྱུད་ཚབ་གན་རྒྱའི་ལག་ལེན་ཡར་སེང་འབད་ཚུགས། དངུལ་ཁུངས་ཇོ་བདག་ལས་མ་འདྲཝ་འོང་ཚུགས། |
| **རྒྱབ་རྟེན་དབང་འཛིན་པ** | ཐོ་གཞུང་ ཚད་བཀག་པ་ གོང་ཚད་རྩིས་པ་ ཨོ་ར་ཀཱལ་ གླ་འཐུས་ལམ་ལུགས་ཡང་ན་ལམ་ལུགས་གླ་འཐུས་དབང་འཛིན་པ་ལུ་དབང་འཛིན་འབདཝ་ཨིན། |
| **ཐོ་གཞུང་བདག་སྐྱོང་པ** | གན་རྒྱ་ ལྷག་ལུས་དང་ blockchain ལོ་རྒྱུས་མ་བཏོན་པར་ ཐོ་གཞུང་གི་ཐོ་བཅོ་ནི་ སྦ་ནི་ ལག་ལེན་ལས་ཕྱིར་བཏོན་ནི་དང་ལོག་བཙུགས་ནི་འབད་ཚུགས། |
| **གླ་འཐུས་ལེན་མི** | གདམ་ཁ་རྐྱབ་ཡོད་པའི་དངུལ་ཁུངས་ཡང་ན་ལམ་ལུགས་གླ་འཐུས་ལེནམ་ཨིན། འཛིན་སྐྱོང་པ་ཡང་ན་ཇོ་བདག་ཨིན་དགོཔ་མེད། |
| **རྒྱབ་སྐྱོར་འབད་མི་ཡང་ན་རྒྱུ་དངོས་བྱིན་མི** | སོ་སོ་གསལ་བསྒྲགས་གནས་ཚིག་འོག་ལུ་རྒྱུ་དངོས་བྱིནམ་ཨིན། ད་ལྟོའི་ `SwapPool` གིས་རང་བཞིན་གྱིས་བགོ་བཤའ་ ལོག་ཐོབ་ནི་ ཕྱིར་བཏོན་ནི་ གསོལ་རས་ཡང་ན་སྐྱོང་སྲིད་ཐོབ་དབང་མི་བཟོ། |

## ལཱ་དང་འཚོ་རིམ་

| གློག་རིམ་ཡང་ན་ཡིག་ཆའི་ཚིག | གོ་དོན |
| --- | --- |
| **འཛིན་ཤོག་བཟོ་ནི་ཡང་ན་གསལ་བསྒྲགས** | ཊོ་ཀེན་གཞི་བཙུགས་ཡང་ན་སྒྲིག་སྟངས་བཟོ་སྟེ་ ཐོ་གཞུང་དང་གནས་ཚིག་གསལ་བསྒྲགས་འབད་ནི། |
| **གསར་བཏོན་འབད་ནི** | གདམ་ཁ་རྐྱབ་ཡོད་མི་ཇོ་བདག་ཡང་ན་འབྲི་མིའི་དབང་ཆ་འོག་ལུ་ཊོ་ཀེན་ལྷག་ལུས་བཟོ་ནི། |
| **འབུལ་བའི་ཐོ་གསལ་བསྒྲགས** | འཛིན་ཤོག་འོག་ལུ་ཅ་ཆས་ཡང་ན་ཞབས་ཏོག་གི་ཐོ་ཁ་སྐོང་ནི། |
| **དགོས་མཁོ་གསལ་བསྒྲགས** | འཚོལ་ཞིབ་དང་འབྲེལ་བ་དོན་ལུ་དགོས་མཁོ་བཤད་ནི། འདི་གིས་རྐྱངམ་ཅིག་སྤྲོད་ལེན་མི་བཟོ། |
| **གཏང་།** | ཊོ་ཀེན་གྱི་ལྷག་ལུས་ཁ་བྱང་གཞན་ལུ་སྤོ་ནི། |
| **“བསྐྱར་ཉོ།”** | ཊོ་ཀེན་ཇོ་བདག་གི་ཁ་བྱང་ཧེ་མ་ལས་བཀོད་མི་བཏང་བྱ་ཁ་ཕྱེ་ནི། འདི་ལག་ལེན་འཐབ་ནི་ལུ་ཕུལ་ནི་ཨིན། ཁས་ལེན་སྒྲུབ་ཚར་ཟེར་མི་སྒྲུབ། |
| **ཁས་ལེན་སྒྲུབ་ནི** | གསར་བཏོན་པ་གིས་ ཁས་བླངས་པའི་ཅ་ཆས་ ཞབས་ཏོག་ ཁེ་ཕན་ཡང་ན་ལཱ་གཞན་བྱིན་ནི། |

## གནས་གོང་ ཡིད་རྟོན་ ཚད་དང་གླ་འཐུས་

གནས་གོང་གི་ཚིག་འདི་ཚུ་སོ་སོ་བཞག།

- **འབུལ་བའི་གོང་ཚད:** ཐོ་གཞུང་ནང་གི་ཅ་ཆས་ཡང་ན་ཞབས་ཏོག་དོན་ལུ་ཞུ་མི་གྲངས་འབོར།
- **འཛིན་ཤོག་གི་བཀོད་ཡོད་གནས་གོང:** གསར་བཏོན་པ་གི་གསལ་བསྒྲགས་གནས་ཚིག་ནང་གི་གནས་གོང།
- **དངུལ་ཁུངས་བརྗེ་སོར་གོང་ཚད་ཡང་ན་གྲོས་འཆར:** དངུལ་ཁུངས་ཀྱི་གོང་ཚད་རྩིས་པ་གིས་བཟོ་མི་སྤྲོད་ལེན་གཞི་གྲངས།
- **ཨོ་ར་ཀཱལ་གཞི་བཞག:** གནས་གོང་རྩིས་གྱི་གྲུབ་ཆ་ནང་ལག་ལེན་འཐབ་མི་ཕྱིའི་གནས་སྡུད།
- **ལག་ལེན་གྱི་གནས་ཚིག:** གསར་བཏོན་པ་གིས་ག་ཅི་དང་གནས་ཚིག་ག་ཅིའི་འོག་ལུ་ཁས་ལེན་འབདཝ་ཨིན་ན།

གློག་རིམ་ནང་གི་ **ཡིད་རྟོན།** འདི་ ཐོབ་ཚུགས་པའི་ཁས་ལེན་དང་བརྗེ་སོར་གྱི་ནུས་པ་ལུ་གོཝ་ཨིན། འདི་རང་བཞིན་གྱིས་སྒེར་གྱི་བུ་ལོན་ སྐྱིན་འགྲུལ་ གསར་བཏོན་པ་གི་ནུས་པའི་བརྟག་ཞིབ་ཡང་ན་འགན་ལེན་མེན།

**“ཡིད་རྟོན་ཚད།”** གིས་ དངུལ་ཁུངས་ཀྱི་ཊོ་ཀེན་ལྷག་ལུས་ཚད་ལུ་གོཝ་ཨིན། བཙུགས་ཚར་ཞིནམ་ལས་ ཊོ་ཀེན་འདི་ག་དེ་ཅིག་མང་ཤོས་བཞག་ཚུགསཔ་ཨིན་ན་འདི་ཨིན། དེབ་དཀར་ནང་གྲོས་འཆར་གྱི་དུས་མཚམས་ཅན་ རྩིས་ཐོ་དང་ཡོངས་འབྲེལ་ཡོངས་ཀྱི་ཚད་ཚུ་ ཐབས་ལམ་སོ་སོ་ཨིན།

Protocol v1.1.0 གིས་ དངུལ་ཁུངས་བརྗེ་སོར་རེ་རེ་ལུ་ **དངུལ་ཁུངས་ཀྱི་གླ་འཐུས** དང་ཁ་སྐོང་ **ལམ་ལུགས་ཀྱི་གླ་འཐུས** ལེན་ཚུགས། ལམ་བརྒྱུད་བརྗེ་སོར་ནང་རིམ་པ་རེ་རེ་དོན་ལུ་གཉིས་ཆ་ར་ཁ་གསལ་སྟོནམ་ཨིན། ད་ལྟོའི་གློག་རིམ་གྱིས་ལམ་བརྒྱུད་ཞབས་ཏོག་གླ་འཐུས་སོ་སོ་མི་བཀལ། དེབ་དཀར་གྱི་གྲོས་འཆར་ནང་ མ་འོངས་པའི་ཡོངས་འབྲེལ་བགོ་བཤའ་དང་ཞབས་ཏོག་གླ་འཐུས་ཡོད་ཚུགས་པའི་སྐོར་ལས་སོ་སོ་བཤད་ཡོད།

## ལམ་དང་རྒྱུ་དངོས་ཡོད་ཚད་

**ལམ** འདི་ རང་སོའི་སྐྱོང་སྲིད་ཡོད་པའི་དངུལ་ཁུངས་གཅིག་ཡང་ན་ལེ་ཤ་བརྒྱུད་པའི་རིམ་པ་ཅན་གྱི་ལམ་ཨིན། **ལམ་གྱི་གཏིང་ཚད** འདི་ལམ་ནང་གི་དངུལ་ཁུངས་བརྗེ་སོར་གྱི་གྲངས་ཨིན།

འཛིན་ཤོག་ དངུལ་ཁུངས་དང་དངུལ་ཁུག་ལ་ལུ་ལམ་བརྒྱུད་དོན་ལུ་འོས་འབབ་མེད། དངུལ་ཁུངས་ནང་འཛིན་ཤོག་ཡོད་ནི་གིས་ ལམ་ག་ར་བརྒྱུད་དེ་ཐོབ་ཚུགསཔ་རང་བཞིན་གྱིས་མི་བཟོ། ད་ལྟོའི་འོས་འབབ་ལམ་ལུགས་དང་སྒྲིག་སྟངས་ཚུ་ [མཉེན་ཆས་ཀྱི་ལམ་བརྒྱུད་ཡིག་ཆ](https://software.cosmolocal.credit/contracts/routing) ནང་དབྱིན་སྐད་ལུ་ཡོད།

**ཡོད་པའི་རྒྱུ་དངོས** འདི་ དངུལ་ཁུངས་ཀྱིས་ད་ལྟོའི་ལམ་ལུགས་ ཚད་དང་གླ་འཐུས་འོག་ལུ་བྱིན་ཚུགས་པའི་མཛོད་ཆས་ཨིན། དངུལ་ཁུངས་གཉིས་འབྲེལ་ལམ་ཡོད་ནི་གིས་ དགོ་པའི་གྲངས་འབོར་ཡོད་ཟེར་མི་སྒྲུབ། མཐའ་མའི་གོང་ཚད་གྲོས་འཆར་བསྐྱར་ཞིབ་འབད། འདི་དུས་ཡུན་རྫོགས་ནི་ཡང་ན་དངུལ་ཁུངས་གནས་སྟངས་སོར་ནི་གིས་ཆ་མེད་འགྱོ་ཚུགས།

ད་ལྟོའི་ལམ་ལག་ལེན་འདི་ བོ་ལོག་ཆེན་གཅིག་གུ་དངུལ་ཁུག་ལས་འགོ་བཙུགསཔ་ཨིན། སྐྱོང་སྲིད་གཅིག་ཁར་མི་སྦྱོར་ མཛོད་ཆས་རང་བཞིན་ཆ་སྙོམས་མི་འབད་ མི་ལེ་ཤའི་འགན་ཁུར་མི་སེལཝ་དང་ཁས་ལེན་སྒྲུབ་ཚར་ཟེར་མི་སྒྲུབ། བོ་ལོག་ཆེན་སོ་སོའི་ HTLC ཡང་ན་བདག་གཉེར་ལམ་ རང་བཞིན་ཆ་སྙོམས་དང་བསྡམས་ཚན་ཕན་ཚུན་བསྡུ་རྩིས་ཚུ་ གྲོས་འཆར་ཡང་ན་གཞི་བཙུགས་ལུ་བརྟེན་ཡོད།
