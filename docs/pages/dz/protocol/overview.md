# ལམ་ལུགས་

**ཁས་ལེན་མཉམ་སྤྱོད་ཀྱི་ལམ་ལུགས་ (CPP)** གིས་ རང་སོའི་སྐྱོང་སྲིད་ཡོད་མི་མཉམ་སྤྱོད་དངུལ་ཁུངས་ཚུ་གིས་ འཛིན་ཤོག་གདམ་ཁ་རྐྱབ་ནི་ བརྗེ་སོར་གྱི་ལམ་ལུགས་གསལ་བསྒྲགས་འབད་ནི་དང་ བརྗེ་སོར་འབད་ཚུགསཔ་བཟོ་ནི་ཚུ་ འགྲེལ་བཤད་འབདཝ་ཨིན། ཤུལ་ལས་ འཛིན་ཤོག་འཆང་མི་གིས་ གསར་བཏོན་པ་ལུ་འཛིན་ཤོག་ལག་ལེན་འཐབ་སྟེ་ ཁས་བླངས་པའི་ཅ་ཆས་ཡང་ན་ཞབས་ཏོག་ལེནམ་ཨིན། འདི་ཚུ་རིམ་པ་སོ་སོ་ཨིནམ་མ་ཚད་ འགན་ཁུར་ཚུ་ཡང་སོ་སོ་ཨིན།

དྲ་ཚིགས་འདི་གིས་ གོ་དོན་འདི་ཚུ་དང་ CLC App ལག་ལེན་འཐབ་ཐངས་འགྲེལ་བཤད་འབདཝ་ཨིན། [CLC མཉེན་ཆས་ཀྱི་ཡིག་ཆ](https://software.cosmolocal.credit/) འདི་ མཉེན་ཆས་ལག་ལེན་བསྟར་ཐངས་ གན་རྒྱ་ API གཞི་བཙུགས་དང་ལག་ལེན་གྱི་དོན་ལུ་ གཞི་བཞག་སའི་ངོ་མའི་ཡིག་ཆ་ཨིན། ད་ལྟོ་དབྱིན་སྐད་ནང་ཡོད།

མཉམ་རུབ་ཀྱི་ཚིག་དོན་ཚུ་ཤེས་ནི་ལུ་ [གོ་དོན་དང་ཚིག་མཛོད](/dz/introduction/concepts) ལས་འགོ་བཙུགས། བཟོ་བཀོད་དང་གྲོས་འཆར་རྒྱ་ཆེ་དྲགས་ཀྱི་དོན་ལུ་ [དེབ་དཀར](/dz/white-paper) ལྷག།

## གཞི་བཙུགས་འབད་ཐངས་

མི་སྡེ་དང་ལས་སྡེ་མ་འདྲཝ་ཚུ་གིས་ རང་སོའི་ལམ་ལུགས་འོག་ལུ་ མཐུན་སྒྲིག་ཡོད་པའི་མཉེན་ཆས་ལག་ལེན་འཐབ་ཚུགས། Grassroots Economics Foundation གིས་ [མི་མང་གི་ CLC App](https://cosmolocal.credit) ལག་ལེན་འཐབ་ཨིན། གཞི་བཙུགས་རེ་རེ་ནང་ ལག་ལེན་འཐབ་མི་ གན་རྒྱ་དང་འགན་འཁྲི་ཅན་གྱི་དབང་འཛིན་ཚུ་གསལ་བཤད་འབད་དགོ།

གན་རྒྱའི་ཁ་བྱང་ གཞི་བཙུགས་ཀྱི་ལམ་སྟོན་ ཇོ་བདག་དང་ཡར་སེང་གི་དབང་ཆ་བདེན་དཔྱད་འབད་ཐངས་ཚུ་གི་དོན་ལུ་ [གཞི་བཙུགས་དང་བདེན་དཔྱད](https://software.cosmolocal.credit/contracts/deployments) ལྷག། རྒྱབ་སྐྱོར་ཞབས་ཏོག་ལག་ལེན་འཐབ་ནི་ལུ་ [CLC Core API](https://software.cosmolocal.credit/core-api/) ལས་འགོ་བཙུགས།

## གློག་རིམ་ནང་ལམ་བརྒྱུད་བརྗེ་སོར་

འོས་འབབ་ཅན་གྱི་ལམ་ཡོད་པའི་སྐབས་ གློག་རིམ་གྱིས་ བཅའ་མར་གཏོགས་མི་ལུ་ མཉམ་སྤྱོད་དངུལ་ཁུངས་ལེ་ཤ་བརྒྱུད་དེ་བརྗེ་སོར་འབད་ནི་ལུ་ཕན་ཐོགས། བཅའ་མར་གཏོགས་མི་གིས་ གོང་ཚད་གྲོས་འཆར་བསྐྱར་ཞིབ་འབད་དེ་ བརྗེ་སོར་གྱི་གནང་བ་བྱིནམ་ཨིན། དངུལ་ཁུངས་རེ་རེ་གི་ ལམ་ལུགས་དང་འགན་འཁྲི་ཅན་གྱི་མི་ཚུ་སོ་སོ་སྦེ་སྡོདཔ་ཨིན།

བཅའ་མར་གཏོགས་མི་གི་དོན་ལུ་ག་དེ་སྦེ་ཨིན་ན་ཤེས་ནི་ལུ་ [ལམ་དང་འགན་ཁུར](/dz/protocol/network) ལྷག། མཉེན་ཆས་ཀྱིས་ལམ་གོང་ཚད་རྩིས་རྐྱབ་སྟེ་ལག་ལེན་འཐབ་ཐངས་ཀྱི་དོན་ལུ་ [ལམ་བརྒྱུད་ཀྱི་ལག་ལེན](https://software.cosmolocal.credit/contracts/routing) ལྷག།
