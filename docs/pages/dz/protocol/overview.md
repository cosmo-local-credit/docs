## གཞི་བཙུགས་འབད་ཐངས་

གནས་སྟངས་ཅན་གྱི་ མདོ་སྡེ་མང་ཤོས་ཅིག་ འགོ་འདྲེན་འཐབ་ཨིན། **ERC-1967 བརྒྱུད་ཚབ་ཀྱི་ལེའུ་ཚུ་** Solady གི་ `ERC1967Factory` གྱི་ཐོག་ལས་ ལག་ལེན་འཐབ་ཚུགས། ལས་རིམ་མང་ཤོས་ཅིག་གིས་ལག་ལེན་ཚུ་བགོ་བཤའ་བརྐྱབ་ཚུགསཔ་ཨིན། འདི་ཡང་ བདག་འཛིན་པ་སོ་སོ་དང་ སྒྲིག་གཞི་ དེ་ལས་ གནས་སྡུད་སོ་སོར་ལུ་ བཞག་སྟེ་ཡོདཔ་ཨིན། བགོ་བཀྲམ་འབད་བའི་ཧེ་མར་ཁ་བྱང་ཚུ་ སྔོན་འགོག་འབད་ཚུགས་པའི་དོན་ལུ་ དངོས་གྲུབ་ཅན་གྱི་ ཚྭ་ཚུ་ཡང་ ལག་ལེན་འཐབ་འོང་།

ཁག་ཆེམས་ཁག་ག་ར་གི་ཚབ་མ་ལུ་ བྱིན་མི་ཚུགས།`DecimalQuoter`དང་`SwapRouter`གཞུང་མིན་གྱི་ ཐབས་ལམ་ཚུ་ཨིན།`RescueVault`དང་`ERC1967Factory`འདི་ཡང་ཐད་ཀར་དུ་ལག་ལེན་འཐབ་ཡོདཔ་ཨིན། ལྷག་ལུས་ stateful ཚད་གཞི་ཚུ་ འོག་ལུ་ལུ་བཀོད་རྒྱ་འབད་ཡོདཔ་ proxy ལག་ལེན་གྱི་དོན་ལུ་བཟོ་ཡོདཔ་ཨིན།

Proxy འདྲ་ཕབ་སོ་སོ་རེ་གིས་ ལག་ལེན་དེ་ བསྒྱུར་བཅོས་འབད་ཚུགས་མི་ བདག་འཛིན་པ་ཅིག་ཡོདཔ་ཨིན། Proxy འཛིན་སྐྱོང་འདི་ ཁག་འབགཔ་གི་བདག་དབང་ལས་ཁ་འཕྱལ་ཏེ་ཡོད་མི་དེ་དང་བསྟུན་པའི་སྒོ་སྒྲིག་ལུ་བཅའ་མར་གཏོགས་དགོཔ་ཨིན། ཡར་དྲག་གཏང་ནི་གྱིས་ བྱ་སྤྱོད་ཚུ་ འགྱུར་བཅོས་འབད་ཚུགས། འདི་འབདཝ་ལས་ལག་ལེན་འཐབ་མི་ཚུ་གིས་ Pool གི་བཟོ་བཀོད་མ་ཚར་བའི་ཤུལ་ལས་ཡང་ གནས་སྟངས་བསྒྱུར་བཅོས་འབད་འོང་། འདི་གིས་འབད་ ཁོང་གཉིས་ཆ་ར་གིས་ Pool གི་ཇོ་བདག་དང་ proxy admins གཉིས་ཆ་རང་ལུ་བརྟག་དཔྱད་འབད་དགོ།

འདི་ལུ་བཏོན་མི་`GiftableToken`, ཟུར་ཐོ་གསུམ་`OracleRelay`, `Limiter`ཐོ་བཀོད་དང་ཐོ་ཡིག་ལེ་ཤ་ཅིག་རང་`Splitter`, `EthFaucet`, `PeriodSimple`དེ་ལས་EIP-165རྒྱབ་སྐྱོར་དེ་ཡང་ མཁོ་སྤྲོད་གི་ཐད་ལུ་དམིགས་ཏེ་ཨིནམ་ལས་ འཛམ་གླིང་ཡོངས་ཀྱི་མ་ཨིན།`RescueVault`. `SwapPool`, `SwapRouter`, `FeePolicy`, `ProtocolFeeController`དེ་ལས་`CAT`ཁ་གསལ་མ་གཏང་`supportsInterface`v1ནང་ལུ་1.0.
