བཀྲམ་སྤེལ་འབད་ཡོད་པའི་ རྒྱགས་ཤོག་འདི་གིས་ **འབྱུང་ཚུགས་པའི་ གིརཕ་ལམ་** བཟོ་ནི་ཨིནམ་ལས་ ངེས་གཏན་གྱི་ ལམ་འདི་མེན། བཟོ་སྐྲུན་གྱི་ CLC Core ཞབས་ཏོག་གིས་ མཉམ་སྤྱོད་དངུལ་ཁུངས།, ཐོ་བཀོད་ལས་རིམ་དང་ དབྱེ་རིམ་ དེ་ལས་ ཚད་གཞི་འཐུས་ཀྱི་རྩིས་ཁྲ་ཚུ་ བཞག་དོ་ཡོདཔ་ཨིན། དེ་མ་ཚད་ session wallet གི་གནད་དོན་ཡོད་མི་ཚུ་ཡང་ བརྟག་ཞིབ་འབདཝ་ཨིན། མི་མང་གི་ཁ་ཐུག་ལས་ ད་རེས་ནངས་པར་ མཉམ་སྤྱོད་དངུལ་ཁུངས། swap ཐབས་ལམ་གསུམ་དེ་ཅིག་ འཚོལ་དོ་ཡོདཔ་ཨིན།

བཟོ་བསྐྲུན་གྱི་ལམ་རིམ་འདི་གིས་ དམིགས་བསལ་གྱིས་ ཐད་ཀར་དུ་ཁ་སྐོང་བསྐྱར་གསོ་འབད་མི་ལས་ལྷག་སྟེ་ ཐོབ་ཐང་གི་ཁྱད་རྣམ་ཆུང་ཀུ་ཅིག་ལག་ལེན་འཐབ་དོ་ཡོདཔ་ཨིན། བདེན་དཔྱད་འབད་དེ་ གོང་ཚད་དང་འབྲེལ་བའི་སྤོ་བཤུད་འབད་མི་ཏོག་ཀ་ཚུ་རྐྱངམ་ཅིག་བཀོད་དེ་ཡོདཔ་ཨིན། `GiftableToken` ཤོག་བྱང་དང་ ཕྱི་ཁ་གི་ཨི་ཨེསི་ཀ-20 ཀྲི་ཀཱན་ཚུ་ གསལ་ཏོག་ཏོ་སྦེ་བཀོད་དེ་ཡོདཔ་དང་ འདི་ཚུ་ཡང་ `router.plain_erc20` བཟོ་བཀོད་ནང་ལུ་ཐོ་བཀོད་འབད་དེ་ཡོདཔ་ཨིན་མས། དེ་འབདཝ་ལས་ ཀྲོ་ཀེན་འདི་ ལག་ལེན་གྱི་གནས་ཚད་ཀྱི་ལམ་རིམ་ནང་ལུ་ འོས་འབབ་མེད་རུང་ ཐད་ཀར་དུ་ པཱུལ་ཨིསི་ཝ་པི་གི་ནང་ལུ་ལག་ལེན་འཐབ་བཏུབ་ཨིན།

གིརཕ་ཐོབ་ནི་དེ་ མགྱོགས་པ་རང་ཨིན་རུང་ ཨེན་ཌེ་ཀེསི་འབད་ཡོད་པའི་ས་སྒོ་འདི་བཟུམ་ཅིག་སྦེ་ ཆ་བཞགཔ་ཨིན། གྲུབ་འབྲས་འདི་ རྙིངམ་སྦེ་ཐོ་བཀོད་འབད་ཡོདཔ་དང་ མཐུད་སྦྲེལ་གྱིས་ འདོད་པའི་ཨང་གྲངས་དེ་ བཏོན་ཚུགསཔ་ཨིན་ཟེར་ བདེན་ཁུངས་མི་བྱིན་པས། App གི་ **Credit** filter གིས་ ཚོང་ར། དང་ འབྲེལ་བ་ཡོད་པའི་འཚོལ་ཞིབ་ཀྱི་ཨེབ་རྟ་ཚུ་གི་དོན་ལུ་ འཐོབ་ཚུགས་པའི་སྒྲིག་བཀོད་འདི་ལག་ལེན་འཐབ་ཨིན།

### གཏན་འཁེལ་གྱི་བཀོད་རྒྱ་

ཆིངས་ཡིག་གི་བདག་པོ་གིས་ སྤུས་ཚད་ཅན་གྱི་དངུལ་འབོར་འདི་ གདམ་ཁ་རྐྱབ་སྟེ་ གནས་ས་ཅིག་ནང་ལུ་ ལེན་ཚུགས་ནི་ཨིན་མས། དངུལ་འབབ་སོ་སོ་སྦེ་བཞག་མི་གི་གནས་སྟངས་ནང་ལུ་ གྱངས་ཁ་ཡར་སེང་འགྱོ་མི་གི་དངུལ་འབབ་འདི་ འ་ནི་ལམ་རིམ་ལས་ བཀག་ཆ་འབད་བཞག་དོ་ཡོདཔ་མ་ཚད་ ལྷག་ལུས་ཀྱི་དངུལ་འབབས་འདི་ཡང་ ཕྱིར་བཏོན་འབད་ནི་གི་དབང་ཚད་འདི་ ད་རེས་ནངས་པ་ཡང་ཡོད་དེ། བཅའ་མར་གཏོགས་མི་ཚུ་གིས་ ཁྱིམ་བདག་དང་ ངོ་ཚབ་འཛིན་སྐྱོང་ རེ་བ་སྐྱེད་དེ་ཡོད་པའི་ཚད་འཛིན་ཚུ་ བལྟ་བརྟོག་འབད་དགོཔ་དང་ གནས་སྡུད་བསྡུ་གསོག་འབད་མི་གི་གནས་སྟངས་ ཁྲལ་ལེན་མི་ཚུ་དང་ དཔར་བསྐྲུན་འབད་དེ་ཡོད་མི་སྡེ་ཚན་གྱི་ཁྲིམས་ལུགས་ཚུ་ལུ་ བློ་གཏད་མ་འབད་བའི་ཧེ་མ་ སྡེ་ཚན་འདི་ལུ་བརྟེན་ཏེ་སྡོད་དགོཔ་ཨིན།
