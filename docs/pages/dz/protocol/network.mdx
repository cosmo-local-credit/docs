ཐོ་བཀོད་, limiter, quoter, fee policy དང་ protocol-fee controller འདི་ གདམ་ཁ་རྐྱབས་ཅིག་ཨིན། register མེད་པ་ཅིན་ tokens གིས་ འཛུལ་ཞུགས་ཀྱི་བརྟག་དཔྱད་འདི་མཐར་འཁྱོལ་ཚུགས། limiter མེད་པའི་བསྒང་ལས་ དངུལ་ཕོགས་ཚུ་ ངེས་བསྡུར་མེདཔ་ཨིན། quoter མིན་འདུག་པ་ཅིན་ Pool གིས་ raw-unit parity ལག་ལེན་འཐབ་དོ་ཡོདཔ་ཨིན། fees modules མིན་མེད་པ་ཅིན་ འོས་འབབ་དེ་ ༠ ཨིན་པས།

ཟུར་བཞག་འབད་ཚུགས་པའི་ས་སྒོ་ལྔ་འདི་`feePolicy`, `feeAddress`, `quoter`, `tokenRegistry`དེ་ལས་`tokenLimiter`སྦྲགས་ཐིའུ་འདི་ ད་ལྟོའི་ Pool གི་བདག་འཛིན་གྱིས་ འདི་གི་ཁ་བྱང་དེ་ Setter གིས་ བསྒྱུར་བཅོས་འབད་མ་ཚུགསཔ་ཨིན་རུང་ འདི་གིས་ dependence གི་ ནང་འཁོད་གནས་སྟངས་ལུ་ ཐིམ་ཕུག་མེདཔ།`protocolFeeController`ཁ་བྱང་དང་`feesDecoupled`ཐབས་ལམ་དེ་སེལ་འཐུ་འབད་མ་ཚུགསཔ་ཨིན། འདི་ཡང་རྫོང་ཁའི་མཐར་འཁྱོལ་བའི་ནུས་ཤུགས་འདི་ སྦྲེལ་ཐིག་ལས་སོ་སོ་སྦེ་ཡོདཔ་ཨིན།

ཟད་འགྲོ་བཏང་མི་དངུལ་ཁང་གི་བདག་འཛིན་པ་གིས་ གྲོང་གསེབ་ནང་ཡོད་པའི་ དངུལ་ཕོགས་ཚུ་ གདམ་ཁ་རྐྱབ་པའི་ཁ་བྱང་ལུ་ ལོག་ལེན་འབད་ཚུགས། བསྡུ་སྒྲིག་འཐུས་མེད་པའི་གནས་སྟངས་ནང་ལུ་ འཁྲུན་ཆོད་ཅན་གྱི་གླ་ཆ་འདི་ ལམ་དེ་ནང་ལས་བཞག་ཡོདཔ་ཨིན། ལྷག་ལུས་ཡོད་མི་ ཏི་རུ་དེ་ཚུ་ ལོག་ལེན་ནི་གི་དབང་ཆ་དེ་ ད་ལྟོ་ཡང་ ཡོདཔ་ཨིན། བཅའ་མར་གཏོགས་མི་ཚུ་གིས་ སྒོ་ནོར་གྱི་བདག་འཛིན་འཐབ་མི་དང་ བརྒྱུད་ཚབ་ལག་ལེན་འགོ་དཔོན་ དེ་ལས་ འགན་འཁྲི་བཅོལ་བའི་ལས་བྱེདཔ་ཚུ་ ལྟ་རྟོག་འབད་དགོཔ་ཨིན།
