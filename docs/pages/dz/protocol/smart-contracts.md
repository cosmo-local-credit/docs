# མཁས་མཆོག་གི་འཆམ་ཡིག་ཚུ་

འ་ནི་ཤོག་ལེབ་འདི་ Protocol v1.1.0 ནང་གི་ Pool དང་ Voucher གི་གདམ་ཁ་ངོ་མ་ཚུ་ གསལ་བཀོད་འབདཝ་ཨིན། གྲོས་ཆོད་ཀྱི་ བྱ་སྤྱོད་འདི་གིས་ རྩིས་ཁྲ་བཟོ་ནི་གི་འཕྲུལ་ཆས་ལག་ལེན་འཐབ་དོ་ཡོདཔ་ཨིན། དེ་གིས་ emitter གྱི་གསལ་སྒྲགས་དང་ Pool ཁྲིམས་ལུགས་ དེ་ལས་ ལག་ལེན་གཞན་ཚུ་གི་ གནས་སྟངས་ལུ་ བསྒྱུར་བཅོས་འབད་མི་ཚུགས།

ལག་ལེན་འཐབ་ནི་ [བསམ་འཆར་དང་ཚིག་ཡིག་ཚུ་](/dz/introduction/concepts) ཁྲིམས་སྐྱོང་འབད་མི་ཚུ་དབྱེ་བ་ཕྱེ་ནིའི་དོན་ལུ་ཁས་ལེན་མཉམ་སྤྱོད་དངུལ་ཁུངས།ལས་`SwapPool`དེ་ལས་ བསྐྱིན་ཚབ་སྤྲོད་ལེན་དང་ མཇུག་བསྡུ་ནི་དང་ ཐོ་བཀོད་ནང་ལས་ འགྱུར་བཅོས་འབད་ཐབས།


## ཐོ་བཀོད་རྟགས་ (`GiftableToken`)

`GiftableToken`འདི་ERC20ཌེ་བི་ཊི་གི་ཨེམ་སི་ཚུ་དང་འབྲེལ་བའི་བརྡ་མཚོན་ཅིག་ཨིན།

- **ཐོ་བཀོད་འབད་ཡོད་མི་ minting** བདག་འཛིན་འཐབ་མི་གིས་ `mintTo`དང་གཅིག་ཁར་ ཐོ་བཀོད་འབད་ཚུགས་པའི་ ཡིག་འབྲུ་འབྲི་མི་ཚུ་ལུ་ བཙུགས་ཚུགས།
- **དགོས་མཁོ་ཅན་གྱི་དུས་ཡུན་མཇུག་བསྡུ་ནི།** དུས་ཡུན་ཚང་བའི་སྐབས་`0`ཚད་གཞི་དེ་ཡང་མ་གྲུབ་པར་བཞག་པ་ཅིན་ བསྒྱུར་བཅོས་དང་ མཚམས་སྦྱོར་ དེ་ལས་ མེ་གཏང་ནི་ཚུ་ གཞི་སྒྲིག་འབད་ཡོད་པའི་དུས་རྟགས་ལུ་ ཡང་ན་ དེ་གི་ཤུལ་ལས་ ལོག་སྟེ་ར་ འགོ་བཙུགས་འོང་།`expired`ཌའི་ལོག་ལུ་ བརྒྱུད་འཕྲིན་བཏང་`applyExpiry`ཐད་ཀར་དུ་
- **བཀྲམ་སྤེལ་གྱི་རྩིས་ཁྲ་** — `totalMinted`དང་`totalBurned`འབུམ་གྱི་མཁོ་སྒྲུབ་འབད་ནིའི་ལཱ་ཚུ་ གསལ་སྟོན་འབདཝ་ཨིན།`burn`འགན་ཁུར་འདི་ ཇོ་བདག་གི་ཁ་བྱང་གིས་བཞག་མི་ token འདི་འཚིག་གཏང་ཨིན།

ཕྲང་རྟགས་ཀྱི་འཆམ་ཡིག་འདི་ **འདི་མེན་** ཅ་ཆས་དང་ ཞབས་ཏོག་ཚུ་ ངོས་འཛིན་འབད་ཞིནམ་ལས་ བསྡུ་ལེན་གྱི་གོང་ཚད་གཏན་འབེབས། སྒྲིང་སྒྲི་བཏོན་ནི་ ཡང་ན་ ཏི་རུ་བསྒྱུར་བཅོས་འབད་ནི་ལུ་ ཁས་བླངས་འབདཝ་ཨིན། `GiftableToken` འདི་ དངུལ་ཁང་གི་གནས་སྟངས་དང་ སྤྱོད་ལམ་སོ་སོར་སྦེ་གསལ་བསྒྲགས་འབད་བའི་ཐོག་ལས་རྐྱངམ་གཅིག་ བགོ་བཀྲམ་འབད་ཚུགས་པའི་བཅའ་གཏད་བཟོཝ་ཨིན། ཕྱིར་ཚོང་འཐབ་མི་ཚུ་གིས་ གནས་སྟངས་དེ་ ལེགས་ཤོམ་སྦེ་བཤད་ནི་དང་ དམ་ཚིག་ཅན་བཟོ་ནི་ལུ་ འགན་འཁྲི་བསྐྱེདཔ་ཨིན་མས།


## ཁས་ལེན་མཉམ་སྤྱོད་དངུལ་ཁུངས། (`SwapPool`)

`SwapPool`འདི་ token vault དང་ swap settlement engine ཨིན་ཏེ་འབད་རུང་ འདི་གིས་ERC20ཌེ་སི་ཊི་བི་གི་མིང་དང་ རྟགས་མཚན་ དེ་ལས་ ཨང་གྲངས་བཅུ་ཐམ་ཚུ་གི་དོན་ལུ་ metadata འདི་ v1ཨིན།1.0ལས་འཆམ་དེ་ནང་ Pool-share tokens ཚུ་བཟོ་མི་འདུག ལི་ཀའིཌ་ཊིག་འདི་ Token འདི་ལུ་ Transfer በማድረግ གྲོང་གསེབ་ནང་ལུ་ བཏང་ཡོདཔ་ལས་ contract holder གིས་ འཐོབ་ཚུགས་པའི་ liquidity དེ་ཕྱིར་བཏོན་འབད་ཚུགས།

### བསྒྱུར་བཅོས་འབད་ཐབས།

བསྒྱུར་བཅོས་ཀྱི་དོན་ལུ་ `SwapPool`:

1. ཨེན་པུབ་དང་ཨོན་པུབ་གི་ལྡེ་མིག་ཚུ་ གདམ་ཁ་རྐྱབས་ཀྱི་ཐོ་ཡིག་ནང་ལས་བརྒལ་ཏེ་ཡོདཔ་ཨིན་ན་ བརྟག་དཔྱད་འབད་ཞིནམ་ལས་ requested input འདི་ optional pool-balance limit དང་གཅིག་ཁར་བརྟག་ཞིབ་འབདཝ་ཨིན།
2. ཨེབ་ཐོར་རྟགས་འདི་འབོ་མི་ནང་ལས་བཏོན་ཞིནམ་ལས་ ངོ་མ་ཐོབ་པའི་དངུལ་ཀྲམ་ཚུ་ བརྩིས་ཏེ་ཨིན། གོང་ཚད་བཟོ་ནི་དེ་ རྩིས་སྤྲོད་འབད་ཡོད་པའི་ དངུལ་ཀྲམ་ཚུ་གི་དོན་ལུ་ཡང་ ལག་ལེན་འཐབ་ཡོདཔ་ཨིན།
3. གཞི་སྒྲིག་འབད་ཡོད་པའི་ quoterལས་ བརྒྱ་ཆའི་གནས་གོང་ཐོབ་ནི་ ཡང་ན་ གནས་ཚད་མ་བཙུགས་པའི་སྐབས་ལུ་ raw received amount ལག་ལེན་འཐབ་ཨིན།

## དངུལ་གྱི་གནས་གོང་ཚུ་

quoters གསུམ་ཆ་མཉམ་གིས་ forward དང་ reverse quote functions ལག་ལེན་འཐབ་སྟེ་`SwapPool`དང་`SwapRouter`:

- **`DecimalQuoter`** ༡:༡ གི་གོང་ཚད་འདྲ་མཉམ་གི་གཞི་བཞག་ནང་ལུ་ རྒྱལ་ཁབ་མེད་པའི་བཅུ་ཐམ་གནས་རིམ་སྒྲིག་རྐྱབས།
