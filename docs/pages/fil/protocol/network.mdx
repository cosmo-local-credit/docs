# Arkitektura ng protocol network

Maaaring iugnay ng maraming Pool na magkakahiwalay ang pamamahala ang hawak mong Voucher sa Voucher na gusto mo. Bawat Pool ang nagbibigay ng isang hakbang sa palitan, gamit ang sarili nitong mga patakaran at magagamit na imbentaryo.

Ang [sanggunian sa routing ng CLC software](https://software.cosmolocal.credit/contracts/routing) ang pangunahing sanggunian sa pagtuklas ng ruta, pagiging kwalipikado, pagsasagawa, at mga service interface. Nasa Ingles ang dokumentasyon ng software sa kasalukuyan. Ipinapaliwanag ng pahinang ito ang paglalakbay at pananagutan ng kalahok.

## Production route discovery at execution

Sa view na **Kredito** ng App, piliin ang Voucher na gusto mong **Kunin** o ang nais mong **Gastusin**. Halimbawa, maaaring ipalit ng isang ruta ang Voucher sa transportasyon sa Voucher sa pagkain sa pamamagitan ng dalawang magkaibang Pool.

Hindi garantiya ng palitan ang pagkakaroon ng koneksyon. Dapat pahintulutan ng mga suportadong Voucher, limitasyon ng Pool, magagamit na imbentaryo, bayarin, pagiging katugma ng Wallet, at availability ng serbisyo ang hinihinging halaga.

### May-awtoridad na quote

Suriin ang **Mga detalye ng ruta** bago kumpirmahin: ano ang ibabayad at matatanggap mo, bawat kasaling Pool, mga bayarin, minimum na matatanggap, at pag-expire ng quote. Nakatutulong ang tantiya sa pagtingin ng mga pagpipilian; ang quote ang panukalang pinapahintulutan mo. Kumuha ng bagong quote kung nag-expire ito o nagbago ang kalagayan ng Pool.

Pinananatili sa [sanggunian sa routing](https://software.cosmolocal.credit/contracts/routing) at [configuration ng serbisyo](https://software.cosmolocal.credit/core-api/configuration#credit-router) ang mga teknikal na tuntunin sa pagiging kwalipikado at mga setting ng quote.

### Pinirmahang atomic batch

Sinusuri at pinapahintulutan mo ang buong palitan. Sa kasalukuyang ruta, nagtatagumpay ang lahat ng palitan sa Pool o sabay-sabay na nababawi ang mga ito kapag may nabigong hakbang. Pinipigilan nito ang pagkumpleto ng bahagi lamang ng ruta; hindi nito ginagarantiya ang paghahatid ng produkto o serbisyo pagkatapos.

Para sa pagbuo at pagsasagawa ng transaksyon, tingnan ang [Pagsasagawa ng ruta](https://software.cosmolocal.credit/contracts/routing#execute-a-route).

### Solidity `SwapRouter` at mga bayarin

Magkaibang bahagi ng software ang quote-only na Solidity `SwapRouter` at ang daloy ng palitan sa App. Ipinapaliwanag ang ugnayan nila sa [Routing](https://software.cosmolocal.credit/contracts/routing).

Para sa kalahok, mahalagang suriin ang buong quote. Maaaring maningil ang bawat Pool. Hindi pinagsasama ng iisang ruta ang mga Pool o ginagawang responsable ang isang Tagapangasiwa sa ibang Pool.

### Resibo at mga katayuan ng pagkabigo

Pagkatapos magsumite, tingnan kung nakabinbin, kumpirmado, o nabigo ang palitan, at itago ang resibo. Kung walang ruta, subukang mag-refresh, bawasan ang halaga, o pumili ng ibang suportadong input Voucher.

Hindi binabago ng nabigong palitan ang mga naunang pangako ng Tagapag-isyu. Itinatala ng matagumpay na palitan ang pagbabago ng balanse; sumusunod pa rin sa mga tuntunin ng Tagapag-isyu ang pagtupad at discharge. Tingnan ang [mga praktikal na halimbawa](/fil/introduction/example).

Makikita ng mga developer ang mga interface para sa transaksyon at pagsubaybay sa [sanggunian sa CLC Core API](https://software.cosmolocal.credit/core-api/reference).

## Mga panloob na bahagi ng Pool

Bago umasa sa Pool, tukuyin ang Tagapangasiwa, may-ari ng contract, mga awtoridad sa upgrade, tatanggap ng bayarin, at sinumang maaaring magbago ng mahahalagang setting. Maaaring magkaibang partido ang teknikal na controller at ang Tagapangasiwang may pananagutan.

Pinananatili ng sanggunian sa software ang [mga mekanismo ng Pool](https://software.cosmolocal.credit/contracts/pools) at [beripikasyon ng deployment](https://software.cosmolocal.credit/contracts/deployments). Ipinapaliwanag dito ang [mga tungkulin at bokabularyo](/fil/introduction/concepts), [mga pananagutan sa pamamahala](/fil/governance/mechanics), at ang [mas malawak na disenyo ng CPP](/fil/white-paper).
