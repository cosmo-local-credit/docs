## C. 拟议的 KPI 定义

这些关键指标构成了拟议的测量规范,而不是当前应用程序或协议记录每一个所需的事件的声明.

每个公布的KPI都必须包含:

- 负责的出版商和数据来源;
- 事件或状态的定义;
- 一组或测量期;
- 单位和估值方法;
- 估值时间表;
- 包容和排斥的规则;
- 部分,争议,过期,无法访问和纠正的记录处理;
- 需要在链外的证据或证明;
- 审查历史和数据质量限制;以及
- 结果是否在链上,报告,认证,独立验证或估计.

| KPI | 拟议的定义 | 需要的证据和排除 |
| --- | --- | --- |
| **有效的表达** | 在一段时间内接受发行人赎回过程中的计数或单元 | 报表标识,发行人,持有权限,数量,时间,状态;排除复制和无效的请求 |
| **履约率** | 已填写的有效表现,分为相同成熟群体的有效呈现 | 单独的发行方绩效证据;报告开放,拒绝,争议,部分和纠正的案件 |
| **核销完整性** | 已填写的表单,分为已填补的表现 | 燃烧,取消,禁用记录或与履行相关的其他未再使用证据 |
| **履约延迟** | 呈现到完成时间的中位数和90个百分点 | 不取代发行到提交或收购到提交的持有时间 |
| **持有时间** | 收购到提交时间的中位数和分布 | 确定收购事件并排除未知的收购时间 |
| **现有资格承诺** | 已确定排除后仍然存在的可接受第三方承诺 | 发行人身份和条款;不包括适用的发行人的库存,过期,燃烧,清理,测试和非承诺代币 |
| **资金池交换量** | 根据一个披露的估值方法完成直接组交换的价值 | 链上结算事件,代币单位,汇率来源,时间;不归类为发行人履行 |
| **资金池库存** | 在特定时间内,一个集团所持的衡量支持资产 | 合同余额,费用保留,不可访问的资产,估值方法和所有者撤销权 |
| **储备充足性** | 符合条件的可用储备资产,按明确覆盖的风险分为 | 覆盖政策,资产资格性,保管/控制,负债,排除和估值;不包括默认的全部代币供应 |
| **限制利用率** | 测量的库存代币余额以其当前配置的上限分为 | Limiter地址,代币,池,时间标签,变化和无限制期限 |
| **报价通过率** | 通过有效的报价尝试划分成功报价回复 | 仅引用结果;不执行路线 |
| **路线执行率** | 完成的多跳执行分为有效的执行尝试 | 仅适用于实施执行系统;每次报告和原子性规则 |
| **担保人回收** | 收到的资格回报,分为已支付的受保索赔 | 确定担保人,索赔政策,时间表,成本,争端和抵免 |
| **拟议的网络收入** | 收到的拟议网络拉克加上收取的单独路由/服务费 | 排除池所保留的毛额费用,避免两次计数拉克 |
| **管理及时性** | 发现,决定,暂停,修复和关闭事件的时间 | 定义时钟,负责机构,紧急权力,上诉和失踪事件 |

区块链活动本身并不能确定身份,发行方的表现,满意度,社区健康,因果关系或影响.
