# C. 拟议的 KPI 定义

这些关键指标构成了拟议的测量规范,而不是当前应用程序或协议记录每一个所需的事件的声明.

每个公布的KPI都必须包含:

- 负责的出版商和数据来源;
- 事件或状态的定义;
- 一组或测量期;
- 单位和估值方法;
- 估值时间表;
- 包容和排斥的规则;
- 部分,争议,过期,无法访问和纠正的记录处理;
- 需要在链外的证据或证明;
- 审查历史和数据质量限制;以及
- 结果是否在链上,报告,认证,独立验证或估计.

| KPI | 拟议的定义 | 需要的证据和排除 |
| --- | --- | --- |
| **有效的表达** | 在一段时间内接受发行人赎回过程中的计数或单元 | 报表标识,发行人,持有权限,数量,时间,状态;排除复制和无效的请求 |
| **履约率** | 已填写的有效表现,分为相同成熟群体的有效呈现 | 单独的发行方绩效证据;报告开放,拒绝,争议,部分和纠正的案件 |
| **核销完整性** | 已填写的表单,分为已填补的表现 | 燃烧,取消,禁用记录或与履行相关的其他未再使用证据 |
| **履约延迟** | 呈现到完成时间的中位数和90个百分点 | 不取代发行到提交或收购到提交的持有时间 |
| **持有时间** | 收购到提交时间的中位数和分布 | 确定收购事件并排除未知的收购时间 |
| **现有资格承诺** | 已确定排除后仍然存在的可接受第三方承诺 | 发行人身份和条款;不包括适用的发行人的库存,过期,燃烧,清理,测试和非承诺代币 |
| **直接资金池兑换量** | 按已披露的估值方法衡量、作为一次资金池兑换发起的已完成兑换价值 | 链上结算事件、代币单位、汇率来源和时间；不得归类为发行方履约 |
| **路径发现尝试** | 在一段时间内查找可到达代金券或候选路径的有效请求 | 图版本、索引区块、新鲜度、钱包范围、请求深度、候选数量、遗漏或搜索预算状态；不是权威报价 |
| **可用候选路径** | 发现功能针对已定义请求群组返回的候选路径 | 分别计算每条有序的资金池/代币路径；说明路径深度和排除项；不得归类为可执行或已结算 |
| **路径报价通过率** | 返回的权威路径报价除以有效报价尝试 | 固定区块、路径、金额模式、到期、结果或拒绝原因；与发现成功和执行分开 |
| **路径执行率** | 已确认的路径兑换除以同一成熟群组中有效、已签署的执行尝试 | 跟踪 ID、交易哈希、中继状态、确认或回滚、路径深度和失败原因；不包括未签署报价 |
| **整条路径兑换量** | 已确认路径兑换的输入和输出价值，每条路径只计算一次 | 按一种估值方法，使用第一跳已结算输入和最后一跳已结算输出；不得把所有跳的价值相加为独立经济量 |
| **逐跳结算** | 已确认路径中每一跳的已结算输入、总输出、资金池费用、协议费用和净输出 | 有序资金池和代币标识符、结算事件、交易哈希、区块、日志索引和任何中间余量 |
| **路径费用** | 一条路径上实际结算的当前资金池费用和协议费用 | 按费用类型逐跳和汇总报告；不得标记为拟议网络分成或尚未实现的服务费 |
| **路径限制** | 被拒绝的路径或报价数量及占比 | 准入、存入上限、流动性、费用域、不受支持的代币或报价器、钱包余额或类型、Gas、搜索预算、到期、不匹配或模拟证据 |
| **路径对账健康度** | 索引图和分组结算记录的新鲜度与可靠性 | 图版本和年龄、对账队列深度、对账时长、纠正、故障、未知成员和未解决收据 |
| **资金池库存** | 在特定时间内,一个集团所持的衡量支持资产 | 合同余额,费用保留,不可访问的资产,估值方法和所有者撤销权 |
| **储备充足性** | 符合条件的可用储备资产,按明确覆盖的风险分为 | 覆盖政策,资产资格性,保管/控制,负债,排除和估值;不包括默认的全部代币供应 |
| **限制利用率** | 测量的库存代币余额以其当前配置的上限分为 | Limiter地址,代币,池,时间标签,变化和无限制期限 |
| **担保人回收** | 收到的资格回报,分为已支付的受保索赔 | 确定担保人,索赔政策,时间表,成本,争端和抵免 |
| **拟议的网络收入** | 收到的拟议网络拉克加上收取的单独路由/服务费 | 排除池所保留的毛额费用,避免两次计数拉克 |
| **管理及时性** | 发现,决定,暂停,修复和关闭事件的时间 | 定义时钟,负责机构,紧急权力,上诉和失踪事件 |

区块链活动本身并不能确定身份,发行方的表现,满意度,社区健康,因果关系或影响.
