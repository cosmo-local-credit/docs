本隐私声明说明，当您访问或使用 `cosmolocal.credit` 上的 Cosmo-Local Credit App 及 GEF 运营的相关服务（合称**应用**）时，Grassroots Economics Foundation（以下简称 **GEF** 或 **本基金会**；本声明中的 **我们** 和 **我们的** 均指 GEF）如何处理个人数据。

> **发布前请阅读。** 您的私密个人资料并不是公开资料。但是，您输入或复制到代金券、资金池、商品或服务项目、需求、目录或帖文中的信息，可能会随该资源一起发布。资源的描述、条款、图片、标签、钱包地址和精确地图坐标可能无需登录即可查看。代金券、资金池或需求中的联系方式仅通过登录后的资源信息或联系功能显示，但接收者仍可复制或分享这些信息。

本声明是对[服务条款](/zh/governance/terms)和[数据保护政策](/zh/governance/data-protection)的补充。

## 1. 谁负责您的数据？

Grassroots Economics Foundation 是该应用的运营方，也是本声明所述应用数据的数据控制者；但另一方独立决定如何使用数据的情况除外。

GEF 联系方式：

- 电子邮件：[privacy@grassecon.org](mailto:privacy@grassecon.org)
- 邮政地址：P.O. Box 1659-80108, Kilifi, Kenya

发行方、资金池管理者、支付服务提供商、钱包服务提供商、区块链参与者和外部服务运营方，可能对其接收或发布的信息构成独立的数据控制者。他们各自的声明和条款也可能适用。

## 2. 本声明适用于谁和哪些信息？

本声明适用于访客、账户持有人、使用应用功能的人，以及其信息由获授权用户通过应用提交的人。它涵盖 GEF 运营的应用界面、API、目录、存储、交易转发、通知、内容审核、支持和相关运营服务。

对于独立发行方、资金池管理者、第三方服务提供商、公共区块链、外部网站或其他用户在 GEF 职责范围之外处理信息的方式，本声明不具有控制力。该应用仅供符合《服务条款》资格要求的成年人使用。

## 3. 我们收集的数据

### 账户和个人资料数据

根据您使用的功能，我们可能收集：

- 您的用户名和公共区块链钱包地址；
- 您的姓名、电子邮件地址、电话号码、国家和首选货币；
- 您的个人简介、网站、头像，以及已保存的位置名称和坐标；
- 账户角色、状态、资源限制，以及账户创建或更新时间；以及
- 您的设置、语言、通知偏好和其他选择。

您的用户名不同于私密个人资料中的姓名。用户名用作接收者标识符；已登录用户输入完整且准确的用户名时，系统可能向其返回该用户名和您的钱包地址。您的个人资料可用于预填表格，但只有在您选择发布资源后，预填字段才会随资源发布。

获授权的管理员可以按姓名、用户名、电子邮件、电话号码或钱包地址搜索账户目录，并可在运营、支持、审核和保护应用所需的范围内查看账户身份和联系字段、角色、状态、资源限制及关联资源。该目录不公开。

### 身份验证、钱包和交易数据

我们可能处理钱包地址、已签名消息、交易授权、签名、通行密钥凭证标识符和公钥坐标、凭证状态、会话标识符和角色、交易请求、交易转发记录、替代交易数据和交易状态。更换登录卡时，我们可以保留旧钱包地址和新钱包地址、所请求变更的证明、关联的通行密钥状态，以及恢复或验证该变更所需的运营记录。

应用把浏览器登录卡的私密材料存放在该浏览器的本地存储中，以便浏览器完成签名。GEF 服务接收签名和已签名交易，而不接收原始私钥。通行密钥提供方保护通行密钥的私钥；应用及其服务使用注册或验证所需的凭证标识符、公钥材料、挑战值和已签名断言。如果您使用纸钱包、登录卡、通行密钥或其他凭证，您有责任保护设备和私密材料。

当代金券或资金池由兼容的多重签名钱包控制时，我们可能处理多签地址、签名人钱包地址、批准门槛、拟议交易、确认记录、执行状态，以及显示和操作多签控制所需的权限。所有者地址、签名人集合和批准门槛可以通过公开的所有权查询返回，也可能在公共区块链上显示。

### 设备、安全和使用数据

我们可能收集技术和运营信息，例如 IP 地址、浏览器和设备信息、时间戳、请求的页面或端点、会话和安全事件、验证错误、速率限制信息、通知订阅和送达确认、服务活动及诊断记录。

### 内容和支持数据

我们会处理您在代金券、资金池、商品或服务项目、需求、目录、帖文、代金券与资金池评价、图片、附件、条款、描述、标签、位置、联系字段、交易后的私密消息或订单、投诉、支持消息及其他通信中提交的信息。

如果您使用 App 消息功能，我们会处理：

- 对话请求及其状态；
- 参与者的钱包地址、用户名和头像；
- 消息文本、图片和时间戳；
- 每位用户的已读标记、屏蔽记录和请求配额记录；以及
- 帮助台对话和滥用举报。

私信仅供对话双方查看。GEF 管理员可以读取帮助台消息。只有当参与者将某条私信附在滥用举报中时，管理员才能读取该私信。

除非您具有合法理由并已取得任何必要许可，否则请勿发布他人的个人数据、图片、联系方式或精确位置。

## 4. 哪些信息会公开？

应用包含五种重要的信息可见性级别。

| 可见性 | 这意味着什么 |
| --- | --- |
| 私密个人资料和账户数据 | 个人资料姓名、电子邮件、电话号码、已保存位置、偏好、身份验证记录和类似账户信息用于运营应用，不会自动出现在公开资源响应中。获授权的 GEF 人员和服务提供商可在工作需要时访问这些信息。获授权管理员也可搜索和管理非公开账户目录。 |
| 精确的接收者查询 | 已登录用户输入您的完整且准确的用户名或完整电话号码时，可能会获得您的公开用户名和钱包地址。输入部分用户名不会返回用户。用于查询的电话号码，以及您的私密个人资料姓名、电子邮件、电话号码和已保存位置，均不会出现在接收者查询结果中。 |
| 公开目录和资源数据 | 已发布的描述、条款、图片、标签、钱包和合约地址、位置、精确坐标、商品或服务项目、需求、帖文、评价、资金池规则和技术设置，可能无需登录即可查看。公开字段可能被索引、复制、分享，或与某个钱包或其他资源相关联。 |
| 登录后可见的资源联系方式 | 主动添加到代金券、资金池或需求中的电子邮件、电话、网站或联系说明，会从未登录用户获得的目录和详情响应中移除。已登录用户可请求包含完整联系方式的代金券或资金池记录，或获取某项活跃需求所选择的联系方式。接收者仍可复制、使用或分享这些信息。已下架资源仅允许所有者或管理员在更有限的范围内访问。 |
| 公共区块链记录 | 钱包地址、合约、余额、持有资产、转账、金额、交易对手、时间戳、签名和合约操作，可能通过公共网络和独立区块浏览器永久可见。GEF 无法删除或改写公共区块链。 |

App 消息不公开。对话双方可以看到彼此的钱包地址、用户名、头像、消息、图片、对话状态和时间戳。已读标记、屏蔽列表和请求配额属于运营记录，不会公开。

从应用目录中移除资源，不会删除其他人、搜索服务、档案服务、独立索引器或公共区块链已经保存的副本。

## 5. 公共资源领域

随着应用发展，资源可用字段可能发生变化。发布前显示的表单，是对您选择公开哪些信息最直接的说明。

| 资源 | 可能公开的信息 |

| 资金池 | 公开：合约和链上标识符；资金池名称和描述；所有者、费用接收方、依赖项或其他技术控制方的钱包地址；支持的代金券；库存或可用性信息；估值方法；费用、限额、规则及其他配置；位置名称和精确坐标；图片；标签；时间戳；以及兼容多签的所有者地址、签名人地址和批准门槛。登录后可见：主动填写的电子邮件、电话和网站。已下架资金池记录与已下架代金券一样，只能通过权限更严格的完整信息端点访问。 |
| 商品或服务项目 | 关联代金券的详细信息；卖方或来源钱包地址；所提供的商品或服务；描述、数量、单位、频率、价格和可用性；位置名称及精确坐标或继承的坐标；图片；标签；以及时间戳。 |
| 需求 | 公开：所需商品或服务；描述；标签；图片；状态和日期；位置名称和精确坐标。登录后可见：仅限为该活跃需求主动选择的联系说明、电子邮件或电话。公开的需求响应会省略这些联系字段，也不会识别创建者的私密个人资料；但关联的代金券或资金池仍可能形成间接关联。 |
| 目录 | 目录名称、描述、图片、标签、所有者钱包地址、列出的成员或资源、数量、位置名称和精确坐标，以及时间戳。 |
| 已发布帖文 | 标题、摘要、正文、主办方名称、参与者信息、日期、图片、图片说明、附件、嵌入链接、标签、关联的代金券或资金池，以及精确坐标。作者的钱包地址和工作流状态会保留用于管理和问责，但不会出现在公开帖文响应中。关联资源或内容本身仍可能暴露这种关联。 |
| 代金券或资金池评价 | 评分、评论，以及代金券或资金池所有者的任何公开回复。公开的评价响应不包含评价者的钱包地址，也不包含兑付或兑换证据。服务会保留评价者地址及必要证据，用于验证资格、防止重复评价、支持回复和举报、审核内容并执行评价期限。评价被举报时，管理员可以收到举报理由和被举报的评价内容。 |

联系方式和精确坐标可能带来人身安全风险。请尽可能使用适当的公开联系方式，并选择安全的公共会面地点，而不是私人住所。

## 6. 公共区块链信息

应用会与公共区块链网络交互。交易可能披露相关钱包、Token 或代金券合约、金额、时间、状态、签名及相关合约事件。资金池合约还可能披露支持的资产、余额、存款、支出、兑换、流动性提取、费用、限额、估值、所有者、管理员、依赖关系及其他配置。兼容的多签钱包可能披露签名人集合、批准门槛、提案、确认记录及已执行操作。

区块链信息可能由网络验证者、节点运营方、索引器、钱包软件、分析服务和任何读取该网络的人处理。交易可能不可逆。关闭应用账户、更改个人资料、更换登录卡、移除或下架目录资源、销毁代金券单位，或要求 GEF 删除链下数据，都不会删除早先的区块链记录或由独立机构索引的副本。

## 7. 我们使用数据的原因和法律依据

我们仅在具有适用法律依据时使用个人数据。具体依据可能因个人、功能和司法管辖区而异。

| 目的 | 典型的法律依据 |
| --- | --- |
| 创建和运营账户、验证用户身份、提供所请求功能、提交已授权交易，以及提供支持 | 履行我们与您的协议，以及应您的请求采取措施 |
| 发布您主动提交用于公开展示的资源或联系方式 | 履行我们的协议、您主动采取的公开行为，以及在法律要求时取得的同意 |
| 保护账户和服务、防止欺诈或滥用、执行限额、调查事件并维护可靠记录 | 运营安全且可问责服务的合法利益、履行我们的协议，以及法律义务 |
| 审核内容、处理投诉、执行《服务条款》并保护用户或公众 | 合法利益、履行我们的协议，以及法律义务 |
| 保存财务、交易、治理、合规、税务和争议记录 | 法律义务，以及问责和法律主张方面的合法利益 |
| 发送可选通信或通知 | 法律要求时取得同意；对于服务消息，则依据我们的协议和合法利益 |
| 改进服务并开展研究或编制汇总统计数据 | 合法利益、法律要求时取得的同意，以及具有适当保障的其他合法研究依据 |

我们不会把您决定发布某一字段，视为您同意发布与其无关的私密个人资料字段。

## 8. 要求的和可选的数据

应用会在相关表单中标明必填字段。目前，引导式账户创建要求提供钱包地址和身份验证证明、姓名、个人资料图片、国家和已保存位置、首选货币，以及至少一个电子邮件地址或电话号码。用户名为可选。其他登录或账户恢复流程可能先创建临时系统值，直到用户完成或更正个人资料。特定功能可能需要额外的交易、联系、位置、资格或资源信息。

除非表单另有说明，其他个人资料和资源字段均为可选。如果您不提供必填信息，我们可能无法创建账户、验证您的身份、提交交易、发布资源、提供支持、满足法律要求或提供所请求的功能。

“可选”并不表示发布后仍然私密。如果您把可选的联系方式、图片、描述或地图标记添加到资源并发布该资源，这些信息就会公开。

## 9. 我们如何获取数据

我们通过以下来源接收数据：

- 直接来自您，或获授权代表您行事的人；
- 来自您的浏览器、设备、钱包、通行密钥或通知服务；
- 来自公共区块链网络、合约、节点和索引器；
- 来自发行方、资金池管理者、交易对手、支付或服务提供商，以及参与某项功能或交易的其他用户；
- 来自可依法收集的公开来源；以及
- 来自安全、内容审核、支持和合规流程。

## 10. 谁会接收数据？

我们只披露为所述目的、适用法律或您要求的公开行为所合理需要的信息。接收者可能包括：

- 当您发布资源或使用公共区块链时，应用的访客和用户；
- 当已登录的应用用户请求您主动附加到活跃代金券、资金池或需求上的联系方式时，这些已登录用户；
- 私信对话中的另一位参与者；
- 处理帮助台对话或滥用举报的 GEF 授权管理员，但其访问须受第 3 节所述限制；
- 完成交易、兑付、投诉或所请求服务所需的发行方、资金池管理者、交易对手和其他参与者；
- 提供托管、数据库、存储、内容分发、安全、身份验证、支持、电子邮件、通知、地图、地理编码、区块链访问、索引、交易转发和监控的基础设施服务商；
- 您选择使用的独立钱包、区块链、支付、稳定币、现金出入金或其他第三方服务提供商；
- 在承担适当义务并具备适当保障的情况下，专业顾问、审计师、保险机构、研究人员、资助方和合作伙伴；以及
- 法律要求披露或为保护权利、安全和服务完整性而合理需要披露时的监管机构、法院、执法机关或其他人员。

生产环境的网页应用通过 Cloudflare Pages 提供。当前浏览器配置使用 MapTiler 提供地图样式和基于 IP 的位置建议，使用 ArcGIS World Geocoding 进行地点搜索和反向地理编码，并使用已配置的 Gnosis Chain RPC 端点读取链上数据。这些服务会接收响应请求所需的数据，其中可能包括 IP 地址、浏览器信息、地图区域、搜索文字、坐标，或钱包与合约查询。

其他集成取决于具体功能。启用并使用相关功能时：通知服务会处理推送订阅端点、设备状态、关联的钱包地址、送达和点击确认及收件箱状态；交易转发服务会处理已签名请求和交易状态；Safe 交易服务会处理多签地址、提案、签名、确认和执行状态；支付或现金出入金服务商会处理该功能所需的电话号码、钱包地址、资产、金额、服务商标识符、汇率和交易状态。图片存储、应用 API、数据库、区块链索引器和基础设施监控会处理其功能所需的内容和运营记录。第三方服务也可能依据自己的隐私声明直接收集数据。

## 11. 国际处理

应用、公共区块链网络、服务提供商、合作伙伴和用户可能在多个国家运营。因此，个人数据可能在肯尼亚或数据收集国以外被访问或处理。

当数据传输需要保障措施时，GEF 会采用适合该传输并符合适用法律的措施，其中可能包括合同、访问限制、传输中加密、对接收者和目的地的评估、适当情况下的同意，或其他法律认可的传输依据。公开信息和区块链交易可在全球访问，无法限制在单一国家内。

## 12. 我们保存数据的时间

GEF 仅在实现数据收集目的所合理需要的期间内保留个人数据，包括：

- 账户、资源、交易、对话、屏蔽、滥用举报、投诉或支持事项仍处于活跃状态期间；
- 为满足安全、防欺诈、对账、审计、治理、研究完整性和服务连续性需要；
- 为满足税务、会计、监管、合同、争议、时效期限或其他法律要求；以及
- 在按计划删除或替换前，于受保护备份和日志中保留的有限期间。

因此，不同记录具有不同的保留期限。当数据不再需要时，我们会删除、汇总、去标识化或限制使用，除非法律要求或允许继续保存。公共区块链记录和由他人控制的副本不属于 GEF 可以删除的范围。

## 13. 安全

GEF 采用与风险相称的技术和组织措施来保护个人数据。这些措施可能包括访问控制、身份验证、职责分离、安全传输、系统更新、监控、备份、事件处理程序、员工职责和服务提供商保障。

任何在线系统、公共区块链、凭证或传输都无法保证绝对安全。您必须保护自己的设备、会话、通行密钥、私钥、纸钱包和恢复信息，并在公开信息前仔细检查。

## 14. 您的权利和选择

根据适用法律,您可能有以下权利:

- 获知您的个人数据如何被使用；
- 请求访问 GEF 持有的与您有关的个人数据；
- 请求更正不准确或具有误导性的数据；
- 对特定处理提出异议或请求限制处理；
- 在处理以同意为依据时撤回同意；
- 请求删除 GEF 无须或无权继续保留的数据；
- 在该权利适用时，以可携带的形式接收数据；以及
- 向 Office of the Data Protection Commissioner（**ODPC**）或其他主管机关投诉。

请将请求发送至 [privacy@grassecon.org](mailto:privacy@grassecon.org)。我们可能需要在采取行动前验证您的身份和权限。您的权利可能受到他人权利、公共记录、法律义务、技术必要性或公共区块链永久性的限制。

您也可以选择不填写可选的个人资料字段、在发布前删除可选信息、使用适当的公开联系方式、选择安全的公共地图点、管理通知权限，以及避免使用要求提供您不愿提供之数据的功能。

关于肯尼亚数据主体权利的信息可从 [ODPC](https://www.odpc.go.ke/rights-of-a-data-subject/) 获取。

## 15. 儿童

CLC App 仅供年满 18 岁且已达到其适用法定成年年龄的人使用。除非 GEF 明确提供了具备必要保障和授权的独立合法流程，否则请勿为儿童创建应用账户，也不要通过应用提交儿童的个人数据。

GEF 在应用之外开展且涉及儿童的活动，受[儿童保护政策](/zh/governance/child-safeguarding)和适用数据保护要求的约束。
