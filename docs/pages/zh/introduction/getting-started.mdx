# 入门

Cosmo-Local Credit（CLC）帮助人们说明自己能提供什么、发布自己需要什么，并通过独立治理的承诺资金池交换代金券。打开 [CLC App](https://cosmolocal.credit) 即可开始。

基本思路很简单：

1. 为自己能提供的东西创建一张代金券——它很像礼品卡。
2. 发布一项 **商品或服务项目（Offering）**，让人们发现相关的商品或服务。
3. 发布或回应一项 **需求（Want）**，寻找可能的交换伙伴。
4. 通过承诺资金池，按照已公布的规则交换受支持的代金券。
5. 按照代金券条款，向发行方使用代金券并获得其承诺的商品或服务。

App 中的 Credit（界面标签为“可存入”）是指获得认可的承诺以及代金券交换容量，并不自动表示个人贷款、借款额度或垫款承诺。

准确的定义请参阅[概念与词汇](/zh/introduction/concepts)。

## 第一次使用 App

### 1. 浏览市场和需求

创建任何内容之前，可以先浏览 [CLC App](https://cosmolocal.credit)。**市场（Market）** 是用于发现内容的目录，本身并不自动成为卖方、交换场所、认可或担保。

查看代金券时，请确认：

- 由谁发行；
- 承诺提供哪些商品或服务；
- 可以在何处、何时以及如何使用；
- 有哪些限制、有效期、联系方法和投诉流程；以及
- 哪些承诺资金池支持它。

**需求（Want）** 用来表达需要。发布或回应需求，并不自动表示接受代金券、预留商品、授权交换或产生义务。联系其他参与者或给对方发送消息，本身也不会产生、履行或解除代金券承诺。

### 2. 创建或访问账户和钱包

App 使用账户来访问个人资料和会话，并使用 **钱包（Wallet）** 进行区块链授权。请妥善保护通行密钥、纸钱包资料、恢复信息、设备和其他凭据。确认交易前，请检查每个地址、资产、金额、资金池、费用和授权。

界面会在注册流程中以及发布代金券或资金池之前要求您确认条款。继续之前，请阅读[服务条款](/zh/governance/terms)和[隐私声明](/zh/governance/privacy)。

### 3. 创建代金券和商品或服务项目

为自己能够合理提供的东西创建代金券。可以把它理解为制作自己的礼品卡：您说明它代表什么，以及使用条件是什么。

一张完整的代金券包含几个彼此独立的层面：

1. 代币合约机制和余额；
2. 发行方公布的代金券条款；
3. 一项或多项描述相关商品或服务的 **商品或服务项目（Offering）** 记录；以及
4. 发行方在现实世界中的履行。

创建或铸造代币，并不能证明相关商品或服务项目确实存在、发行方具备履行能力，或 Grassroots Economics Foundation（GEF）保证履行。

### 4. 发布或回应需求

使用需求来说明您正在寻找什么，包括数量、地点、时间和合适的联系方法。其他参与者可以发现这项需求、查看您公开的代金券和商品或服务项目，并决定是否与您联系。

应明确协商内容和责任。消息可以帮助参与者就交付、预约或其他细节达成一致，但承诺的内容取决于适用的代金券条款以及另行约定的交易条款。

### 5. 查找或创建承诺资金池

承诺资金池对选定的代金券进行筛选，并支持它们之间的交换。使用或支持资金池之前，请查看：

- 负有责任的 **资金池管理者（Pool Steward）** 和当前合约所有者；
- 获准进入的代金券和其他受支持资产；
- 汇率或报价方法；
- App 中的 **“信用额度（Credit limit）”**，它是资金池的代币余额上限，不是个人信用额度；
- 资金池费用和协议费用；
- 可用库存，以及资金池所有者提取流动性的权限；
- 代理、多签和依赖项控制者；以及
- 另行公布的贡献、担保、储备、奖励或保险条款。

存入资产会把资产转移到资金池的 `SwapPool` 中。Protocol v1.1.0 不会自动赋予存款人资金池份额、还款权、提款权、奖励或治理权。

### 6. 发送或交换代金券

使用 **发送（Send）** 直接转移代金券。使用 **资金池交换（Pool swap）**，通过一个资金池把一种受支持资产换成另一种。

App 的 **可存入（Credit）** 视图还可以查找通过多个独立治理资金池可达的代金券。选择 **获取（Get）** 来指定想获得的代金券，或选择 **花费（Spend）** 来指定想使用的代金券。然后查看：

1. **支付方式（Pay with）** 和 **估算（Estimate）**；
2. **路径详情（Route details）**，包括每个资金池、金额、资金池费用和协议费用；
3. 最低收到数量和报价到期时间；以及
4. 在选择 **确认兑换（Confirm exchange）** 前，检查准备好的钱包批次。

并非每张代金券、每个资金池或每种钱包都支持路由交换。App 会检查您的选项是否可以交换。[软件路由参考](https://software.cosmolocal.credit/contracts/routing)以英文维护当前资格规则和技术要求。

路线发现只是估算。签名前，请审核最终报价，包括最低收到数量和到期时间。当前路由交换要么整体成功，要么各资金池交换一起回滚。提交后，请检查收据中的结果、交换数量和费用。

### 7. 向发行方使用代金券

阅读代金券条款，并按照发行方的预约、交付或联系流程操作。在当前 App 中，**“兑付（Redeem）”** 会打开普通发送流程，并预填代币所有者的地址。发送代金券属于兑付出示，并不能证明发行方已经提供承诺的商品或服务。

履行后，发行方应记录 **解除（discharge）**，使已经履行的单位不能再次使用，例如按照公布的条款接收、销毁、取消或以其他方式停用这些单位。

## 发布之前

代金券、资金池、商品或服务项目、需求、目录、帖子和评价可能具有不同的可见范围。发布资源之前：

- 选择一个可以安全公开的地图位置；精确坐标可能会显示；
- 检查未登录和已登录状态下分别会显示哪些信息；
- 使用适合预期受众的联系方式；
- 除非确实打算公开，否则不要把私人个人资料信息复制到公共资源中；以及
- 阅读隐私声明中的[“哪些信息会公开？”](/zh/governance/privacy#4-哪些信息会公开)部分。

## 当前 App 操作

| App 操作 | 作用 |
| --- | --- |
| **发送（Send）** | 将代币余额转移到另一个地址。 |
| **资金池交换（Pool swap）** | 通过一个 `SwapPool` 交换受支持资产。链上结算不能证明发行方已履行承诺。 |
| **路由交换（Routed exchange）** | 在一笔有明确边界的同链钱包交易中，按顺序执行多次资金池交换。它不会合并各资金池的治理。 |
| **“兑付（Redeem）”** | 预填向代币所有者发送代币的流程，作为兑付出示。履行和解除仍是不同步骤。 |
| **“申请停用（Request retirement）”** | 允许当前所有者请求管理员停用代金券或资金池。请求待处理期间，资源仍保持活跃；所有者可以取消请求，管理员可以批准或拒绝。停用不会删除合约、余额或历史记录。 |
| **资金池停用** | 获批后，阻止新的资金池交换和存款，但仍允许可用的提款。它不会删除此前的结算记录。 |
| **提取资金池流动性** | 允许资金池所有者把可用库存转移到选定地址。 |
| **收取费用** | 把累计的资金池费用发送给配置的接收方。 |

## 责任和重要限制

[Grassroots Economics Foundation](https://grassrootseconomics.org/about/) 运营 App 和支持基础设施。除非 GEF 明确接受某笔特定交易中的其他角色，否则它不是用户创建代金券的发行方、用户创建资金池的管理者、托管人、贷款人、借款人、担保人、保险人或兑换方。

交易前请记住：

- 您必须符合服务条款中的年龄、法律行为能力和管辖权要求。
- 发行方对自己的代金券承诺负责。
- 资金池管理者对自己公布的资金池规则以及明确承担的任何担保负责。
- 列入目录、评价、路线、限额、储备或区块链记录，并不自动表示认可、估值、履行记录、担保、保险政策或兑现现金的承诺。
- 支付服务、奖励、贡献安排和其他服务商集成取决于具体部署，并需要各自的披露。

App 支持可用的直接和路由资金池交换。跨链路由、资金池自动再平衡、批量净额结算、共享保险、拟议治理资产、网络流动性计划和受监管支付通道仍属于拟议功能或取决于具体部署，除非某个具体部署明确表示已经启用。

更多信息请参阅[简单示例和进阶示例](/zh/introduction/example)、[协议概述](/zh/protocol/overview)或[治理机制](/zh/governance/mechanics)。
