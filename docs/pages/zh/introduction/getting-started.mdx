# 入门

Cosmo-Local Credit (CLC) 是一款渐进式网页应用。用户可以通过独立治理的承诺资金池，创建、发现、持有、转移和交换数字资产，包括可兑付的代金券。CLC App 可在 [cosmolocal.credit](https://cosmolocal.credit) 使用。

[Grassroots Economics Foundation](https://grassrootseconomics.org/about/) (GEF) 运营该应用及配套基础设施。除非 GEF 对特定商品或服务项目或交易明确接受其他角色，否则 GEF 不是用户创建代金券的发行方、用户创建资金池的管理者、托管人、贷款方、借款方、担保人、保险人或兑付方。发行方对其代金券承诺负责，资金池管理者对其资金池规则负责。

请阅读 [概念和术语](/zh/introduction/concepts)，了解本文档使用的产品层级、角色、操作、价值、费用和状态术语。

创建账户或交易前，请阅读 [服务条款](/zh/governance/terms)。请特别注意：

- 您必须至少年满 18 岁，已达到适用于您的法定成年年龄，并具有签订合同的能力。
- 您负责确认您的账户、代金券、资金池或交易在所有相关司法管辖区都合法。
- 您必须保护钱包凭证。GEF 可能无法恢复丢失的钱包或撤销已授权的交易。
- 公共区块链上的交易和记录可能公开可见、永久保留且无法撤销。
- 应用中的上架不代表 GEF 认可，也不保证兑付、价值、流动性、可兑换性或现金兑付。

## 从当前应用开始

### 1. 浏览市场

打开 [cosmolocal.credit](https://cosmolocal.credit) 浏览公开的 **市场**。市场是应用的发现目录。请查看负责的发行方、所承诺的商品或服务、地点、可用性和公布条款。市场上架不会自动构成交换场所、卖方关系、独立估值、认可或保证。

### 2. 创建或访问账户和钱包

应用使用账户来管理个人资料和会话，使用钱包授权区块链交易。请保护通行密钥、纸质钱包材料、恢复信息、设备和其他凭证。确认交易前，请检查每项资产、金额、地址、资金池、费用和授权。

### 3. 创建代金券

代金券由几个不同层级组成：

1. 代币合约机制和余额；
2. 发行方对代金券的命名和公布条款；
3. 一条或多条与相关商品或服务有关的商品或服务项目记录；以及
4. 发行方在现实世界中的履约。

仅创建或铸造代币，并不足以证明存在某项商品或服务、发行方有能力提供它，或 GEF 保证兑付。

### 4. 创建或评估承诺资金池

承诺资金池是一项受治理的安排。它当前的 `SwapPool` 合约可以持有受支持的代币库存并执行直接交换。使用或向其注入资产前，请查看：

- 负责的资金池管理者和当前合约所有者；
- 代理管理员和已配置依赖项的控制者；
- 准入的代金券和其他受支持资产；
- 汇率或报价方法；
- 应用中的 **“信用额度”**：它是资金池的代币余额上限，而不是个人信用额度；
- 资金池费用和协议费用；
- 可用库存以及资金池所有者提取流动性的权力；以及
- 单独公布的出资、担保、储备或保险条款。

存入会将资产转入 `SwapPool`。Protocol v1.1.0 不会铸造资金池份额代币，也不会自动赋予存入方偿还、提取、奖励或治理权利。

### 5. 正确理解各项操作

- **发送** 会将代币余额转移到另一个地址。
- **资金池交换** 会通过一个 `SwapPool` 将一种受支持资产换成另一种。链上交换结算不证明发行方已履约。
- **“兑付”** 会打开发送流程，并预先填入代币所有者的地址。这会把代金券出示或退还给发行方；完成兑付还需要发行方履行承诺，并留下防止重复使用的核销记录。
- **“停用代金券”** 会隐藏目录上架。它不会销毁余额、取消代金券或消灭发行方的未履行义务。
- **资金池流动性提取** 允许资金池所有者转移可用库存。
- **费用收取** 会将已累积的资金池费用发送给已配置的接收方。

请参阅 [代金券实例](/zh/introduction/example)，了解完整生命周期。

## 当前、取决于部署以及拟议的功能

当前应用提供市场，并支持账户、钱包、代金券、商品或服务项目、资金池、转移、直接资金池交换和相关记录。可用性取决于活跃部署、资产、资金池配置、设备、网络、资格、提供方、司法管辖区和公布条款。

支付服务、支持方式、奖励、担保、出资安排和其他提供方集成均取决于部署。提供这些功能时，必须披露负责方、费用、限制、资格和法律条款。

Protocol v1.1.0 提供直接资金池执行和仅报价的 `SwapRouter`。多跳执行、HTLC 或托管路由、批量净额结算、共享保险、拟议的治理资产、网络流动性计划和受监管支付渠道仍属拟议或取决于部署，除非特定部署明确说明这些功能已活跃。

任何未来贷款或其他信贷产品都需要单独提供的补充条款和交易条款。普通转移、资金池存入、资金池交换、兑付出示、履约或核销不会自动构成贷款、预付款或偿还。
