# 入门

Cosmo-Local Credit (CLC) 是一款渐进式网页应用。用户可以通过独立治理的承诺资金池，创建、发现、持有、转移和交换数字资产，包括可兑付的代金券。CLC App 可在 [cosmolocal.credit](https://cosmolocal.credit) 使用。

[Grassroots Economics Foundation](https://grassrootseconomics.org/about/) (GEF) 运营该应用及配套基础设施。除非 GEF 对特定商品或服务项目或交易明确接受其他角色，否则 GEF 不是用户创建代金券的发行方、用户创建资金池的管理者、托管人、贷款方、借款方、担保人、保险人或兑付方。发行方对其代金券承诺负责，资金池管理者对其资金池规则负责。

请阅读 [概念和术语](/zh/introduction/concepts)，了解本文档使用的产品层级、角色、操作、价值、费用和状态术语。

创建账户或交易前，请阅读 [服务条款](/zh/governance/terms)。请特别注意：

- 您必须至少年满 18 岁，已达到适用于您的法定成年年龄，并具有签订合同的能力。
- 您负责确认您的账户、代金券、资金池或交易在所有相关司法管辖区都合法。
- 您必须保护钱包凭证。GEF 可能无法恢复丢失的钱包或撤销已授权的交易。
- 公共区块链上的交易和记录可能公开可见、永久保留且无法撤销。
- 应用中的上架不代表 GEF 认可，也不保证兑付、价值、流动性、可兑换性或现金兑付。

## 从当前应用开始

### 1. 浏览市场

打开 [cosmolocal.credit](https://cosmolocal.credit) 浏览公开的 **市场**。市场是应用的发现目录。请查看负责的发行方、所承诺的商品或服务、地点、可用性和公布条款。市场上架不会自动构成交换场所、卖方关系、独立估值、认可或保证。

### 2. 创建或访问账户和钱包

应用使用账户来管理个人资料和会话，使用钱包授权区块链交易。请保护通行密钥、纸质钱包材料、恢复信息、设备和其他凭证。确认交易前，请检查每项资产、金额、地址、资金池、费用和授权。

### 3. 创建代金券

代金券由几个不同层级组成：

1. 代币合约机制和余额；
2. 发行方对代金券的命名和公布条款；
3. 一条或多条与相关商品或服务有关的商品或服务项目记录；以及
4. 发行方在现实世界中的履约。

仅创建或铸造代币，并不足以证明存在某项商品或服务、发行方有能力提供它，或 GEF 保证兑付。

### 4. 创建或评估承诺资金池

承诺资金池是一项受治理的安排。它当前的 `SwapPool` 合约可以持有受支持的代币库存并执行直接交换。使用或向其注入资产前，请查看：

- 负责的资金池管理者和当前合约所有者；
- 代理管理员和已配置依赖项的控制者；
- 准入的代金券和其他受支持资产；
- 汇率或报价方法；
- 应用中的 **“信用额度”**：它是资金池的代币余额上限，而不是个人信用额度；
- 资金池费用和协议费用；
- 可用库存以及资金池所有者提取流动性的权力；以及
- 单独公布的出资、担保、储备或保险条款。

存入会将资产转入 `SwapPool`。Protocol v1.1.0 不会铸造资金池份额代币，也不会自动赋予存入方偿还、提取、奖励或治理权利。

### 5. 直接兑换或通过路径兑换

应用的**可存入**视图可以根据您钱包中的代金券，查找可获得的其他代金券。要获得目标代金券，可能需要一次资金池兑换，也可能需要经过多个独立治理资金池的路径。当前公开部署最多搜索包含三次资金池兑换的路径。

进行兑换时：

1. 对希望获得的代金券选择**获取**，或对希望使用的代金券选择**花费**；
2. 核对可用的**支付方式**和**估算**；
3. 打开**路径详情**，查看每个资金池、兑换、金额、资金池费用和协议费用；
4. 选择**核对**，检查最低收到金额和报价有效期，然后选择**确认兑换**；以及
5. 签署准备好的钱包批次。

CLC Core 根据已索引的资金池和代金券信息查找可能的路径。路径发现只是估算。签署前，CLC Core 会在同一个固定区块读取相关资金池状态，生成权威报价，为每一跳设置最低输出和截止时间，并模拟整个批次。应用目前不会另收路径服务费；每一跳仍可收取已配置的资金池费用和额外协议费用。

签署后的路径会作为一笔同链交易提交。每一跳都使用同一个、与应用兼容的钱包。如果批次中的任何授权或资金池兑换失败，整笔交易都会回滚，因此此前的跳也不会保留为已结算状态。收据会用一个跟踪 ID 汇总路径，并显示状态、交易哈希、每个资金池、已结算金额，以及每一跳的资金池费用和协议费用。

路径可能不可用，原因包括：钱包没有符合条件的输入代金券；某资金池未准入该代币；资金池的代币余额上限会被超过；输出库存不足；报价器或代币不受支持；或者路径服务的数据暂时过时或服务不可用。报价也可能到期、因资金池状态变化而失效、未通过最终模拟，或在链上执行时回滚。请刷新路径并核对新报价，不要假定较早的估算仍然有效。

当前路径执行支持与 CLC App 兼容的 EOA/Calibur 钱包。目前不会为 Safe 或其他合约钱包准备路径兑换。

### 6. 使用正确的行动

- **发送**将代币余额转移到另一个地址。
- **资金池兑换**通过一个 `SwapPool` 将一种受支持资产换成另一种。它可以是直接兑换，也可以是路径兑换中的一跳。链上兑换结算不能证明发行方已经履约。
- **路径兑换**在一笔有明确限制的同链钱包交易中，执行一组有顺序的资金池兑换。它不会合并各资金池的治理，也不会让路径运营方对发行方履约负责。
- **“兑付”**会打开发送流程，并预先填入代币所有者地址。它把代金券向发行方出示或退还；完成兑付还需要发行方履行承诺，并留下防止重复使用的核销记录。
- **“停用代金券”**会隐藏目录条目。它不会销毁余额、取消代金券或消除发行方尚未履行的义务。
- **资金池流动性提取**允许资金池所有者转移可用库存。
- **费用收取**把累积的资金池费用发送给已配置的接收方。

## 当前、取决于部署以及拟议的功能

当前应用提供市场目录，以及账户、钱包、代金券、商品或服务项目、资金池、转移、直接资金池兑换、应用层路径兑换和相关记录的受支持流程。可用性取决于当前部署、资产、资金池配置、库存、钱包类型、设备、网络、资格、提供方、司法管辖区和公布条款。

支付服务、支持方式、奖励、担保、出资安排和其他提供方集成均取决于部署。提供这些功能时，必须披露负责方、费用、限制、资格和法律条款。

Protocol v1.1.0 提供直接资金池执行和仅用于报价的 Solidity `SwapRouter`。生产环境中的 CLC App 和 CLC Core 在这些合约之上提供同链多跳路径发现、权威报价、钱包批次准备、模拟、中继和分组收据。Solidity `SwapRouter` 并未变成执行合约。跨链 HTLC 或托管路径、自动资金池再平衡、批量净额结算、共享保险、拟议治理资产、网络流动性计划和受监管支付服务仍属于拟议或取决于部署的功能，除非具体部署明确说明已启用。

任何未来贷款或其他信贷产品都需要单独提供的补充条款和交易条款。普通转移、资金池存入、资金池交换、兑付出示、履约或核销不会自动构成贷款、预付款或偿还。
