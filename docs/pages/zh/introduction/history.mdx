# 历史

[Grassroots Economics Foundation](https://grassrootseconomics.org/about/) (GEF) 建立和管理历史性 Sarafu Network 现在运营 CLC App 肯尼亚的社区与共享承诺一起生活和学习,通过共同承诺来维持互惠服务. [基层经济:反思和实践](https://grassrootseconomics.org/book/) 承诺可以在不需要中央机构的情况下进行交换,履行和更新的承诺.

这项工作首先通过社区货币来表达.当国家货币稀缺时,记录和履行义务的本地方法.更深层次的教训不是一个特定的货币.它是一个策划模式,共享估值,保护共同资产的限制和保持互惠的交换.这些教训为承诺汇集协议 (CPP) 提供了信息.

## 历史上的 Sarafu Network 转移到 Cosmo-Local Credit

历史性 Sarafu Network 作为社区货币的实践学习环境,承诺资金池通过社区,学校,诊所,农场,合作社和其他地方组织.GEF 通过这种经验,研究了如何将独立管理的承诺连接起来,而不会使它们成为一个统治市场或取消地方责任.

服务曾经被表达为 Sarafu Network 转移到 CLC App 在 [cosmolocal.credit](https://cosmolocal.credit) 根据 GEF 现在,所有 Sarafu 账户,钱包,代币,券商,积分库,余额,报告,参与者或义务都已迁移到当前的应用程序中.

Cosmo-Local Credit 现在的产品家族包括:CLC App 作为一个独立管理的券商,承诺资金池发行方仍然对承诺负责,资金池管理者它们仍然负责其规则和任何公布的保证,社区和机构可以使用适合自己的情况的治理安排.

一条路,简而言之:

1. 当现金短缺时,
2. 承诺集成开发了可重复使用的协议组件的管理,估值,限制和交换.
3. 历史悠久的 Sarafu Network 在许多真正的社区和组织中测试并完善了这些想法.
4. 服务转移到 Cosmo-Local Credit,但没有代表所有历史用户,资产,记录或义务转移.
5. 目前的应用程序提供支持的钱包,代金券,库存和直接交换工作流程;更广泛的路由,清算,流动性,保险和治理机制仍然被提出或依赖于部署.

阅读 [概念和词汇](/zh/introduction/concepts) 在文件中使用的层次和状态术语. [服务条款](/zh/governance/terms) 管理 CLC App 的使用. [白皮书](/zh/white-paper) 提供更广泛的设计,研究和路线图.

## 从基层经济学中进一步学习

这些组织和教育资源提供了额外的背景.它们补充,而不是定义当前 CLC App 和协议行为.

- [关于基层经济](https://grassrootseconomics.org/about/) —其使命,团队,价值观和更长的组织历史.
- [研究和开放数据](https://grassrootseconomics.org/research/) er同行审查的论文,工作文件,数据集,报告和学术研究.
- [基层经济:反思和实践](https://grassrootseconomics.org/book/) —本书以免费的数字和音频格式,印刷版也可用.
- [草根日志](https://grassrootseconomics.org/blog/) community现场笔记,研究更新,社区故事和不断发展的实践.
- [教育游戏](https://grassrootseconomics.org/games/) learning学习资源关于承诺,结算,资源流动,交流和汇集.
