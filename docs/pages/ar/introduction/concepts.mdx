# المفاهيم والمصطلحات

يربط Cosmo-Local Credit بين تطبيق وبروتوكول مفتوح وصناديق ذات حوكمة مستقلة والالتزامات الواقعية التي تمثلها القسائم. تعمل هذه الطبقات معًا، لكنها ليست الشيء نفسه.

تعرّف هذه الصفحة المصطلحات المستخدمة في الوثائق. وتظهر تسميات التطبيق الدقيقة بين علامتي اقتباس عندما تستخدم الواجهة اسمًا مختصرًا أو قد يحتمل أكثر من معنى.

## طبقات المنتج والبروتوكول

| المصطلح | المعنى |
| --- | --- |
| **Cosmo-Local Credit (CLC)** | عائلة المنتجات: CLC App ووثائقه والعمل الأوسع في تجميع الالتزامات. |
| **CLC App** | تطبيق الويب التقدمي على [cosmolocal.credit](https://cosmolocal.credit). تدير GEF هذه الواجهة وخدماتها الداعمة. |
| **بروتوكول تجميع الالتزامات (CPP)** | نموذج قابل لإعادة الاستخدام للتنسيق والتقييم ووضع الحدود والتبادل والحوكمة الخاضعة للمساءلة. |
| **Protocol v1.1.0** | الإصدار المتحقق منه للعقود الذكية العامة والموثق في [مرجع البروتوكول](/ar/protocol/overview). |
| **صندوق الالتزامات** | ترتيب خاضع للحوكمة ينسق الأصول وينشر القواعد ويتيح التبادل. ويُستخدم **الصندوق** اختصارًا. |
| **`SwapPool`** | عقد البروتوكول الحالي الذي يحتفظ بمخزون الرموز وينفذ المبادلات المباشرة. وهو مكوّن تقني واحد في صندوق الالتزامات. |
| **رمز حوكمة CLC المقترح** | تصميم حوكمة مستقبلي في الورقة البيضاء. وليس أصلًا حاليًا في CLC App أو Protocol v1.1.0. |
| **صندوق شبكة CLC المقترح** | تصميم مستقبلي للمقاصة والتنسيق على مستوى الشبكة. وهو ليس `SwapPool` حاليًا. |

## الرموز والقسائم والعروض

**الرمز** رصيد على السلسلة أو أصل رقمي. ويمكن لآليات الرمز تسجيل المعروض والتحويلات وانتهاء الصلاحية والحرق، لكنها لا تعد بمفردها بسلع أو خدمات أو تحويل نقدي أو استرداد.

**القسيمة** رمز أو سجل تمثله جهة مصدرة باعتباره التزامًا قابلًا للاسترداد وفق شروط منشورة. وينبغي أن تحدد الشروط ما هو موعود، ومن المسؤول، وأين ومتى يمكن تقديم القسيمة، والحدود الجوهرية، وكيفية الوفاء وتقديم الشكاوى.

**العرض (Offering)** هو سجل الكتالوج للسلع أو الخدمات المرتبطة بقسيمة. ولا يؤدي نشر عرض إلى سك رموز أو إثبات التوفر أو إثبات وقوع الوفاء.

هذه أربع طبقات مستقلة:

1. عقد الرمز والأرصدة؛
2. وصف القسيمة وشروطها المنشورة؛
3. سجل واحد أو أكثر من سجلات العروض؛ و
4. أداء الجهة المصدرة في الواقع.

## الأدوار المسؤولة والتحكم التقني

| الدور أو السلطة | المسؤولية أو الصلاحية |
| --- | --- |
| **الجهة المصدرة** | تنشر التزام القسيمة وتفي به. ولا تنتقل هذه المسؤولية تلقائيًا لمجرد تغير ملكية العقد. |
| **الحامل** | يتحكم في رصيد قسيمة. ولا يثبت التحكم وقوع الوفاء أو وجود قيمة نقدية أو ضمان. |
| **مقدم الخدمة** | صفة موجهة للجمهور. ويصبح مقدم الخدمة جهة مصدرة عندما ينشر التزامًا في صورة قسيمة. |
| **مشرف الصندوق** | الشخص أو التعاونية أو الجهة العامة أو الاتحاد أو المحفظة متعددة التوقيعات أو الخدمة أو غير ذلك من الهياكل المسؤولة التي تنشر قواعد الصندوق وتديرها. |
| **مالك الصندوق** | العنوان الذي يمتلك صلاحيات المالك الحالية في `SwapPool`، بما فيها الإعداد وتحصيل الرسوم وسحب السيولة المتاحة. |
| **مدير الوكيل** | الجهة القادرة على ترقية تنفيذ عقد يعمل بالوكالة. وقد تختلف عن مالك الصندوق. |
| **المتحكم في المكونات التابعة** | مالك أو كاتب يتحكم في سجل أو محدد حدود أو عارض أسعار أو أوراكل أو سياسة رسوم أو متحكم في رسوم البروتوكول. |
| **مشرف الكتالوج** | مشغّل في التطبيق يستطيع تصحيح سجلات الكتالوج أو إخفاءها أو إعادتها من دون تغيير الأرصدة على السلسلة. |
| **مستلم الرسوم** | العنوان المحدد لاستلام رسوم صندوق أو رسوم البروتوكول. وليس بالضرورة مشرف الصندوق أو مالكه. |
| **الداعم أو مقدم السيولة** | مشارك يساهم بأصول وفق شروط منفصلة ومعلنة. ولا ينشئ `SwapPool` الحالي حصصًا في الصندوق أو حقوقًا تلقائية في السداد أو السحب أو المكافآت أو الحوكمة. |

«عضو المجتمع» تعبير اجتماعي غير رسمي. ولا ينشئ بمفرده قبولًا أو ملكية أو حوكمة أو حق سداد أو أي حقوق قانونية أخرى.

## الإجراءات ودورة الحياة

| مصطلح التطبيق أو الوثائق | معناه |
| --- | --- |
| **إنشاء قسيمة أو نشرها** | نشر رمز أو إعداده ونشر سجل القسيمة وشروطها في الكتالوج. |
| **الإصدار أو السك** | إنشاء رصيد من الرموز بواسطة المالك أو الكاتب المحدد. |
| **نشر عرض** | إضافة سجل لسلعة أو خدمة تحت قسيمة. |
| **إرسال** | نقل رصيد من الرموز إلى عنوان آخر. |
| **«استرداد»** | يفتح في التطبيق الحالي مسار الإرسال مع إدخال عنوان مالك الرمز مسبقًا. ويقدّم الرموز أو يعيدها إلى الجهة المصدرة، لكنه لا يثبت وقوع الوفاء. |
| **الوفاء** | تقدم الجهة المصدرة السلع أو الخدمات أو المنافع أو الأداء الآخر الذي وعدت به. |
| **الإبراء** | تسجيل الوحدات التي تم الوفاء بها حتى لا تُقدَّم مرة أخرى، مثلًا باستلامها أو حرقها أو إلغائها أو تعطيلها بطريقة أخرى وفق الشروط المنشورة. |
| **«سحب القسيمة من التداول»** | إخفاء القسيمة من كتالوج التطبيق. تبقى الأرصدة والسجل، ويمكن للمسؤول إعادة الإدراج. وهذا ليس حرقًا ولا إلغاءً. |
| **إيداع الصندوق أو المساهمة فيه** | نقل أصول إلى `SwapPool`. ولا تنشأ حقوق السداد أو السحب أو المكافآت أو الحوكمة إلا إذا أُفصح عنها بصورة منفصلة. |
| **مبادلة عبر الصندوق** | استبدال أصل مدعوم بآخر من خلال `SwapPool` واحد. وهذا ليس وفاءً من الجهة المصدرة ولا قرضًا تلقائيًا. |
| **سحب سيولة الصندوق** | ينقل مالك الصندوق المخزون المتاح إلى عنوان محدد. |
| **تحصيل الرسوم** | يجمع المستلم المحدد رسوم الصندوق المتراكمة. |

استخدم **تسوية المبادلة** للتحويلات على السلسلة وحساب الرسوم اللذين يكملان مبادلة عبر صندوق. واستخدم **تقديم القسيمة للاسترداد** و**الوفاء** و**الإبراء** للمراحل المستقلة في دورة حياة القسيمة في الواقع.

## السوق والقيم والحدود والرسوم

**السوق** في التطبيق كتالوج لاكتشاف القسائم والصناديق والعروض والمعلومات العامة. ولا يُعد الإدراج تلقائيًا مكانًا للتبادل أو علاقة بيع أو تأييدًا أو تقييمًا أو ضمانًا.

افصل بين مصطلحات القيمة التالية:

- **سعر العرض:** المبلغ المطلوب مقابل سلعة أو خدمة مدرجة؛
- **القيمة المعلنة للقسيمة:** القيمة التي تمثلها الجهة المصدرة في شروطها المنشورة؛
- **سعر الصرف أو عرض السعر في الصندوق:** معامل المعاملة الذي ينتجه عارض الأسعار المحدد للصندوق؛
- **مرجع الأوراكل:** بيانات خارجية تستخدمها وحدة تقييم مضبوطة؛ و
- **شروط الاسترداد:** ما تعد الجهة المصدرة بتقديمه وتحت أي شروط.

تشير تسمية **«حد الائتمان»** في التطبيق إلى سقف رصيد الرمز المضبوط للصندوق: أي أكبر كمية من ذلك الرمز يمكن أن يحتفظ بها الصندوق بعد الإيداع. وليس هذا خط ائتمان شخصيًا، ولا اختبارًا لقدرة الجهة المصدرة، ولا ضمانًا للاسترداد. وتختلف عنه الحدود الدورية وحدود الحسابات والشبكة المقترحة في الورقة البيضاء.

يمكن لـ Protocol v1.1.0 الحالي فرض **رسم صندوق** و**رسم بروتوكول** إضافي. ويصف النموذج المقترح في الورقة البيضاء بصورة منفصلة **حصة شبكة** مستقبلية تُقتطع من رسوم الصندوق، ورسومًا محتملة للتوجيه أو الخدمات. ويجب عدم دمج هذه النماذج عند شرح الرسوم الحالية أو حساب الإيرادات المستقبلية.

## الحماية والأدلة

لا يثبت التنسيق أو الإدراج في سجل أو وجود حد أو احتياطي أو ظهور الأصل في التطبيق أو معاملة على سلسلة الكتل بمفرده وجود تأييد أو قدرة لدى الجهة المصدرة أو وقوع الوفاء أو وجود ضمان أو تأمين.

ينبغي لأي حماية أن تحدد الطرف الملزم والحدث المغطى والتمويل والسقف والاستثناءات والمدة والأدلة وإجراءات المطالبة. ويمكن للسجلات على السلسلة إظهار العناوين والأصول والمبالغ والطوابع الزمنية وأحداث العقود. أما أداء الجهة المصدرة والرضا ومداولات الحوكمة والأثر الاجتماعي فتحتاج إلى إفصاحات أو تقارير أو إقرارات أو أدلة أخرى مستقلة.

## مصطلحات الحالة

- **حالي:** تم التحقق منه في CLC App أو Protocol v1.1.0 كما تصفه هذه الوثائق.
- **معتمد على التنفيذ:** لا يتوفر إلا عندما يتيحه تنفيذ أو صندوق أو مقدم خدمة أو ولاية قضائية أو سياسة منشورة بعينها.
- **تاريخي:** دليل أو وظيفة من خدمة Sarafu Network السابقة.
- **مقترح:** تصميم أو آلية ضمن خارطة الطريق لا تُعرض باعتبارها منشورة حاليًا.

يطبق [دليل البدء](/ar/introduction/getting-started) هذه المصطلحات على التطبيق الحالي. ويوثق [مرجع البروتوكول](/ar/protocol/overview) العقود المتحقق منها، بينما تعرض [الورقة البيضاء](/ar/white-paper) التصميم والمقترحات الأوسع.

ولمقدمة تعليمية إضافية من خلال اللعب حول الالتزامات والتسوية وتدفقات الموارد والتبادل والتجميع، استكشف [ألعاب Grassroots Economics التعليمية](https://grassrootseconomics.org/games/). هذه الألعاب موارد تعليمية وليست تعريفات لسلوك التطبيق أو البروتوكول الحالي.
