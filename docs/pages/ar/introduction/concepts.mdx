# المفاهيم والمصطلحات

يربط Cosmo-Local Credit بين من يقدمون السلع أو الخدمات، ومن يحتاجون إليها، وصناديق التزامات ذات حوكمة مستقلة تتيح تبادل القسائم. تبدأ هذه الصفحة بالمصطلحات التي يراها المشارك، ثم تشرح الطبقات التقنية التي تقوم عليها.

تظهر تسميات App الدقيقة بين علامتي اقتباس عندما تستخدم الواجهة اسمًا أقصر أو يحتمل الالتباس.

## المصطلحات اليومية

| المصطلح | المعنى بلغة بسيطة |
| --- | --- |
| **القسيمة** | التزام قابل للتحويل — يشبه بطاقة الهدايا — تعد جهته المصدرة بسلع أو خدمات أو منافع أو أداء آخر محدد وفق شروط منشورة. |
| **الجهة المصدرة** | الشخص أو المؤسسة التي تنشئ القسيمة وتظل مسؤولة عما تعد به. |
| **العرض** | سجل في الكتالوج يصف سلعًا أو خدمات مرتبطة بقسيمة. ويساعد الناس على اكتشاف العرض، لكنه لا يثبت التوفر أو الوفاء. |
| **الطلب** | تعبير منشور عن شيء يبحث عنه المشارك. ولا يعني بمفرده قبول عرض أو حجز سلع أو التصريح بتبادل أو إنشاء التزام. |
| **السوق** | كتالوج App لاكتشاف القسائم والصناديق والعروض والطلبات وغيرها من المعلومات العامة. وليس تلقائيًا مكانًا للتبادل أو بائعًا أو تأييدًا أو ضمانًا. |
| **صندوق الالتزامات** | ترتيب خاضع للحوكمة يختار القسائم المدعومة وينشر قواعد التبادل ويحتفظ بالمخزون ويتيح التبادل. ويُختصر عادةً إلى **الصندوق**. |
| **مشرف الصندوق** | الشخص أو التعاونية أو الجهة العامة أو الاتحاد أو المحفظة متعددة التوقيع أو الخدمة أو أي هيكل مسؤول آخر ينشر قواعد الصندوق ويديرها. |
| **الحامل** | مشارك يتحكم في رصيد قسيمة. ولا يثبت الاحتفاظ بها الوفاء أو القيمة النقدية أو وجود ضمان. |
| **المحفظة** | الحساب وبيانات الاعتماد المستخدمة للتصريح بتحويلات الرموز والمبادلات عبر الصناديق. |

«عضو المجتمع» تعبير اجتماعي غير رسمي. ولا ينشئ بمفرده قبولًا أو ملكية أو حوكمة أو سدادًا أو حقوقًا قانونية أخرى.

## اكتشاف المشاركين والتواصل معهم

يساعد السوق الناس على العثور على القسائم والعروض والطلبات والصناديق. ويعني الإدراج أن App يستطيع عرض سجل؛ لكنه لا يثبت دقة معلوماته أو توفر المخزون أو نجاح المعاملة.

يمكن للمشارك نشر طلب والتواصل مع مشارك آخر من خلال خصائص الاتصال أو المراسلة المتاحة. ولا يؤدي طلب اتصال أو رسالة أو مناقشة حجز أو استجابة لطلب، بمفرده، إلى:

- قبول قسيمة أو عرض؛
- التصريح بتحويل أو مبادلة عبر صندوق؛
- إثبات التسليم أو الرضا؛
- الوفاء بقسيمة أو إبرائها؛ أو
- جعل GEF طرفًا في اتفاق المشاركين.

المراجعات تعليقات عامة على قسيمة أو صندوق. وهي ليست دليل أهلية خاصًا ولا عناية واجبة من المشغّل ولا ضمانًا ولا إثباتًا لوقوع الوفاء.

## القسائم والرموز والعروض

**الرمز** رصيد على السلسلة أو أصل رقمي. ويمكن لآليات الرمز تسجيل المعروض والتحويلات وانتهاء الصلاحية والحرق، لكنها لا تعد بمفردها بسلع أو خدمات أو تحويل إلى نقد أو استرداد.

**القسيمة** رمز أو سجل تمثله الجهة المصدرة بوصفه التزامًا قابلًا للاسترداد وفق شروط منشورة. وينبغي أن تحدد تلك الشروط ما هو موعود، والطرف المسؤول، وأين ومتى يمكن تقديم القسيمة، والحدود الجوهرية، وعملية الوفاء والشكاوى.

**العرض** هو سجل الكتالوج للسلع أو الخدمات المرتبطة بقسيمة. وفي النثر العادي تعني كلمة «عرض» ببساطة شيئًا يقترحه المشارك؛ أما **العرض** بحرف كبير في الإنجليزية فهو اسم سجل App.

أبقِ هذه الطبقات الأربع منفصلة:

1. عقد الرمز والأرصدة؛
2. وصف القسيمة وشروطها المنشورة؛
3. سجل واحد أو أكثر من سجلات العروض؛ و
4. أداء الجهة المصدرة في العالم الحقيقي.

## الأدوار المسؤولة والتحكم التقني

| الدور أو السلطة | المسؤولية أو الصلاحية |
| --- | --- |
| **الجهة المصدرة** | تنشر التزام القسيمة وتفي به. ولا تنتقل هذه المسؤولية تلقائيًا لمجرد تغير ملكية العقد. |
| **مشرف الصندوق** | ينشر قواعد الصندوق ويديرها، ويظل مسؤولًا عن أي ضمان يعلن عنه الصندوق صراحةً. |
| **مالك الصندوق** | العنوان الذي يملك صلاحيات مالك `SwapPool` الحالية، ومنها التهيئة وتحصيل الرسوم وسحب السيولة المتاحة. |
| **الموقّعون في المحفظة متعددة التوقيع** | يتشاركون السلطة التقنية المسندة إلى المحفظة. ولا يؤدي تغيير الموقّعين أو الحد المطلوب إلى نقل مسؤولية الجهة المصدرة أو مساءلة المشرف أو الملكية القانونية ضمنًا. |
| **مسؤول الوكيل** | يستطيع ترقية تنفيذ عقد يعمل عبر وكيل. وقد يختلف عن مالك الصندوق. |
| **المتحكم في المكوّن التابع** | يتحكم في سجل أو محدد أو عارض أسعار أو أوراكل أو سياسة رسوم أو متحكم رسوم البروتوكول. |
| **مشرف الكتالوج** | يستطيع تصحيح سجلات الكتالوج أو إخفاءها أو إيقافها أو استعادتها من دون حذف العقود أو الأرصدة أو سجل السلسلة. |
| **متلقي الرسوم** | يتلقى رسم صندوق أو بروتوكول مهيأ. وليس بالضرورة مشرف الصندوق أو مالكه. |
| **الداعم أو مزود السيولة** | يساهم بأصول وفق شروط منفصلة ومعلنة. ولا ينشئ `SwapPool` الحالي تلقائيًا حصصًا في الصندوق أو حقًا في السداد أو السحب أو المكافأة أو الحوكمة. |

## الإجراءات ودورة الحياة

| مصطلح App أو الوثائق | معناه |
| --- | --- |
| **إنشاء قسيمة أو نشرها** | نشر رمز أو تهيئته ونشر سجل القسيمة وشروطها في الكتالوج. |
| **الإصدار أو السك** | إنشاء رصيد رمز وفق صلاحية المالك أو الكاتب المهيأة. |
| **نشر عرض** | إضافة سجل سلع أو خدمات تحت قسيمة. |
| **نشر طلب** | وصف حاجة للاكتشاف والتواصل المحتمل؛ ولا ينشئ معاملة بمفرده. |
| **إرسال** | نقل رصيد رمز إلى عنوان آخر. |
| **«استرداد»** | فتح مسار الإرسال مع إدخال عنوان مالك الرمز مسبقًا. وهذا تقديم للاسترداد، ولا يثبت الوفاء. |
| **الوفاء** | أن تقدم الجهة المصدرة السلع أو الخدمات أو المنافع أو الأداء الآخر الموعود. |
| **الإبراء** | تسجيل الوحدات التي تم الوفاء بها حتى لا تقدم مرة أخرى، مثلًا باستلامها أو حرقها أو إلغائها أو تعطيلها بطريقة أخرى وفق الشروط المنشورة. |
| **«طلب الإيقاف»** | يطلب المالك الحالي من مسؤول إداري إيقاف قسيمة أو صندوق. ويظل المورد نشطًا ما دام الطلب قيد النظر، ويمكن قبول الطلب أو رفضه أو إلغاؤه. |
| **إيقاف قسيمة** | إزالة القسيمة، بعد الموافقة، من الاستخدام النشط في الكتالوج. وتبقى العقود والأرصدة والالتزامات والسجل؛ والإيقاف ليس حرقًا أو إبراءً. |
| **إيقاف صندوق** | وقف المبادلات والإيداعات الجديدة بعد الموافقة، مع السماح بعمليات السحب المتاحة. وتبقى سجلات التسويات السابقة. |
| **إيداع أو مساهمة في الصندوق** | نقل أصول إلى `SwapPool`. ولا توجد حقوق في السداد أو السحب أو المكافأة أو الحوكمة إلا عندما تُفصح عنها شروط منفصلة. |
| **مبادلة عبر الصندوق** | تبادل أصول مدعومة من خلال `SwapPool` واحد. وليست وفاءً من الجهة المصدرة ولا قرضًا تلقائيًا. |
| **اكتشاف المسار** | العثور على مسارات محتملة عبر علاقات صناديق مهيأة. والاكتشاف تقدير وليس وعدًا قابلًا للتنفيذ. |
| **عرض سعر المسار** | حساب اقتراح محدود زمنيًا من حالة الصناديق المقروءة في كتلة مثبتة واحدة، ومحاكاته قبل التوقيع. |
| **التبادل الموجّه** | إرسال سلسلة مرتبة من المبادلات عبر الصناديق كحزمة محفظة واحدة على السلسلة نفسها. وفي المسار الحالي تتراجع كل الاستدعاءات إذا فشل أي منها. |
| **إيصال التبادل الموجّه** | يجمع حالة التتبع وتجزئة المعاملة وخطوات المسار والمبالغ المسوّاة ورسوم كل خطوة. |
| **سحب سيولة الصندوق** | يتيح لمالك الصندوق نقل المخزون المتاح إلى عنوان مختار. |
| **تحصيل الرسوم** | يرسل رسوم الصندوق المتراكمة إلى المستلم المهيأ. |

استخدم **تسوية المبادلة** للتحويلات على السلسلة وحساب الرسوم اللذين يكملان المبادلة عبر الصندوق. واستخدم **تقديم القسيمة للاسترداد** و**الوفاء** و**الإبراء** لمراحل دورة حياة القسيمة المنفصلة في العالم الحقيقي.

## طبقات المنتج والبروتوكول

| المصطلح | المعنى |
| --- | --- |
| **Cosmo-Local Credit (CLC)** | عائلة المنتج: CLC App ووثائقه والعمل الأوسع على تجميع الالتزامات. |
| **CLC App** | تطبيق الويب التقدمي على [cosmolocal.credit](https://cosmolocal.credit). تدير GEF هذه الواجهة وخدماتها الداعمة. |
| **CLC Core** | الخدمة الداعمة للكتالوجات وحالة السلسلة المفهرسة واكتشاف المسارات وعروض الأسعار المرجعية وتنسيق الترحيل وإيصالات التبادل الموجّه. وهي ليست عقدًا ذكيًا ولا مشرف صندوق. |
| **بروتوكول تجميع الالتزامات (CPP)** | النموذج القابل لإعادة الاستخدام للتنسيق والتقييم ووضع الحدود والتبادل والحوكمة المسؤولة. |
| **Protocol v1.1.0** | إصدار العقود الذكية العام الموثق في [مرجع البرمجيات المعتمد](https://software.cosmolocal.credit/contracts/) (بالإنجليزية). |
| **`SwapPool`** | عقد البروتوكول الحالي الذي يحتفظ بمخزون الرموز وينفذ المبادلات المباشرة. وهو مكوّن تقني واحد لصندوق الالتزامات. |
| **Solidity `SwapRouter`** | عقد Protocol v1.1.0 الذي يعرض سعر مسار مقترح عبر عدة صناديق. ولا يحفظ الأصول ولا ينفذ المسار. |
| **سير عمل التوجيه في التطبيق** | يعثر التطبيق والخدمات الداعمة على مسارات محتملة عبر الصناديق، ويحسبان عرض سعر للتبادل، ويطلبان إذن المشارك، ويبلّغان النتيجة. |
| **رمز حوكمة CLC المقترح** | تصميم حوكمة مستقبلي في الورقة البيضاء. وليس أصلًا حاليًا في App أو Protocol v1.1.0. |
| **صندوق شبكة CLC المقترح** | تصميم مستقبلي للمقاصة والتنسيق على مستوى الشبكة. وليس هو `SwapPool` الحالي. |

## القيم والائتمان والحدود والرسوم

أبقِ مصطلحات القيمة هذه منفصلة:

- **سعر العرض:** المقدار المطلوب مقابل سلعة أو خدمة مدرجة؛
- **القيمة المعلنة للقسيمة:** قيمة ممثلة في شروط الجهة المصدرة المنشورة؛
- **سعر الصرف أو عرض السعر في الصندوق:** معامل المعاملة الذي ينتجه عارض الأسعار المهيأ للصندوق؛
- **مرجع الأوراكل:** بيانات خارجية تستخدمها وحدة تقييم مهيأة؛ و
- **شروط الاسترداد:** ما تعد به الجهة المصدرة وتحت أي شروط.

يشير **الائتمان** في App إلى الالتزامات التي يمكن الوصول إليها وقدرة التبادل. ولا يعني تلقائيًا اقتراضًا شخصيًا أو قرضًا أو تقييمًا لقدرة الجهة المصدرة أو ضمانًا.

تعني تسمية **«حد الائتمان»** سقف رصيد الرمز المهيأ للصندوق: الحد الأقصى من ذلك الرمز الذي يمكن للصندوق الاحتفاظ به بعد الإيداع. أما الحدود المتجددة وحدود الحساب والشبكة المقترحة في الورقة البيضاء فهي آليات مختلفة.

يمكن لـ Protocol v1.1.0 فرض **رسم صندوق** و**رسم بروتوكول** إضافي على كل مبادلة عبر الصندوق. ويُفصّل التبادل الموجّه كليهما لكل خطوة. ولا يضيف App الحالي رسمًا منفصلًا لخدمة التوجيه. ويصف النموذج المقترح في الورقة البيضاء، بصورة منفصلة، حصة مستقبلية للشبكة ورسوم خدمات محتملة.

## المسارات والسيولة

**المسار** طريق مرتب يمر بصندوق واحد أو أكثر مستقل الحوكمة. و**عمق المسار** هو عدد مبادلات الصناديق في ذلك الطريق.

ليست كل القسائم والصناديق والمحافظ مؤهلة للتوجيه. وظهور قسيمة في صندوق لا يجعلها متاحة تلقائيًا عبر كل مسار. ويحتفظ [مرجع توجيه البرمجيات](https://software.cosmolocal.credit/contracts/routing) بقواعد الأهلية والإعدادات الحالية بالإنجليزية.

**السيولة المتاحة** هي المخزون الذي يستطيع الصندوق تقديمه وفق قواعده وحدوده ورسومه الحالية. ولا يثبت اتصال الصناديق توفر المبلغ الذي تريده. راجع عرض السعر النهائي؛ فقد ينتهي أو يصبح غير صالح إذا تغيرت ظروف الصندوق.

تنفيذ المسار الحالي على السلسلة نفسها وتبدأه المحفظة. ولا يجمع الحوكمة ولا يعيد توازن مخزون الصناديق تلقائيًا ولا يقاص الالتزامات بين أطراف متعددة ولا يثبت الوفاء. ويظل توجيه HTLC أو الضمان عبر السلاسل وإعادة التوازن التلقائي والتسوية الصافية للحزم مقترحًا أو معتمدًا على النشر.

## الحماية والأدلة

لا يثبت التنسيق أو الإدراج في سجل أو الحد أو الاحتياطي أو الظهور في App أو المراجعة أو معاملة البلوكشين، بمفرده، وجود تأييد أو قدرة لدى الجهة المصدرة أو وقوع الوفاء أو وجود ضمان أو تأمين.

ينبغي لأي حماية أن تحدد الطرف الملتزم والحدث المشمول والتمويل والحد الأقصى والاستثناءات والمدة والأدلة وعملية المطالبة. ويمكن للسجلات على السلسلة أن تظهر العناوين والأصول والمبالغ والطوابع الزمنية وأحداث العقود. أما أداء الجهة المصدرة والرضا ومداولات الحوكمة والأثر الاجتماعي فتتطلب أدلة منفصلة.

## كلمات الحالة

- **حالي:** سلوك متحقق منه في CLC App أو Protocol v1.1.0 الموصوف في هذه الوثائق.
- **معتمد على النشر:** متاح فقط عندما يتيحه نشر أو صندوق أو مقدم خدمة أو ولاية قضائية أو سياسة منشورة بعينها.
- **تاريخي:** دليل أو وظيفة من خدمة Sarafu Network السابقة.
- **مقترح:** تصميم أو آلية في خطة التطوير لا تُعرض بوصفها منشورة.

يطبّق [دليل بدء الاستخدام](/ar/introduction/getting-started) هذه المصطلحات على التطبيق الحالي. وتربط [نظرة عامة على البروتوكول](/ar/protocol/overview) هذه المفاهيم بـ[وثائق البرمجيات المعتمدة](https://software.cosmolocal.credit/)، بينما تعرض [الورقة البيضاء](/ar/white-paper) التصميم والمقترحات الأوسع.

لمقدمة تعليمية قائمة على اللعب حول الالتزامات والتسوية وتدفقات الموارد والتبادل والتجميع، استكشف [الألعاب التعليمية لـ Grassroots Economics](https://grassrootseconomics.org/games/). وهذه الألعاب موارد تعليمية تكميلية وليست تعريفات لسلوك App أو البروتوكول الحالي.
