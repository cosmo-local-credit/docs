تشكل شروط الخدمة هذه (**الشروط**) اتفاقًا ملزمًا بينك وبين Grassroots Economics Foundation (**GEF** أو **نحن** أو **لنا**) بشأن وصولك إلى تطبيق الويب التقدمي Cosmo-Local Credit المتاح على `cosmolocal.credit` واستخدامك له وللخدمات ذات الصلة التي تديرها GEF (ويشار إليها مجتمعةً باسم **التطبيق**).

تنطبق هذه الشروط على كل شخص أو مؤسسة تنشئ حسابًا أو تستخدمه، أو تحوز رمزًا أو قسيمة عبر التطبيق أو تستخدمهما، أو تنشئ صندوقًا أو تديره، أو تساهم بأصول في صندوق، أو تجري مبادلة. اقرأها بعناية قبل قبولها أو استخدام التطبيق.

## إشعارات مهمة

1. **يلتزم المستخدمون تجاه بعضهم بعضًا.** الجهة المصدرة مسؤولة عن التزامات قسيمتها، ومشرف الصندوق مسؤول عن قواعد الصندوق وعن أي ضمان يعلنه. ولا تضمن GEF أيًا منهما تلقائيًا.
2. **لا تضمن GEF القيمة أو استرداد الأموال أو السيولة أو الاسترداد.** قد يفقد رمز أو قسيمة أو صندوق أو أصل رقمي آخر قيمته، أو يصبح غير سائل أو غير قابل للاسترداد، أو لا يتوفر في ولاية قضائية معينة.
3. **تنطوي أنشطة سلسلة الكتل على مخاطر دائمة.** قد تكون المعاملات عامة أو غير قابلة للعكس أو معيبة تقنيًا أو متأخرة أو مرفوضة أو مفقودة. وقد لا تتمكن GEF من استعادة بيانات الاعتماد أو الأصول، أو عكس معاملة، أو إزالة سجل عام.
4. **لا يُعد أي إجراء حالي في التطبيق قرضًا تلقائيًا.** يتطلب أي قرض أو منتج ائتماني مستقبلي شروطًا تكميلية وشروط معاملة منفصلة. ولا تنشئ هذه الشروط قرضًا.
5. **أنت مسؤول عن المشروعية في ولايتك القضائية.** عليك تحديد ما إذا كان استخدامك أو رمزك أو قسيمتك أو صندوقك أو مبادلتك أو عرضك أو أي نشاط آخر قانونيًا، وما يلزم من تسجيلات وتراخيص وموافقات وإفصاحات وضرائب وضمانات.

تلخص هذه الإشعارات نقاطًا مهمة، لكنها لا تحل محل بقية الشروط.

## 1. التعريفات

في هذه الشروط:

- **الحساب** يعني ملف المستخدم والجلسة الموثقة والوصول إلى ميزات التطبيق ذات الصلة. وقد يرتبط الحساب ببيانات اعتماد محفظة واحدة أو أكثر وبعناوين عامة على سلسلة الكتل.
- **المحتوى** يعني المعلومات المقدمة أو المنشأة أو المنشورة عبر التطبيق، بما فيها الأسماء والصور والأوصاف والرسائل والمواقع ومعلومات الاتصال وشروط القسيمة وقواعد الصندوق ومعلومات العرض.
- **الإبراء** يعني السجل أو الإجراء الذي يمنع إعادة تقديم وحدات القسيمة التي تم الوفاء بها أو إعادة استخدامها، مثل استلامها أو حرقها أو إلغائها أو تعطيلها بطريقة أخرى وفق الشروط المعمول بها.
- **الوفاء** يعني أن تقدم الجهة المصدرة السلع أو الخدمات أو المنافع أو الأداء أو القيمة الأخرى التي تعد بها شروط القسيمة.
- **الحامل** يعني الشخص أو المؤسسة التي تتحكم قانونيًا في رمز أو قسيمة. ولا يثبت التحكم بمفرده الملكية النفعية أو وفاء الجهة المصدرة أو القيمة النقدية أو وجود ضمان.
- **الجهة المصدرة** تعني الشخص أو المؤسسة التي تنشئ رمزًا أو قسيمة أو تصدرهما أو تمثل نفسها بوصفها مسؤولة عنهما وعن الالتزامات المرتبطة بهما.
- **العرض (Offering)** يعني سجلًا في كتالوج التطبيق يصف السلع أو الخدمات المرتبطة بقسيمة. ولا يؤدي نشر العرض إلى سك رمز أو إثبات التوفر أو إثبات وقوع الوفاء.
- **الصندوق** يعني ترتيبًا لعقود ذكية أو نظامًا منسقًا آخر ينسق الرموز أو القسائم، أو يحتفظ بمخزون من الأصول الرقمية أو يسجله، أو يطبق التقييمات أو الحدود أو الرسوم، ويتيح المبادلات أو معاملات أخرى.
- **المساهمة في الصندوق** تعني نقل أصول إلى صندوق وفق شروط مفصلة بصورة منفصلة. ولا تنشئ تلقائيًا حصة في الصندوق أو مطالبة بالسداد أو حق سحب أو مكافأة أو حق حوكمة.
- **رسم الصندوق** يعني رسمًا يُحصّل وفق قواعد الصندوق وإعداداته المنشورة.
- **عرض سعر الصندوق** يعني تقديرًا للمعاملة تنتجه طريقة التقييم المضبوطة للصندوق. ولا يطابق تلقائيًا سعر العرض أو القيمة المعلنة للقسيمة أو قيمة الاسترداد أو القيمة النقدية.
- **رسم البروتوكول** يعني رسمًا منفصلًا، إذا كان مضبوطًا، يُدفع إلى مستلم رسوم البروتوكول المعلن بالإضافة إلى رسم الصندوق.
- **مشرف الصندوق** يعني الشخص أو المؤسسة أو المجموعة أو هيئة الحوكمة أو المتحكم المفوض المسؤول عن إنشاء قواعد صندوق أو إدارتها أو نشرها.
- **المتحكم التقني** يعني مالك عقد أو مدير وكيل أو مالك مكوّن تابع أو كاتبًا أو مشرف كتالوج أو مستلم رسوم أو شخصًا آخر لديه سلطة تقنية معلنة. ولا ينقل التحكم التقني بمفرده جميع مسؤوليات الجهة المصدرة أو المشرف.
- **المبادلة** تعني استبدال أصل مدعوم بآخر من خلال صندوق واحد أو أكثر. ولا تُعد المساهمة في الصندوق أو الإيداع فيه أو سحب سيولته أو تحصيل الرسوم أو معاملة مقدم خدمة أو إدخال النقد أو إخراجه مبادلةً، إلا إذا شملت أيضًا استبدال أصول.
- **الرمز الرقمي** يعني رمزًا أو سجلًا أو رصيدًا أو أصلًا رقميًا آخر يمكن الوصول إليه عبر التطبيق. وليس كل رمز قسيمة، وتعتمد طبيعته القانونية على خصائصه وما يمثله وكيفية استخدامه والقانون المعمول به.
- **شروط المعاملة** تعني المعايير والقواعد المحددة المقدمة لمعاملة أو المتاحة لها، مثل الأصول والمبالغ والصندوق والمسار وطريقة سعر الصرف والرسوم والحدود والموعد النهائي وشروط مقدم الخدمة أو شروط الاسترداد.
- **تقديم القسيمة للاسترداد** يعني أن يعيد الحامل وحدات القسيمة إلى الجهة المصدرة أو يعرضها عليها من خلال عملية الاسترداد المعلنة. ولا يثبت التقديم بمفرده وقوع الوفاء أو الإبراء.
- **رسم الخدمة** يعني رسمًا يُفصح عنه بصورة منفصلة مقابل خدمة توجيه أو واجهة أو مقدم خدمة أو دفع أو مراقبة أو خدمة أخرى محددة.
- **المستخدم** أو **أنت** يعني الفرد الذي يقبل هذه الشروط، وأي مؤسسة يمثلها الفرد تمثيلًا صحيحًا.
- **القسيمة** تعني رمزًا أو سجلًا تمثله الجهة المصدرة بوصفه التزامًا أو مطالبة مدفوعة مسبقًا أو حقًا في سلع أو خدمات أو منافع أو أداء أو قيمة أخرى محددة وفق شروط استرداد منشورة.
- **المحفظة** تعني حسابًا أو عنوانًا على سلسلة الكتل، أو بيانات اعتماد للتوقيع، أو مفتاح مرور، أو مفتاح محفظة ورقية، أو حسابًا ذكيًا، أو آلية ذات صلة تُستخدم للتصريح بالمعاملات.

## 2. القبول ونطاق التطبيق

لا يسجل التطبيق الحالي قبول إيجابي لهذه الشروط أثناء إنشاء الحساب. في الحد الذي يسمح به القانون المعمول به، تقبل هذه الشروط من خلال إنشاء حساب أو استخدامها أو من خلال الاستمرار في استخدام التطبيق بعد حدوث تحديث مطلع. عندما يتطلب القانون المعمول به قبول إيجابي أو إعادة قبول، سيقدم GEF مراقبة قبول قبل السماح باستمرار استخدام ميزات الحساب المتضررة. ببساطة مشاهدة هذه الشروط دون إنشاء أو استخدام حساب لا يخلق اتفاق في حد ذاته.

إذا لم توافق، لا تخلق حسابًا أو لا تستخدم التطبيق. إذا كنت تقبل لمنظمة، فإنك تمثل أن لديك سلطة لربطها. في هذه الحالة، **أنتِ** يتضمن كل منكما والمنظمة حيث يسمح السياق.

هذه الشروط تحكم العلاقة بينك وبين GEF فيما يتعلق بالتطبيق. قواعد المجموعة، وشروط البطاقة، وشروط المعاملة قد تخلق التزامات منفصلة بين المستخدمين. تُكمل هذه الشروط لعملية المستخدم إلى المستخدم ذات الصلة، لكنها لا تجعل GEF طرفاً في تلك المعاملة، وتتنازل عن الحماية المستحقة لـ GEF، أو تفكيك القانون الإلزامي. إذا كانت شروط المعاملة تتعارض مع هذه الشروط، فإن شروط المعاملة تتحكم فقط في المعاملة المحددة بين المستخدمين، وتستمر هذه الشروط في حكم استخدامك للتطبيق والعلاقة مع GEF.

لا تغير نسخة لاحقة من هذه الشروط بشكل رجعي المعاملة المكتملة أو الاقتصاد المتفق عليه من المعاملة التي تم تأكيدها بالفعل.

## 3. الأهلية والسلطة

يمكنك استخدام التطبيق فقط إذا:

- أن يكون عمرك 18 عامًا على الأقل وقد بلغ سن الأغلبية القانونية في كل ولاية قضائية تطبق عليك.
- لديك القدرة القانونية لإبرام العقود وتنفيذ الالتزامات التي تتعهد بها.
- لا يحظر عليك استخدام التطبيق بموجب عقوبات أو أوامر محكمة أو قيود تنظيمية أو أي قانون آخر ينطبق.
- المعلومات التي تقدمها صحيحة وحديثة ومكتملة. و
- إذا كنت تعمل لصالح شخص أو منظمة أخرى، لديك سلطة مستمرة للقيام بذلك.

يجب أن تتوقف عن استخدام التطبيق إذا توقفت عن الوفاء بهذه الشروط. قد تطلب GEF المعلومات اللازمة بشكل معقول للتحقق من الأهلية أو السلطة أو الهوية أو المخاطر أو الامتثال وقد تقيد الميزات التي تكون التحقق غير كاملة.

## 4. الحسابات والأموال والأمن

أنت مسؤول عن حسابك والمحفظة والأجهزة ومفاتيح المرور ومواد المحفظة الورقية والمفاتيح الخاصة ومعلومات الاسترداد وجميع الأنشطة المسموح بها من خلالها. يجب عليك استخدام أمن معقول، وحماية الإثباتات من الإفصاح، والحفاظ على أي نسخ احتياطية تحتاج إليها، وإبلاغ GEF على `info@grassecon.org` على الفور إذا كنت تشك في الوصول غير المصرح به إلى الحساب أو إساءة استخدام خدمة تديرها التطبيق.

يمكن أن يساعد التطبيق على إنشاء محفظة أو ربطها، وتسجيل مفتاح المرور، وإعداد المعاملة، والحصول على توقيع أو تصريح، وتقديم المعاملة من خلال مزود إعادة أو شبكة. هذه الوظائف لا تتخلص من مسؤوليتك عن الموافقة التي تعطيها. يجب أن تفحص تفاصيل المعاملة قبل تأكيدها

GEF لا يعد بأن يمكن استعادة أو استبدال أو تجميد أو إلغاء أو عكس بطاقة الاعتماد أو محفظة أو رمز أو قسيمة أو معاملة ضائعة. يمكن التعامل مع معاملة المحفظة المعتمدة بشكل صحيح مع أوراق الاعتماد الخاصة بك كإرشادك ما لم يثبت القانون المعمول به أو الأدلة الموثوقة خلاف ذلك. سجل بلوكتشين هو دليل ذي صلة، لكنه ليس بالضرورة حاسم في حالات الاحتيال أو التنازل أو خطأ النظام أو النظام القانوني الملزم.

حسابك شخصي لك ولا يجوز بيعه أو تحويله أو استئجاره أو مشاركته بطريقة تشير بشكل خاطئ إلى من يسيطر عليه. لا يؤدي انسحاب التطبيق أو إزالة تثبيته أو إغلاق ملف تعريف التطبيق إلى إلغاء المعاملات البلوكشينية المكتملة أو إزالة السجلات العامة أو العقود الذكية أو الرصيد أو الالتزامات تجاه المستخدمين الآخرين تلقائيًا.

## 5. دور و قيود GEF

تشغيل GEF واجهة التطبيق ويمكن أن تشغيل خدمات دعم الكتالوجات، واجهات برمجة التطبيقات، والتخزين، والترسلات، والتصفية، والإشعارات، والاعتدال، وتقديم المعاملات. قد تساعد GEF المستخدمين أيضًا على اكتشاف الرموز والتسجيلات والحوافز وغيرها من المستخدمين.

ما لم تُعرف GEF صراحةً كتابياً بأنها تتصرف بصفة أخرى في معاملة معينة، فإن GEF ليست:

- إصدار رمزا أو قسيمة تم إنشاؤها من قبل المستخدم.
- مشرف صندوق خلقها المستخدم
- طرف في عملية تبادل أو غيرها من المعاملات بين المستخدمين؛
- المقرض، المقترض، الوسيط، التاجر، البورصة، البنك، جهاز إرسال الأموال، المؤمن، الوفيد، مدير الاستثمار، وكيل الاحتفاظ أو المستشار المالي؛
- البائع أو المنتج أو المفتش أو الناقل أو المخلص من السلع أو الخدمات الأساسية؛ أو
- ضامن لأي مستخدم أو رمز أو قسيمة أو مجموعة أو معاملة أو التزام أو احتياط أو ضمان أو سعر أو نتيجة.

قد يحتوي العقد الذكي على الأصول الرقمية بموجب قواعدها المبرمجة. هذه الحقيقة لا تعني بذاتها أن GEF تمتلك هذه الأصول أو تدين قيمتها أو يمكنها استعادتها. وبالمثل، يجوز لجهة إعادة نشر أن تنشر المعاملة المسموح بها دون أن تصبح مالكاً أو حارس الأصول المعنية.

الإدراج أو العرض أو الترتيب أو المراجعة أو التحقق منها أو رفض إزالة حساب أو رمز أو قسيمة أو مجموعة أو عنصر المحتوى أو المعاملة لا يشكل تأييد GEF أو شهادة أو تقييم أو تصنيف قانوني أو وعد بالجودة. إذا كانت GEF تعمل صراحة كمنشئ أو وكيل أو طرف مقابل، فهي تخضع لنفس الالتزامات القابلة للتطبيق التي تضعها هذه الشروط على المستخدمين الآخرين في هذا الدور.

## 6. مسؤوليتك القانونية والتنظيمية

يمكن الوصول إلى التطبيق في العديد من الولايات القضائية مع قواعد مختلفة. أنت الوحيد المسؤول عن الحصول على المشورة المختصة وتحديد القوانين التي تنطبق على نشاطك، بما في ذلك القوانين المتعلقة بحماية المستهلكين، والائتمان، والقروض، والمدفوعات، ونقل الأموال، والخدمات المصرفية، والمال الإلكتروني، والأصول الرقمية، والأوراق المالية، والسلع، وجمع الأموال، والجمعيات الخيرية، والتوظيف، والأجور، والضرائب، والعقوبات، والتحكم في مكافحة غسيل الأموال، وأمان المنتجات، والتجارة، والخصوصية، والملكية الفكرية، والتراث الثقافي، والمعاملات الإلكترونية.

لا تمثل GEF أن أي رمز أو قسيمة أو مجموعة أو تبادل أو مساهمة مجموعة أو منتج ائتماني مستقبلي أو ترتيب آخر لديه تصنيف قانوني أو محاسبي أو تنظيمي أو ضريبي معين. لا تتداخل العلامات التي يستخدمها المستخدم أو داخل التطبيق مع القانون المعمول به.

يجب أن تحصل على جميع التسجيلات والإذن والموافقة والإفصاح والإذن والتسجيل والحماية اللازمة لأنشطتك يجب ألا تستخدم هذه الشروط أو توافر ميزة التطبيق كدليل على أن GEF أو أي سلطة قد وافقت على نشاطك.

يجوز لـ GEF تقييد أو توقف أو إيقاف أو إيقاف أو إيقاف أو رفض الوصول إلى حساب أو أصول أو مسار أو ميزة لمعالجة المخاطر القانونية أو التنظيمية أو العقوبات أو الاحتيال أو السلامة أو التشغيل. هذا القسم لا ينقل إليك أي واجب قانوني يضعه القانون المعمول به مباشرة على GEF.

## 7. الرموز والبطاقات بشكل عام

## 9. تقديم القسيمة للاسترداد وتحقيقها وإفراجها

في التطبيق الحالي، علامة UI **«استرداد»** يقوم بإعداد نقل رمز عادي إلى مالك الرمز كقائمة استرداد. هذا التحويل لا يثبت في حد ذاته الإنجاز أو الإبراء.

الجهة المصدرة، وليس GEF، هو المسؤول عن تلبية بطاقة البطاقة الخاصة به وفقاً للشروط المنشورة عند اكتسابها من صاحب البطاقة وأي اتفاق آخر صالح. مع مراعاة الشروط القانونية المعلنة، يجب على الجهة المصدرة:

- تقبل بطاقة قسيمة تم تقديمها بشكل صحيح للسلع أو الخدمات أو الفوائد أو الأداء أو القيمة الأخرى المذكورة؛
- توفير الجودة والكمية الموعودة خلال الفترة المحددة؛
- عدم رفض أو تأخير غير معقول أو تطبيق خصم غير مطلع ببساطة لأن البطاقة قد تم نقلها أو تم نقلها من خلال مجموعة؛
- توفير عملية عملية عملية لتقديم الشكاوى والتحقق منها وتسليمها وإصلاحها؛ و
- سجل الإكمال الإكمال والإبراء عن طريق استقبال أو حرق أو إلغاء أو تعطيل وحدات البوتر المكتملة بطريقة أخرى عند الضرورة لمنع إعادة الاستخدام.

لا يجوز للمصدر تطبيق قيود بناء على القانونية أو السلامة أو الموقع أو القدرة أو الجدول أو انتهاء الصلاحية أو الهوية أو غيرها من الشروط إلا إذا كانت مشروعة وتم الكشف عنها بوضوح قبل الاستحواذ، إلا إذا كان القانون يتطلب قيوداً لاحقاً أو ضرورياً لمنع الأضرار المقبلة.

يجب على صاحب البطاقة قراءة شروط البطاقة، وتقييم الجهة المصدرة والعرض، واتباع عملية الاسترداد المنصوص عليها، وتقديم دليل قانوني على السيطرة، وتفتيش السلع أو الخدمات التي تم تسليمها عند الاقتضاء، وتجنب تقديم البطاقة نفسها أكثر من مرة. الحصول على قسيمة لا يجعل GEF مسؤولا عن أداء الجهة المصدرة.

إذا قام المستلم بتعديل أو إعادة تعبئة أو إعادة توزيع عرض عندما تسمح شروط الجهة المصدرة بذلك، يجب على هذا المستلم تحديد التغييرات الأساسية بدقة، والحفاظ على الإقرارات المطلوبة بالمنشأ والجهة المصدرة، وإرسال الشروط المعمول بها، وتجنب الإشارة إلى أن الجهة المصدرة الأصلي أو GEF قد وافق على العرض المعدل.

علامة التطبيق **«سحب القسيمة من التداول»** يعني إزالة الكتالوج العكسي من القائمة. فإنه لا يحرق أو يلغي الأرصدة، أو يكمل الوفاء أو الإبراء، أو يلغي التزامات الجهة المصدرة المعلقة.

يمكن أن يكون المدير، ومالك المجموعة، ومدير وكيل، ومراقبي الاعتماد، ومدير الكتالوج، ومستفيدون من الرسوم أطراف مختلفة. يجب على الكشف عن المجموعة أن يحدد كل سلطة مهمة. إن سلطة المراقب الفني لا تجعل ذلك الطرف في حد ذاته المدير أو تنقل التزامات المدير.

## 11. استخدام صندوق أو المساهمة فيه

قبل استخدام أو المساهمة في مجموعة، يجب عليك تقييم المدير، القواعد، العقود، الأصول المقبولة، التقييمات، الرسوم، الحدود، المخزون، الاحتياطيات، الحوكمة، صلاحيات الترقية، الضمانات، والحالة القانونية. أنت تقبل المخاطر التي:

- يمكن للمصدر رفض تقديم الرداد المفعول أو عدم تقديم الوفاء.
- قد يفشل المدير أو المدير أو الوسيط أو الضامن أو أي شخص آخر يعتمد عليه أو يتصرف بشكل غير لائق.
- قد تتغير الأسعار والقيم المرجعية والرسوم والحدود والطرق أو التوافر في المستقبل إذا سمحت القواعد الحاكمة بذلك.
- قد تصبح الإعداد غير قابلة للتغيير أو قد تظل قابلة للتغيير من قبل المدير.
- قد تكون الاحتياطيات أو المخزونات غير كافية.
- قد يتوقف الصندوق أو المسار، أو يرفض، أو يعود، أو يصبح غير متاح، أو يتوقف عن العمل. و
- قد يحتوي العقد الذكي على عيوب أو يتصرف بشكل غير متوقع.

تكون المساهمة هبة أو منحة غير قابلة للرجوع، ولا تمنح أي حق في الملكية أو الربح أو الفائدة أو الحوكمة أو السداد أو السحب، فقط عندما تُعرض وتُقبل صراحةً على هذا الأساس. وفي غير ذلك، تُحدَّد حقوق المساهم وفقًا لشروط الصندوق والمعاملة المُعلنة والقانون المعمول به.

## 12. التبادلات، والعروض، والرسوم، والتوجيه

الاقتباس هو تقدير يعتمد على الشروط في وقت معين، وليس ضمان التنفيذ أو القيمة المستقبلية. قبل تأكيد التبادل، يجب عليك مراجعة الأصول، والكميات، ومجموعة أو الطريق، وتقييم، والرسوم، والحدود، والإجراءات أو الموعد النهائي، وغيرها من شروط المعاملة المتاحة لك.

من خلال تأكيد التبادل والإذن بمعاملة المحفظة ذات الصلة، تقوم بتوجيه العقود والمقدميين للخدمات المعنيين لمحاولة المعاملة على تلك المعايير. قد يحتاج الاقتباس لتجديد. يمكن أن تفشل عملية التبادل أو تتراجع أو تنتهي صلاحيتها أو تنفيذها بعد تأخير أو تصبح غير متوفرة بسبب المخزون أو الحدود أو حركة الأسعار أو الرسوم أو ظروف الشبكة أو حالة العقد أو التوجيه أو الإذن أو القيود القانونية.

قد يتفاعل التبادل المتوجه مع مجموعة متعددة من المجموعات أو العقود أو المقدمين. كل مكون إضافي يقدم قواعد وخطراته الخاصة. لا يعد GEF عن توافر أو أفضل سعر أو دقة أو استكمال أو تعديل أو طبيعة قانونية للاستبدال.

إن اتجاه الأصول لا يحدد بذاته الطابع القانوني للمعاملة. على سبيل المثال، فإن الحصول على عملة ثابتة مقابل قسيمة لا يشكل تلقائيًا قرضًا، كما أن تسليم عملة ثابتة مقابل قسيمة لا يشكل سداد تلقائيًا. شروط المعاملة الصريحة، قواعد المجموعة، سلوك الأطراف، ومراقبة القانون المعمول بها.

## 13. منتجات الائتمان أو القروض المستقبلية

شروط التطبيق الحالية لا تخلق أو تحكم منتج القرض. الإرسال العادي، مساهمة المجموعة، إيداع المجموعة، تبادل المجموعة، سحب السيولة المجموعة، تحصيل الرسوم، معاملة المزود، تقديم القسيمة للاسترداد، الوفاء، أو الإبراء ليس تلقائيًا قرضًا أو تقدمًا أو استردادًا أو فائدة ضمانة أو سهولة ائتمان.

يجب أن يتم تحديد أي قرض مستقبلي أو تقدم قابل للسداد أو معاملة مضمونة أو منتج ائتماني آخر بشكل منفصل قبل دخول المستخدم إليه ويجب أن يحكمها شروط إضافية ومشروط محددة للمعاملة. يجب على هذه الشروط تحديد الأطراف وجميع الخصائص الأساسية التي يتطلبها القانون المعمول بها، بما في ذلك المبالغ والمواعيد المحددة، والرسوم أو الفائدة، ومعاملة الضمانات، والتمويل، والعجز، والإصلاحات، والإفصاحات، والموافقة، ودليل على السداد أو الإبراء. لا يتم تقديم هذا المنتج ببساطة لأن هذا القسم يصف هذا الشرط.

## 14. الرسوم والضرائب وخدمات الدفع من طرف ثالث

أنت مسؤول عن مراجعة وتسديد الرسوم والرسوم المعلنة عن خدمة التطبيقات أو المجموعة أو المعاملة أو الشبكة أو الجهة التنسيقية أو مقدم الطرف الثالث. يمكن خصم الرسوم من المبالغ المنقولة أو دفعها بشكل منفصل حسب الإفصاح. المعاملة المكتملة أو المقدمة بطريقة لا رجعة فيها غير قابلة للرد ما لم يقتضي الشروط أو القانون المعمول بها خلاف ذلك.

رسوم المجموعة، رسوم البروتوكول، رسوم الخدمة، رسوم شبكة بلوكتشين، ورسوم مزود طرف ثالث مختلفة. قبل الإذن، يجب على الطرف المسؤول الكشف عن نوع الرسوم، وأساس الحساب، والمبلغ أو المعدل، المدفوع، المستلم، والوقت، معالجة الإسترداد، والشروط المادية. قد تكون رسوم البروتوكول الحالية إضافية إلى رسوم المجموعة. هذا ليس النموذج المقترح للشبكة المكشوفة في الورقة البيضاء.

أنت الوحيد المسؤول عن تحديد وتقديم التقارير والاحتفاظ بها وجمع ودفع الضرائب والرسوم والرسوم والتقييمات الناتجة عن نشاطك. GEF لا يحسب أو يدفع ضرائبك ولا يوفر المشورة الضريبية.

يسمح التطبيق بتوفير خدمات تديرها أطراف ثالثة للعملات المستقرة أو المدفوعات النقدية أو الدفعات الداخلية أو الخارجية أو التحقق من الهوية أو الاتصالات أو الخرائط أو التخزين أو وظائف أخرى. قد يفرض هؤلاء المقدمون شروطًا منفصلة وقواعد الأهلية والرسوم وممارسات البيانات. ما لم ينص صراحة، فإن GEF لا تحتفظ بالبيانات النقدية، أو تشغيل خطوط الدفع من طرف ثالث، أو تضمن تحويل أو دفع أو سعر صرف أو مزود أو نتيجة تنظيمية.

## 15. السلوك المحظور

لا يجوز لك استخدام التطبيق أو الحساب أو الرمز أو الجائزة أو الجدول أو التبادل أو المحتوى أو الخدمة ذات الصلة:

- انتهاك القانون أو العقوبات أو أمر محاكم أو حقوق شخص آخر؛
- ارتكاب الاحتيال، والسرقة، والرشوة، والفساد، وغسل الأموال، وتمويل الإرهاب، والهروب من الضرائب، أو جمع الأموال الخاطئة؛
- إنشاء أو استخدام أصول أو مطالبات مزيفة أو غير مصرح بها أو مدعومة بالكذب أو تضاعف الالتزامات؛
- تقديم بيانات خاطئة عن الهوية والسلطة والمالكية والمصدر، والإمدادات، والقيمة، والتكييف، والاحتياطيات، والسيولة، والضمانات، والنشاط، أو الغرض من المعاملة؛
- التلاعب بالأسعار والحجم والتصنيفات والطرق والحوكمة أو القياسات الأخرى؛
- تقديم أو تسهيل أسلحة غير مشروعة أو المخدرات أو الاتجار بها أو الاستغلال بها أو الخدمات الجنسية أو المواد الصريحة أو السلع المراقبة أو المنتجات غير الآمنة؛
- يتجنب المستهلك، المقترض، الأجور، العمل، الخيريات، الخدمات المالية، أو التزامات حماية البيانات؛
- التمثيل أو التحرش أو التهديد أو التمييز أو الاستغلال أو الكشف عن المعلومات الخاصة لشخص آخر؛
- انتهاك الملكية الفكرية أو الخصوصية أو الدعاية والسرية أو التراث الثقافي أو المعرفة التقليدية أو حقوق المجتمع؛
- إدخال البرامج الخبيثة، سرقة إثباتات الإعتماد، استكشاف أو تجاوز الأمن، تعطيل البنية التحتية، زيادة عبء الخدمة، إزالة دون إذن، أو التدخل في مستخدم آخر؛
- الرسائل غير المرغوب فيها أو إرسال عروض ترويجية غير مرغوب فيها أو استخدام معلومات الاتصال لأغراض غير معروفة.
- تخفي تضارب مادي للمصالح أو إساءة استخدام المعلومات غير العامة. أو
- مساعدة شخص آخر على القيام بأي من المواضيع المذكورة أعلاه

يجوز لـ GEF التحقيق في الانتهاكات المشتبه فيها، والحفاظ على السجلات ذات الصلة، وتقييد الميزات، والتعاون مع الطلبات القانونية من السلطات. لا يتطلب GEF أن تقرر كل ادعاء من مستخدم إلى مستخدم ويمكن أن تتخذ إجراءات وقائية متناسبة أثناء تقييم المخاطر.

## 16. المحتوى والإعلانات العامة

تحافظ على أي حقوق تملكها في المحتوى الخاص بك. بالنسبة للمحتوى الذي تقدمه عمدا للعرض العام أو النشر، فإنك تسمح لـ GEF، ومقاوليها، ومقدمي الخدمات بتضخيمها، وتخزينها، وإعادة إنتاجها، وتصميمها، وتحويلها، وإظهارها، وإرسالها، وتوزيعها في جميع أنحاء العالم دون رسوم رسمية، فقط حسب الضرورة المعقولة لتشغيل التطبيق، والأمان، وتحسينه، وتفسيره، وعلى عرض أو تعزيز العرض أو الإعلان العام الذي قدمته. تستمر هذه الإذن في السجلات العامة وأدلة المعاملات والنسخ الاحتياطية المعقولة والمادة التي تم مشاركتها بالفعل مع الآخرين، حتى بعد إزالة المحتوى أو إغلاق الحساب.

لا ينطبق هذا الإذن على المحتوى العام على معلومات الحساب الخاص، والدعم، والشكوى، والأمن، أو الامتثال. لا يجوز لـ GEF معالجة هذه المعلومات إلا كما هو موضح في القسم 17 والقانون المعمول به. ستحصل GEF على أي إذن منفصل مطلوب بموجب القانون قبل استخدام المحتوى المحدد للإعلان عن GEF خارج عرض أو تعزيز الإعلان العام الذي قدمته له.

أنت تقترح أن لديك سلطة لتقديم المحتوى وتمنح هذه الموافقة. يجب أن تحترم الخصوصية وتحصل على أي موافقة مطلوبة قبل نشر معلومات شخص آخر أو صورة أو موقع أو تفاصيل الاتصال أو المعرفة التقليدية أو معلومات المجتمع.

يجوز لـ GEF تحرير تنسيق المحتوى، ترجمة المحتوى، إضافة إشعارات المخاطر، تقييد الرؤية، أو إزالة المحتوى الذي ينتهك هذه الشروط أو يخلق مخاطر قانونية أو أمنية أو احتيالية أو تقنية أو سمعة. لا تتحمل GEF مسؤولية النسخ المحتفظ بها من قبل مستخدمين آخرين أو شبكات عامة أو أرشيفات أو أطراف ثالثة.

يظل التطبيق وتصميمه وعلامته التجارية والمواد التي تم إنشاؤها GEF- ملكة GEF أو المالك المعني. الوصول إلى التطبيق لا ينقل ملكيتها أو يسمح باستخدام اسم GEF أو العلامات التجارية للتعريف.

## 17. البيانات والسجلات الإلكترونية

بالنسبة للبيانات الشخصية خارج السلسلة التي تحدد GEF أغراضها ووسائلها، تعمل GEF كمدير معالجة البيانات أو منظمة مسؤولة معادلة بموجب القانون المعمول به. قد تقوم GEF بمعالجة المعلومات اللازمة بشكل معقول لتشغيل التطبيق والأمان والدعم والامتثال للقانون فيما يتعلق به. اعتمادا على الميزات التي تستخدمها، قد تشمل ذلك:

- الهوية، والاتصال، والملف الشخصي، والموقع، والعملة المفضلة، ومعلومات الصورة التي تم تحميلها؛
- عناوين المحفظة، واحتفاظ بالتوكينات، وتاريخ المعاملات، والتوقيعات، والإذن، وسجلات بلوكتشين العامة؛
- معلومات عن الجهاز والمتصفح والجلسة والأمن والإخطار والدعم واستخدام الخدمات. و
- المحتوى، شروط الجائزة، قواعد المجموعة، معايير المعاملات، الشكاوى، وسجلات الامتثال.

يمكن لـ GEF معالجة هذه المعلومات لإنشاء وإدارة الحسابات وتوفير الميزات المطلوبة وتقديم وتصفية المعاملات وعرض الإعلانات العامة والتواصل معك ومنع الإساءة، وتأمين الأنظمة، والحفاظ على السجلات، وحل النزاعات، وتحسين التطبيق، وتلبية الالتزامات القانونية. اعتماداً على السياق والقانون المعمول به، قد تكون المعالجة ضرورية لتنفيذ هذا الاتفاق، أو الامتثال للقانون، أو حماية المصالح المشروعة، أو إقامة أو الدفاع عن المطالبات القانونية، أو حماية المصالح الحيوية، أو التصرف بناء على موافقة منفصلة.

المعلومات المعلنة حسبما هو مطلوب أثناء إنشاء الحساب أو المعاملة ضرورية لتوفير هذا الحساب أو الميزة أو تلبية الالتزام القانوني أو إدارة المخاطر المهمة. إذا لم تقدمها، قد لا تتمكن GEF من إنشاء الحساب أو توفير الميزة. الحقول الاختيارية للملف الشخصي، والوصول إلى الموقع، والإشعارات، وغيرها من الوظائف الاختيارية المماثلة ليست مطلوبة للاستخدام العام للحساب ويمكن رفضها أو تعطيلها، مع مراعاة الحدود التقنية للمعاملة أو الميزة المطلوبة بالفعل.

قبول هذه الشروط ليس موافقة شاملة على معالجة البيانات الاختيارية. عندما يتطلب القانون موافقة محددة، ستطلب GEF ذلك بشكل منفصل وتقدم أي خيار مطلوب.

يجوز لـ GEF مشاركة المعلومات مع المقاولين والمقدمين الذين يدعمون الاستضافة والتخزين والاتصالات والخرائط والتصديق والإرسال والوصول إلى بلوكتشين والأمن والدعم والامتثال والاستشارات المهنية. مع المستخدمين الآخرين عند نشر أو إجراء المعاملات؛ ومع السلطات أو الأطراف الأخرى عندما يكون ذلك مطلوبًا أو ضروريًا قانوناً لحماية الحقوق والسلامة. قد يعمل المقدمون والشبكات العامة في بلدان أخرى، وبالتالي يمكن معالجة المعلومات عبر الحدود مع مراعاة الضمانات المعمول بها.

قد يعرض نشاط بلوكتشين عام عنوان محفظة، والأصول، والكميات، والخوابات الزمنية، وبيانات المعاملات، والبيانات الأساسية ذات الصلة في جميع أنحاء العالم. قد يتم نسخها، وتصفيتها، وتجمعها مع معلومات أخرى، ومن المستحيل عملياً لـ GEF حذفها أو تصحيحها. لا تضع معلومات شخصية خاصة أو حساسة أو غير ضرورية في بيانات المعاملات أو البيانات المعدنية العامة.

تحتفظ GEF بالمعلومات طالما كان ذلك مطلوبًا معقولًا للأغراض المذكورة أعلاه، بما في ذلك الأمن ومنع الاحتيال وأدلة المعاملات والواجبات القانونية والفترات القصوى والنسخ الاحتياطية وحل النزاعات. الاحتفاظ لا يجعل GEF قادرة على حذف المعلومات التي تحتفظ بها شبكة عامة أو طرف ثالث.

مع مراعاة القانون المعمول به، يمكنك طلب الوصول، والتصحيح، والحذف، والقيود، والاعتراض، والنقل، أو غيرها من حقوق البيانات المتاحة عن طريق الاتصال بـ `info@grassecon.org`. GEF تستخدم ضمانات معقولة ولكن لا يمكن أن تعد الأمن المطلق أو السرية، وخاصة للأنشطة العامة بلوكتشين والمعلومات التي تنشرها.

## 18. تغييرات الخدمة وإيقافها وإنهاءها

يجوز لـ GEF إضافة أو تغيير أو إيقاف أو تقييد أو إيقاف ميزات التطبيق أو الشبكات المدعومة أو الأصول أو الكتالوجات أو الطرق أو الرسوم أو المتطلبات التقنية أو الأهلية. ستقدم GEF إشعارًا معقولًا حيثما كان ذلك ممكناً، ولكن يمكن أن تتخذ إجراءات فورية لمعالجة القانون أو العقوبات أو الاحتيال أو الأمن أو الأمن أو فشل الشبكة أو الاعتماد على أطراف ثالثة أو الضرر المحتمل.

يجوز لـ GEF تحذير أو تحديد أو الحد أو حذف القائمة أو تعليق أو إنهاء حساب أو عنصر المحتوى أو رمز أو قسيمة أو مجموعة أو طريق أو خدمة تديرها التطبيق إذا كان لـ GEF اعتقادًا معقولًا بأن:

- يتم انتهاك هذه الشروط أو القواعد المعمول بها أو القانون؛
- المعلومات غير صحيحة أو غير كاملة أو غير آمنة أو مضللة بشكل مادي.
- لم يتم الوفاء بالالتزام أو الاسترداد أو الضمان أو الرسوم؛
- يتم تعرض حساب أو شهادة اعتماد للخطر؛
- إن الاستمرار في الوصول يخلق مخاطر قانونية أو تنظيمية أو أمنية أو احتيالية أو تقنية أو مجتمعية أو سمعة؛ أو
- تتطلب السلطة أو مقدم الخدمات اتخاذ إجراءات.

عندما يكون ذلك مناسبًا وشرعيًا، يجوز لـGEF تقديم إشعار أو فرصة لتصحيح انتهاك أو طريقة لطلب مراجعة. قد تحدث إجراءات طارئة دون إشعار مسبق.

يمكنك التوقف عن استخدام التطبيق في أي وقت ويمكنك طلب إغلاق البيانات أو الوصول التي تسيطر عليها GEF. لا يؤدي الإيقاف أو إزالة القائمة أو إنهاء أو إغلاق المعاملات المكتملة أو إزالة سجلات بلوكتشين العامة أو إعادة الأصول تلقائيًا أو إلغاء الالتزامات تجاه الجهات المصدرة أو الاحتماليين أو المجمعات أو المراقبين أو المقترضين أو المستخدمين الآخرين.

## 19. المخاطر لا توجد نصيحة مهنية

أنت تفهم وتقبل خطر الخسارة الناتجة عن:

- فقدان الوثائق، التفتيش، السرقة، الوصول غير المصرح به، فشل الجهاز، أو خطأ المستخدم.
- أخطاء البرمجيات، والرمز الخبيث، والضعف في العقود الذكية، والترقية، والسلطات الإدارية، أو الإعدادات التي لا تتغير؛
- إزدحام الشبكة وإعادة تنظيم السلسلة والشواذ والانقطاعات والروابط الفاشلة والجسور والعقود والمؤشرات أو البنية التحتية الأخرى؛
- الإقتباسات غير الدقيقة، وفشل الأوراقل، تغييرات في التقييمات، التقلبات، التخفيضات، عدم كفاية المخزون، الانزلاق، الرسوم، أو عدم السيولة؛
- عدم الوفاء بالجهة المصدرة، وعدم الاسترداد، سوء الجودة، تأخير التسليم، سوء سلوك المدير، عدم كفاية الاحتياطيات، أو فشل الضمانات.
- تغيير القانون أو التنفيذ أو الضرائب أو العقوبات أو الجغرافيا أو التصنيف القانوني؛ و
- الفشل أو الإفلاس أو الإيقاف أو سوء السلوك من طرف ثالث.

المعلومات الموجودة في التطبيق هي معلومات عامة، وليس مشورة قانونية أو ضريبية أو محاسبية أو مالية أو استثمارية أو ائتمانية أو تأمينية أو مشورة مهنية أخرى. يجب أن تقوم بتقييمك بنفسك والحصول على نصيحة مؤهلة عند الاقتضاء.

## 20. الضمانات والاستبعاد من المسؤولية

لا تستبعد GEF أي ضمان أو رسوم أو تعويضات لا يسمح لها القانون المعمول به بإستبعادها. مع مراعاة هذه القاعدة وحتى الحد الأقصى الذي يسمح به القانون، يتم توفير التطبيق على أساس المتاحة. لا تضمن GEF أن التطبيق أو أي محتوى أو رمز أو قسيمة أو مجموعة أو مسار أو اقتباس أو معاملة أو سلعة أو خدمة أو مزود طرف ثالث سيكون دون انقطاع أو خال من الأخطاء أو آمنًا أو دقيقًا أو قانونيًا أو متاحًا أو مناسبًا لأغراض معينة أو ذات جودة مرضية أو قابلة للاسترداد أو سائلاً أو مربحًا.

GEF لا تضمن هوية المستخدم الآخر أو سلطة أو قابلية الدفع أو القدرة أو الصدق أو الأداء أو السلع أو الخدمات أو الاحتياطيات أو الضمانات أو الامتثال. أنت مسؤول عن الدقة الواجبة والالتزامات التي تتعهد بها.

لا يوجد شيء في هذا القسم يقلل من واجب الإصدار في احترام بطاقة الصرف الخاصة به، أو واجب المدير في احترام قواعد المجموعة والضمانات التي يتم الإعلان عنها، أو التزامات طرف آخر بموجب شروط المعاملة المعمول بها.

## 21. الحد من المسؤولية

لا شيء في هذه الشروط يستبعد أو يحد من المسؤولية عن الاحتيال أو الإساءة المتعمدة أو الإهمال الشديد أو الوفاة أو الإصابة الشخصية حيث لا يمكن تقييد هذه المسؤولية بشكل قانوني، وانتهاك واجبات حماية البيانات الإلزامية، أو وسائل معالجة المستهلكين الإلزامية، أو أي مسؤولية أخرى لا يسمح القانون المعمول بها لـ GEF باستبعادها أو تقييدها.

مع مراعاة هذه الاستثناءات وحتى الحد الأقصى الذي يسمح به القانون، لا تتحمل GEF ومسؤوليها ومديريها وموظفيها ومقاوليها وموكليها والكيانات التابعة لها مسؤولية:

- سلوك أو فشل الجهة المصدرة أو المدير أو الاحتمالي أو الجهة المعارضة أو المستخدم الآخر؛
- جودة أو سلامة أو قانونية أو تسليم أو استرداد أو تسعير أو توفير السلع أو الخدمات أو الرموز أو البطاقات أو الأوراق المالية أو الضمانات؛
- فقدان أوراق الاعتماد، والأصول، والبيانات، والفرص، والخيرات، والأرباح، والإيرادات، والأعمال التجارية، أو المدخرات المتوقعة؛
- الخسائر غير المباشرة أو غير المباشرة أو خاصة أو مثالية أو عقابية أو نتيجة؛
- العقد الذكي أو البلوكشين أو المحفظة أو الجهاز أو الشبكة أو القرآن أو الجسر أو الجهاز التنقل أو خدمة طرف ثالث أو حدث القوة الكبرى أو السجل العام خارج سيطرة GEF المعقولة؛ أو
- القيود أو الإجراءات الصادقة التي تم اتخاذها لمعالجة القانون أو العقوبات أو الاحتيال أو السلامة أو الأمن.

مع مراعاة نفس الاستثناءات، فإن إجمالي مسؤولية GEF الناتجة عن التطبيق أو المتعلقة به أو هذه الشروط لن تتجاوز إجمالي الرسوم التي دفعتها مباشرة إلى GEF لاستخدام التطبيق خلال 12 شهرا مباشرة قبل الحدث الذي أدى إلى المطالبة. رسوم المجموعة، رسوم الشبكة، رسوم الطرف الثالث، والمساهمات، والأصول التي يتم نقلها إلى مستخدم آخر أو عقد لا هي رسوم مدفوعة مباشرة إلى GEF ما لم يتم تحديد GEF صراحة كمستلمها.

إذا كان القانون المعمول به لا يسمح باستبعاد معين أو الحد، فإن هذا الاستبعاد أو الحد لا ينطبق إلا في أقصى نطاق يسمح به القانون. هذا القسم يخصص المخاطر بينك و GEF لا تحد من المطالبات التي قد تكون لديك مباشرة ضد الجهة المصدرة أو الموكل أو المقترض أو المقترض أو صاحب القرض أو أي طرف مسؤول آخر.

## 22. التعويضات

في الحد الأقصى المسموح به من قبل القانون، ستقوم بتعويض GEF وموظفيها ومديريها وموظفيها ومقاوليها ووكلاءها ووكلاءها ووكالاتها والكيانات التابعة لها وتحميلهم من المطالبات والخسائر والمسؤوليات والعقوبات والحكمات والتكاليف المعقولة الناتجة عن:

- انتهاك هذه الشروط أو القانون المعمول به؛
- حسابك، المحتوى، الرمز، الجائزة، المجموعة، التبادل، المساهمة في المجموعة، السلع، الخدمات، أو الالتزامات الأخرى؛
- انتهاكك أو إساءة استخدام حقوق أو معلومات أو أصول أو شهادات شخص آخر؛ أو
- الضريبة أو التنظيمية أو المستهلكية أو العمل أو الاسترداد أو الدفع أو التزامات أخرى تكون مسؤولة عنها.

لا ينطبق هذا التعويض في الحد الذي تسببت فيه المطالبة في الاحتيال أو سوء السلوك المتعمد أو الإهمال الجسيم أو انتهاك رسوم لا يمكن استبعادها. ستقدم GEF إشعارًا معقولًا عن المطالبة المغطاة حيثما كان ذلك ممكناً ولن تطلب منك قبول تسوية تعترف بشكل غير قانوني بأفعال خاطئة نيابة عنك.

## 23. النزاعات

إذا كان لديك نزاع مع مستخدم آخر، يجب عليك أولاً استخدام عملية الشكوى أو الاسترداد أو النزاع التي تم الكشف عنها عن البطاقة أو المجموعة أو المعاملة ذات الصلة. يمكن لـ GEF أن تختار تقديم سجلات أو أدوات الاتصال أو تدبير أو مساعدة غير رسمية، ولكنها ليست ملزمة بحل النزاع ولا تتحمل المسؤولية عن الالتزام الأساسي من خلال المساعدة.

قبل تقديم مطالبة ضد GEF، يجب عليك إرسال وصف كتابي للمسألة وطلب التعويض إلى `info@grassecon.org` وإتاحة فرصة معقولة للرد بحسن نية. هذا لا يقلل من مدة التجديد القانونية أو يمنع الإغاثة العاجلة.

تنظم هذه الشروط والنزاعات بينك وبين GEF بموجب قوانين كينيا، دون النظر في قواعد الصراع بين القوانين. يمكن للمحاكم المختصة في كينيا سماع مثل هذه النزاعات. هذا الخيار لا يحرمك من حماية المستهلكين الإلزامية أو الوصول إلى منتدى لا يسمح القانون المعمول به بإقصاء هذه الشروط.

## 24. تغييرات على هذه الشروط

GEF قد تقوم بتحديث هذه الشروط لتعكس التغييرات في التطبيق أو القانون أو المخاطر أو الأمن أو العمليات. ستحدد GEF النسخة الجديدة وتاريخ التنفيذ.

ستقدم GEF إخطارًا لمدة 30 يومًا على الأقل قبل حدوث تغيير جوهري من خلال طريقة الإخطار المعتمدة لهذا التحديث. تم نشر النسخة 1.1 والتي دخلت حيز التنفيذ في 1 أكتوبر 2026 كشروط الاستخدام العام الأول للتطبيق. يمكن أن يبدأ التغيير حيز التنفيذ في وقت مبكر عندما يكون ذلك ضروريًا معقولًا للامتثال للقانون أو معالجة خطر أمني أو أمني عاجل أو منع الاحتيال أو الاستجابة لحدث خارج سيطرة GEF المعقولة.

عندما يسمح القانون المعمول به، فإن الاستمرار في الاستخدام بعد تاريخ التنفيذ يشكل قبولًا للشروط المحدثة. إذا كان القانون يتطلب موافقة إيجابية، فسوف يطلب GEF إعادة القبول قبل السماح باستمرار استخدام ميزات الحساب المتضررة. إذا لم توافق، يجب عليك التوقف عن استخدام الميزات المتأثرة. تطبق التغييرات مستقبلاً ولا تغير المعاملة المكتملة أو شروط المعاملة المتفق عليها سابقاً.

## 25. الشروط العامة

**اتفاق كامل** هذه الشروط هي الاتفاقية الكاملة بينك وبين GEF المتعلقة بالتطبيق، باستثناء اتفاقية كتابية منفصلة وقعتها ممثل GEF المعتمد. تنظم شروط الجائزة وقواعد المجموعة وشروط المعاملة الالتزامات ذات الصلة بين أطرافها كما هو موضح في القسم 2.

**لا شراكة أو وكالة** لا يخلق استخدام التطبيق عملًا أو شراكة أو مشروعًا مشتركًا أو وكالة أو وكيلًا أمنيًا أو امتيازًا أو سلطة ممثلة بينك و GEF أو بين المستخدمين.

**مهمة** لا يمكنك تعيين حسابك أو هذه الاتفاقية دون موافقة مكتوبة من GEF. يمكن لـ GEF تعيين هذه الاتفاقية كجزء من إعادة تنظيم أو نقل التطبيق أو تداول العمليات، مع مراعاة القانون المعمول به وإشعار معقول.

**الاختصاص.** إذا كان حكمًا غير قانوني أو غير قابل للتنفيذ، فسيتم تقييد ذلك إلى الحد الأدنى اللازم، وستستمر الأحكام المتبقية في التنفيذ.

**لا تخلف.** الفشل أو التأخير في تنفيذ حكم لا يعتبر إعفاءً. لا ينطبق الإعفاء إلا إذا كان مكتوبًا من قبل طرف مصرح به، ولا ينطبق إلا على المسألة المحددة المذكورة.

**القوة القصوى** لا تتحمل GEF المسؤولية عن التأخير أو الفشل الناجم عن الأحداث التي تتجاوز سيطرتها المعقولة، مع مراعاة أي واجب لا يمكن استبعاده من اتخاذ تدابير احتياطية معقولة أو تخفيف الأضرار.

**النجاة** الأحكام المتعلقة بالالتزامات المتبقية، والأدلة على المعاملات، والسجلات العامة، وموافقة المحتوى، والاحتفاظ بالبيانات، وتخصيص المخاطر، والمسؤولية، والتعويضات، والنزاعات، والتفسير العام لا تزال قائمة على التعليق، أو إنهاء، أو إغلاق الحساب إلى الحد اللازم لإعطائها تأثير.

**تصريحات مصرح بها** لا يمكن أن يخلق التزام نيابة عن GEF إلا بإصدار بيان كتابي من قبل ممثل GEF مرخص به بشكل صحيح. لا يمكن لمتطوع أو مقاول أو عضو في المجتمع أو وسيط أو مستخدم آخر أن يربط GEF دون هذه السلطة.

**العناوين واللغة** العناوين هي من أجل الراحة. النسخة الإنجليزية تتحكم ما لم يتطلب القانون المعمول به خلاف ذلك.
