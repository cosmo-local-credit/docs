# البروتوكول

يشرح **بروتوكول تجميع الالتزامات (CPP)** كيف تختار الصناديق المستقلة في حوكمتها القسائم، وتنشر قواعد التبادل، وتتيح التبادل. ويستخدم الحامل القسيمة لاحقًا لدى الجهة المصدرة للحصول على السلع أو الخدمات الموعودة. هذه خطوات منفصلة، ولكل منها مسؤولياتها.

يشرح هذا الموقع هذه المفاهيم وكيفية استخدام CLC App. وتُعد [وثائق برمجيات CLC](https://software.cosmolocal.credit/) المرجع المعتمد لتفاصيل التنفيذ البرمجي والعقود وواجهات API والنشر والتشغيل. وهي متاحة حاليًا بالإنجليزية.

ابدأ بصفحة [المفاهيم والمصطلحات](/ar/introduction/concepts) للتعرّف على المصطلحات المشتركة، أو [الورقة البيضاء](/ar/white-paper) للاطلاع على التصميم والمقترحات الأوسع.

## نمط النشر

يمكن لمجتمعات ومؤسسات مختلفة تشغيل برمجيات متوافقة وفق قواعدها الخاصة. وتدير Grassroots Economics Foundation [CLC App العام](https://cosmolocal.credit). وينبغي توضيح المشغلين والعقود والجهات المسؤولة في كل نشر.

لعناوين العقود وإرشادات النشر وكيفية التحقق من المالكين وصلاحيات الترقية، راجع [النشر والتحقق](https://software.cosmolocal.credit/contracts/deployments). ولتشغيل الخدمات الداعمة، ابدأ بصفحة [CLC Core API](https://software.cosmolocal.credit/core-api/).

## التبادل الموجه على مستوى التطبيق

يمكن للتطبيق مساعدة المشارك على التبادل عبر عدة صناديق عند توفر مسار مناسب. يراجع المشارك عرض السعر ويأذن بالتبادل. ويحتفظ كل صندوق بقواعده وأطرافه المسؤولة.

راجع [المسارات والمسؤوليات](/ar/protocol/network) لفهم ما يعنيه ذلك للمشاركين، و[التنفيذ البرمجي للتوجيه](https://software.cosmolocal.credit/contracts/routing) لمعرفة كيف تحسب البرمجيات عروض أسعار المسارات وتنفذها.

تتيح البرمجيات التبادل؛ وتبقى الجهات المصدرة مسؤولة عن وعود قسائمها، ويبقى مشرفو الصناديق مسؤولين عن قواعدهم المنشورة. ويخضع استخدام التطبيق العام إلى [شروط الخدمة](/ar/governance/terms).
