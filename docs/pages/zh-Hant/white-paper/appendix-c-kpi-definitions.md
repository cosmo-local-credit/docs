## C. 擬議的 KPI 定義

這些關鍵指標構成了擬議的測量規範,而不是當前應用程式或協議記錄每一個所需的事件的宣告.

每個公佈的KPI都必須包含:

- 負責的出版商和資料來源;
- 事件或狀態的定義;
- 一組或測量期;
- 單位和估值方法;
- 估值時間表;
- 包容和排斥的規則;
- 部分,爭議,過期,無法訪問和糾正的記錄處理;
- 需要在鏈外的證據或證明;
- 審查歷史和資料質量限制;以及
- 結果是否在鏈上,報告,認證,獨立驗證或估計.

| KPI | 擬議的定義 | 需要的證據和排除 |
| --- | --- | --- |
| **有效的表達** | 在一段時間內接受發行人贖回過程中的計數或單元 | 報表標識,發行人,持有許可權,數量,時間,狀態;排除複製和無效的請求 |
| **履約率** | 已填寫的有效表現,分為相同成熟群體的有效呈現 | 單獨的發行方績效證據;報告開放,拒絕,爭議,部分和糾正的案件 |
| **核銷完整性** | 已填寫的表單,分為已填補的表現 | 燃燒,取消,停用記錄或與履行相關的其他未再使用證據 |
| **履約延遲** | 呈現到完成時間的中位數和90個百分點 | 不取代發行到提交或收購到提交的持有時間 |
| **持有時間** | 收購到提交時間的中位數和分佈 | 確定收購事件並排除未知的收購時間 |
| **現有資格承諾** | 已確定排除後仍然存在的可接受第三方承諾 | 發行人身份和條款;不包括適用的發行人的庫存,過期,燃燒,清理,測試和非承諾代幣 |
| **直接資金池兌換量** | 按已披露的估值方法衡量、作為一次資金池兌換髮起的已完成兌換價值 | 鏈上結算事件、代幣單位、匯率來源和時間；不得歸類為發行方履約 |
| **路徑發現嘗試** | 在一段時間內查詢可到達代金券或候選路徑的有效請求 | 圖版本、索引區塊、新鮮度、錢包範圍、請求深度、候選數量、遺漏或搜尋預算狀態；不是權威報價 |
| **可用候選路徑** | 發現功能針對已定義請求群組返回的候選路徑 | 分別計算每條有序的資金池/代幣路徑；說明路徑深度和排除項；不得歸類為可執行或已結算 |
| **路徑報價透過率** | 返回的權威路徑報價除以有效報價嘗試 | 固定區塊、路徑、金額模式、到期、結果或拒絕原因；與發現成功和執行分開 |
| **路徑執行率** | 已確認的路徑兌換除以同一成熟群組中有效、已簽署的執行嘗試 | 跟蹤 ID、交易雜湊、中繼狀態、確認或回滾、路徑深度和失敗原因；不包括未簽署報價 |
| **整條路徑兌換量** | 已確認路徑兌換的輸入和輸出價值，每條路徑只計算一次 | 按一種估值方法，使用第一跳已結算輸入和最後一跳已結算輸出；不得把所有跳的價值相加為獨立經濟量 |
| **逐跳結算** | 已確認路徑中每一跳的已結算輸入、總輸出、資金池費用、協議費用和淨輸出 | 有序資金池和代幣識別符號、結算事件、交易雜湊、區塊、日誌索引和任何中間餘量 |
| **路徑費用** | 一條路徑上實際結算的當前資金池費用和協議費用 | 按費用型別逐跳和彙總報告；不得標記為擬議網路分成或尚未實現的服務費 |
| **路徑限制** | 被拒絕的路徑或報價數量及佔比 | 准入、存入上限、流動性、費用域、不受支援的代幣或報價器、錢包餘額或型別、Gas、搜尋預算、到期、不匹配或模擬證據 |
| **路徑對賬健康度** | 索引圖和分組結算記錄的新鮮度與可靠性 | 圖版本和年齡、對賬佇列深度、對賬時長、糾正、故障、未知成員和未解決收據 |
| **資金池庫存** | 在特定時間內,一個集團所持的衡量支援資產 | 合同餘額,費用保留,不可訪問的資產,估值方法和所有者撤銷權 |
| **儲備充足性** | 符合條件的可用儲備資產,按明確覆蓋的風險分為 | 覆蓋政策,資產資格性,保管/控制,負債,排除和估值;不包括預設的全部代幣供應 |
| **限制利用率** | 測量的庫存代幣餘額以其當前配置的上限分為 | Limiter地址,代幣,池,時間標籤,變化和無限制期限 |
| **擔保人回收** | 收到的資格回報,分為已支付的受保索賠 | 確定擔保人,索賠政策,時間表,成本,爭端和抵免 |
| **擬議的網路收入** | 收到的擬議網路拉克加上收取的單獨路由/服務費 | 排除池所保留的毛額費用,避免兩次計數拉克 |
| **管理及時性** | 發現,決定,暫停,修復和關閉事件的時間 | 定義時鐘,負責機構,緊急權力,上訴和失蹤事件 |

區塊鏈活動本身並不能確定身份,發行方的表現,滿意度,社群健康,因果關係或影響.
