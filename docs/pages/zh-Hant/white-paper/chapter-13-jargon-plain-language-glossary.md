# 13. 通俗術語表

- **Cosmo-Local Credit (CLC):** 產品家族,包括 CLC App,文件和更廣泛的承諾共享工作.
- **CLC App:** 透過 GEF 在 `cosmolocal.credit`.
- **承諾匯聚協議 (CPP):** 管理,估值,限制,交換和負責任治理的可重複使用模型.
- **Protocol v1.1.0:** 證實公開智慧合同釋出.
- **承諾資金池:** 一個管理的安排,允許支援資產併發布交易規則.
- **`SwapPool`:** 現在的代幣庫和直接交換合同.
- **標誌:** 單獨的代幣機制不能創造一個可以贖回的承諾.
- **憑證:** 證券或記錄,由發行者以公佈的條件表現為可贖回的承諾.
- **提供:** 有關券的商品或服務目錄.
- **需求：** 一項已公佈的需要表達。它本身不會接受商品或服務專案或代金券、授權兌換、預留庫存或建立義務。
- **發行方:** 負責發行和履行券承諾的當事人.
- **資金池管理者:** 負責釋出和管理池規則的結構.
- **登錄檔：** 用於識別合約、資金池、代幣或其他資源的發現和許可記錄。被收錄本身不能證明認可、發行方資格、履約、保證或保險。
- **匯率或報價:** 一個由配置的報價符生成的交易引數;不是現金證明或贖回值.
- **價值指數 (Value Index)：** 已配置報價器用於計算資金池兌換報價的相對估值輸入。它不是自動市場價格、現金價值或發行方義務。
- **`Limiter`：** 可選的 Protocol v1.1.0 元件，為一個資金池設定最大代幣餘額。應用可能把這個上限標記為**“信用額度”**。它不是個人借款限額，也不是全網路滾動限額。
- **庫存交換:** 透過一個 `SwapPool` 進行直接資產交易.
- **路徑：** 從錢包中的輸入代金券到目標代金券，由一次或多次資金池兌換組成的有序序列。
- **路徑深度：** 一條路徑中的資金池兌換次數。當前公開部署最多搜尋三次。
- **路徑發現：** 根據經過對賬的圖和錢包持倉資料估算可能路徑。發現的路徑不是可執行承諾。
- **路徑報價：** 針對選定路徑的有時限權威提議；它根據受支援的資金池狀態計算，在同一個固定區塊讀取，並在簽署前模擬。
- **路徑兌換：** 由參與者授權的一系列資金池兌換。當前應用把它作為一筆同鏈 Calibur 錢包批次提交；任何呼叫失敗，整筆批次都會回滾。
- **路徑兌換收據：** 一份分組技術記錄，包含路徑狀態、交易雜湊、各跳、已結算金額，以及逐跳資金池費用和協議費用。
- **流動性:**符合資格的庫存,可根據當前招收,餘額上限,報價,費用,預訂和撤回條件提供. 一個圖邊或代幣餘額本身並不能證明可用的流動性.
- **交換結算:** 在鏈上進行的轉賬和費用會計,完成 Pool swap.
- **報價:** 返回或以其他方式向發行人呈現券單元.
- **履約:** 發行者提供承諾的商品,服務,福利或其他效能.
- **核銷:** 防止完成單位再次呈現的記錄.
- **Solidity `SwapRouter`：** Protocol v1.1.0 中僅用於報價的合約。它可以沿給定路徑進行計算，但不託管資產、不授權代幣，也不執行兌換。
- **應用層路徑流程：** 當前 CLC App 和 CLC Core 用於在資金池合約之上發現、報價、模擬、準備、中繼、對賬和報告同鏈路徑的服務。
- **再平衡：** 根據管理者授權的任務，把資金池庫存移向已採納目標。當前由參與者發起的路徑兌換本身不授權自動再平衡。
- **清算或淨額結算：** 把多項義務或預期轉移彙總，以計算減少後的淨額。它不是當前 App/Core 路徑兌換的一部分。
- **修復：** 在特定許可權範圍內糾正配置、登錄檔記錄、服務故障、爭議或未履行承諾的可問責流程。登錄檔或路徑服務修復不會在未披露的情況下改寫獨立資金池規則，也不會解除發行方義務。
- **擬議的CLC網路池:** 未來的網路級清算和預算協調安排.
- **擬議的CLC治理代幣:** 未來的治理設計,而不是當前的App或 Protocol v1.1.0 資產.
- **網路拉克:** 擬用於未來網路預算的組費用份額.
- **擔保或保險:** 只有一個特定方明確承擔,資助和公佈這一保護.
