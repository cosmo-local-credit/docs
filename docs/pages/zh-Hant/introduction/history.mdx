# 歷史

[Grassroots Economics Foundation](https://grassrootseconomics.org/about/) (GEF) 建立和管理歷史性 Sarafu Network 現在運營 CLC App 肯亞的社群與共享承諾一起生活和學習,透過共同承諾來維持互惠服務. [基層經濟:反思和實踐](https://grassrootseconomics.org/book/) 承諾可以在不需要中央機構的情況下進行交換,履行和更新的承諾.

這項工作首先透過社群貨幣來表達.當國家貨幣稀缺時,記錄和履行義務的本地方法.更深層次的教訓不是一個特定的貨幣.它是一個策劃模式,共享估值,保護共同資產的限制和保持互惠的交換.這些教訓為承諾彙集協議 (CPP) 提供了資訊.

## 歷史上的 Sarafu Network 轉移到 Cosmo-Local Credit

歷史性 Sarafu Network 作為社群貨幣的實踐學習環境,承諾資金池透過社群,學校,診所,農場,合作社和其他地方組織.GEF 透過這種經驗,研究瞭如何將獨立管理的承諾連線起來,而不會使它們成為一個統治市場或取消地方責任.

服務曾經被表達為 Sarafu Network 轉移到 CLC App 在 [cosmolocal.credit](https://cosmolocal.credit) 根據 GEF 現在,所有 Sarafu 賬戶,錢包,代幣,券商,積分庫,餘額,報告,參與者或義務都已遷移到當前的應用程式中.

Cosmo-Local Credit 現在的產品家族包括:CLC App 作為一個獨立管理的券商,承諾資金池發行方仍然對承諾負責,資金池管理者它們仍然負責其規則和任何公佈的保證,社群和機構可以使用適合自己的情況的治理安排.

一條路,簡而言之:

1. 當現金短缺時,
2. 承諾整合開發了可重複使用的協議元件的管理,估值,限制和交換.
3. 歷史悠久的 Sarafu Network 在許多真正的社群和組織中測試並完善了這些想法.
4. 服務轉移到 Cosmo-Local Credit,但沒有代表所有歷史使用者,資產,記錄或義務轉移.
5. 目前的應用程式提供支援的錢包,代金券,庫存和直接交換工作流程;更廣泛的路由,清算,流動性,保險和治理機制仍然被提出或依賴於部署.

閱讀 [概念和詞彙](/zh-Hant/introduction/concepts) 在檔案中使用的層次和狀態術語. [服務條款](/zh-Hant/governance/terms) 管理 CLC App 的使用. [白皮書](/zh-Hant/white-paper) 提供更廣泛的設計,研究和路線圖.

## 從基層經濟學中進一步學習

這些組織和教育資源提供了額外的背景.它們補充,而不是定義當前 CLC App 和協議行為.

- [關於基層經濟](https://grassrootseconomics.org/about/) —其使命,團隊,價值觀和更長的組織歷史.
- [研究和開放資料](https://grassrootseconomics.org/research/) er同行審查的論文,工作檔案,資料集,報告和學術研究.
- [基層經濟:反思和實踐](https://grassrootseconomics.org/book/) —本書以免費的數字和音訊格式,印刷版也可用.
- [草根日誌](https://grassrootseconomics.org/blog/) community現場筆記,研究更新,社群故事和不斷發展的實踐.
- [教育遊戲](https://grassrootseconomics.org/games/) learning學習資源關於承諾,結算,資源流動,交流和彙集.
