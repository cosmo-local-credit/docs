# 入門

Cosmo-Local Credit（CLC）幫助人們說明自己能提供什麼、發布自己需要什麼，並透過獨立治理的承諾資金池交換代金券。打開 [CLC App](https://cosmolocal.credit) 即可開始。

基本思路很簡單：

1. 為自己能提供的東西建立一張代金券——它很像禮品卡。
2. 發布一項 **商品或服務項目（Offering）**，讓人們發現相關的商品或服務。
3. 發布或回應一項 **需求（Want）**，尋找可能的交換夥伴。
4. 透過承諾資金池，按照已公佈的規則交換受支援的代金券。
5. 按照代金券條款，向發行方使用代金券並獲得其承諾的商品或服務。

App 中的 Credit（介面標籤為“可存入”）是指獲得認可的承諾以及代金券交換容量，並不自動表示個人貸款、借款額度或墊款承諾。

準確的定義請參閱[概念與詞彙](/zh-Hant/introduction/concepts)。

## 第一次使用 App

### 1. 瀏覽市場和需求

建立任何內容之前，可以先瀏覽 [CLC App](https://cosmolocal.credit)。**市場（Market）** 是用於發現內容的目錄，本身並不自動成為賣方、交換場所、認可或擔保。

查看代金券時，請確認：

- 由誰發行；
- 承諾提供哪些商品或服務；
- 可以在何處、何時以及如何使用；
- 有哪些限制、有效期、聯繫方法和投訴流程；以及
- 哪些承諾資金池支援它。

**需求（Want）** 用來表達需要。發布或回應需求，並不自動表示接受代金券、預留商品、授權交換或產生義務。聯繫其他參與者或給對方傳送訊息，本身也不會產生、履約或核銷代金券承諾。

### 2. 建立或存取帳戶和錢包

App 使用帳戶來存取個人資料和工作階段，並使用 **錢包（Wallet）** 進行區塊鏈授權。請妥善保護通行金鑰、紙錢包資料、復原資訊、裝置和其他憑證。確認交易前，請檢查每個地址、資產、金額、資金池、費用和授權。

介面會在註冊流程中以及發布代金券或資金池之前要求您確認條款。繼續之前，請閱讀[服務條款](/zh-Hant/governance/terms)和[隱私聲明](/zh-Hant/governance/privacy)。

### 3. 建立代金券和商品或服務項目

為自己能夠合理提供的東西建立代金券。可以把它理解為製作自己的禮品卡：您說明它代表什麼，以及使用條件是什麼。

一張完整的代金券包含幾個彼此獨立的層面：

1. 代幣合約機制和餘額；
2. 發行方公佈的代金券條款；
3. 一項或多項描述相關商品或服務的 **商品或服務項目（Offering）** 記錄；以及
4. 發行方在現實世界中的履約。

建立或鑄造代幣，並不能證明相關商品或服務項目確實存在、發行方具備履約能力，或 Grassroots Economics Foundation（GEF）保證履約。

### 4. 發布或回應需求

使用需求來說明您正在尋找什麼，包括數量、地點、時間和合適的聯繫方法。其他參與者可以發現這項需求、查看您公開的代金券和商品或服務項目，並決定是否與您聯繫。

應明確協商內容和責任。訊息可以幫助參與者就交付、預約或其他細節達成一致，但承諾的內容取決於適用的代金券條款以及另行約定的交易條款。

### 5. 查找或建立承諾資金池

承諾資金池對選定的代金券進行篩選，並支援它們之間的交換。使用或支援資金池之前，請查看：

- 負有責任的 **資金池管理者（Pool Steward）** 和當前合約所有者；
- 獲准進入的代金券和其他受支援資產；
- 匯率或報價方法；
- App 中的 **“信用額度（Credit limit）”**，它是資金池的代幣餘額上限，不是個人信用額度；
- 資金池費用和協議費用；
- 可用庫存，以及資金池所有者提取流動性的權限；
- 代理、多簽和依賴項控制者；以及
- 另行公佈的貢獻、擔保、儲備、獎勵或保險條款。

存入資產會把資產轉移到資金池的 `SwapPool` 中。Protocol v1.1.0 不會自動賦予存入者資金池份額、還款權、提款權、獎勵或治理權。

### 6. 傳送或交換代金券

使用 **傳送（Send）** 直接轉移代金券。使用 **資金池交換（Pool swap）**，透過一個資金池把一種受支援資產換成另一種。

App 的 **可存入（Credit）** 檢視還可以查找透過多個獨立治理資金池可達的代金券。選擇 **取得（Get）** 來指定想獲得的代金券，或選擇 **花費（Spend）** 來指定想使用的代金券。然後查看：

1. **支付方式（Pay with）** 和 **估算（Estimate）**；
2. **路徑詳情（Route details）**，包括每個資金池、金額、資金池費用和協議費用；
3. 最低收到數量和報價到期時間；以及
4. 在選擇 **確認兌換（Confirm exchange）** 前，檢查準備好的錢包批次。

並非每張代金券、每個資金池或每種錢包都支援路由交換。App 會檢查您的選項是否可以交換。[軟體路由參考](https://software.cosmolocal.credit/contracts/routing)以英文維護當前資格規則和技術要求。

路線發現只是估算。簽署前，請審核最終報價，包括最低收到數量和到期時間。當前路由交換要麼整體成功，要麼各資金池交換一起還原。提交後，請檢查收據中的結果、交換數量和費用。

### 7. 向發行方使用代金券

閱讀代金券條款，並按照發行方的預約、交付或聯繫流程操作。在當前 App 中，**“兌付（Redeem）”** 會打開普通傳送流程，並預填代幣所有者的地址。傳送代金券屬於兌付出示，並不能證明發行方已經提供承諾的商品或服務。

履約後，發行方應記錄 **核銷（discharge）**，使已經履約的單位不能再次使用，例如按照公佈的條款接收、銷毀、取消或以其他方式停用這些單位。

## 發布之前

代金券、資金池、商品或服務項目、需求、目錄、貼文和評價可能具有不同的可見範圍。發布資源之前：

- 選擇一個可以安全公開的地圖位置；精確座標可能會顯示；
- 檢查未登入和已登入狀態下分別會顯示哪些資訊；
- 使用適合預期受眾的聯繫方式；
- 除非確實打算公開，否則不要把私人個人資料資訊複製到公共資源中；以及
- 閱讀隱私聲明中的[“哪些資訊會公開？”](/zh-Hant/governance/privacy#4-哪些資訊會公開)部分。

## 當前 App 操作

| App 操作 | 作用 |
| --- | --- |
| **傳送（Send）** | 將代幣餘額轉移到另一個地址。 |
| **資金池交換（Pool swap）** | 透過一個 `SwapPool` 交換受支援資產。鏈上結算不能證明發行方已履行承諾。 |
| **路由交換（Routed exchange）** | 在一筆有明確範圍的同鏈錢包交易中，按順序執行多次資金池交換。它不會合併各資金池的治理。 |
| **“兌付（Redeem）”** | 預填向代幣所有者傳送代幣的流程，作為兌付出示。履約和核銷仍是不同步驟。 |
| **“申請停用（Request retirement）”** | 允許當前所有者請求管理員停用代金券或資金池。請求待處理期間，資源仍保持活躍；所有者可以取消請求，管理員可以批准或拒絕。停用不會刪除合約、餘額或歷史記錄。 |
| **資金池停用** | 獲批後，阻止新的資金池交換和存款，但仍允許可用的提款。它不會刪除此前的結算記錄。 |
| **提取資金池流動性** | 允許資金池所有者把可用庫存轉移到選定地址。 |
| **收取費用** | 把累計的資金池費用傳送給配置的接收方。 |

## 責任和重要限制

[Grassroots Economics Foundation](https://grassrootseconomics.org/about/) 營運 App 和支援基礎設施。除非 GEF 明確接受某筆特定交易中的其他角色，否則它不是使用者建立代金券的發行方、使用者建立資金池的管理者、託管人、貸款人、借款人、擔保人、保險人或兌換方。

交易前請記住：

- 您必須符合服務條款中的年齡、法律行為能力和管轄權要求。
- 發行方對自己的代金券承諾負責。
- 資金池管理者對自己公佈的資金池規則以及明確承擔的任何擔保負責。
- 列入目錄、評價、路線、限額、儲備或區塊鏈記錄，並不自動表示認可、估值、履約記錄、擔保、保單或兌現現金的承諾。
- 支付服務、獎勵、貢獻安排和其他服務提供者整合取決於具體部署，並需要各自的披露。

App 支援可用的直接和路由資金池交換。跨鏈路由、資金池自動再平衡、批次淨額結算、共享保險、擬議治理資產、網路流動性計劃和受監管支付通道仍屬於擬議功能或取決於具體部署，除非某個具體部署明確表示已經啟用。
