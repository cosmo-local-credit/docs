# 入門

Cosmo-Local Credit (CLC) 是一款漸進式網頁應用。使用者可以透過獨立治理的承諾資金池，建立、發現、持有、轉移和交換數字資產，包括可兌付的代金券。CLC App 可在 [cosmolocal.credit](https://cosmolocal.credit) 使用。

[Grassroots Economics Foundation](https://grassrootseconomics.org/about/) (GEF) 運營該應用及配套基礎設施。除非 GEF 對特定商品或服務專案或交易明確接受其他角色，否則 GEF 不是使用者建立代金券的發行方、使用者建立資金池的管理者、託管人、貸款方、借款方、擔保人、保險人或兌付方。發行方對其代金券承諾負責，資金池管理者對其資金池規則負責。

請閱讀 [概念和術語](/zh-Hant/introduction/concepts)，瞭解本文件使用的產品層級、角色、操作、價值、費用和狀態術語。

建立賬戶或交易前，請閱讀 [服務條款](/zh-Hant/governance/terms)。請特別注意：

- 您必須至少年滿 18 歲，已達到適用於您的法定成年年齡，並具有簽訂合同的能力。
- 您負責確認您的賬戶、代金券、資金池或交易在所有相關司法管轄區都合法。
- 您必須保護錢包憑證。GEF 可能無法恢復丟失的錢包或撤銷已授權的交易。
- 公共區塊鏈上的交易和記錄可能公開可見、永久保留且無法撤銷。
- 應用中的上架不代表 GEF 認可，也不保證兌付、價值、流動性、可兌換性或現金兌付。

## 從當前應用開始

### 1. 瀏覽市場

開啟 [cosmolocal.credit](https://cosmolocal.credit) 瀏覽公開的 **市場**。市場是應用的發現目錄。請檢視負責的發行方、所承諾的商品或服務、地點、可用性和公佈條款。市場上架不會自動構成交換場所、賣方關係、獨立估值、認可或保證。

### 2. 建立或訪問賬戶和錢包

應用使用賬戶來管理個人資料和會話，使用錢包授權區塊鏈交易。請保護通行金鑰、紙質錢包材料、恢復資訊、裝置和其他憑證。確認交易前，請檢查每項資產、金額、地址、資金池、費用和授權。

### 3. 建立代金券

代金券由幾個不同層級組成：

1. 代幣合約機制和餘額；
2. 發行方對代金券的命名和公佈條款；
3. 一條或多條與相關商品或服務有關的商品或服務專案記錄；以及
4. 發行方在現實世界中的履約。

僅建立或鑄造代幣，並不足以證明存在某項商品或服務、發行方有能力提供它，或 GEF 保證兌付。

### 4. 建立或評估承諾資金池

承諾資金池是一項受治理的安排。它當前的 `SwapPool` 合約可以持有受支援的代幣庫存並執行直接交換。使用或向其注入資產前，請檢視：

- 負責的資金池管理者和當前合約所有者；
- 代理管理員和已配置依賴項的控制者；
- 准入的代金券和其他受支援資產；
- 匯率或報價方法；
- 應用中的 **“信用額度”**：它是資金池的代幣餘額上限，而不是個人信用額度；
- 資金池費用和協議費用；
- 可用庫存以及資金池所有者提取流動性的權力；以及
- 單獨公佈的出資、擔保、儲備或保險條款。

存入會將資產轉入 `SwapPool`。Protocol v1.1.0 不會鑄造資金池份額代幣，也不會自動賦予存入方償還、提取、獎勵或治理權利。

### 5. 直接兌換或透過路徑兌換

應用的**可存入**檢視可以根據您錢包中的代金券，查詢可獲得的其他代金券。要獲得目標代金券，可能需要一次資金池兌換，也可能需要經過多個獨立治理資金池的路徑。當前公開部署最多搜尋包含三次資金池兌換的路徑。

進行兌換時：

1. 對希望獲得的代金券選擇**取得**，或對希望使用的代金券選擇**花費**；
2. 核對可用的**支付方式**和**估算**；
3. 開啟**路徑詳情**，檢視每個資金池、兌換、金額、資金池費用和協議費用；
4. 選擇**核對**，檢查最低收到金額和報價有效期，然後選擇**確認兌換**；以及
5. 簽署準備好的錢包批次。

CLC Core 根據已索引的資金池和代金券資訊查詢可能的路徑。路徑發現只是估算。簽署前，CLC Core 會在同一個固定區塊讀取相關資金池狀態，生成權威報價，為每一跳設定最低輸出和截止時間，並模擬整個批次。應用目前不會另收路徑服務費；每一跳仍可收取已配置的資金池費用和額外協議費用。

簽署後的路徑會作為一筆同鏈交易提交。每一跳都使用同一個、與應用相容的錢包。如果批次中的任何授權或資金池兌換失敗，整筆交易都會回滾，因此此前的跳也不會保留為已結算狀態。收據會用一個跟蹤 ID 彙總路徑，並顯示狀態、交易雜湊、每個資金池、已結算金額，以及每一跳的資金池費用和協議費用。

路徑可能不可用，原因包括：錢包沒有符合條件的輸入代金券；某資金池未准入該代幣；資金池的代幣餘額上限會被超過；輸出庫存不足；報價器或代幣不受支援；或者路徑服務的資料暫時過時或服務不可用。報價也可能到期、因資金池狀態變化而失效、未透過最終模擬，或在鏈上執行時回滾。請重新整理路徑並核對新報價，不要假定較早的估算仍然有效。

當前路徑執行支援與 CLC App 相容的 EOA/Calibur 錢包。目前不會為 Safe 或其他合約錢包準備路徑兌換。

### 6. 使用正確的行動

- **傳送**將代幣餘額轉移到另一個地址。
- **資金池兌換**透過一個 `SwapPool` 將一種受支援資產換成另一種。它可以是直接兌換，也可以是路徑兌換中的一跳。鏈上兌換結算不能證明發行方已經履約。
- **路徑兌換**在一筆有明確限制的同鏈錢包交易中，執行一組有順序的資金池兌換。它不會合並各資金池的治理，也不會讓路徑運營方對發行方履約負責。
- **“兌付”**會打開發送流程，並預先填入代幣所有者地址。它把代金券向發行方出示或退還；完成兌付還需要發行方履行承諾，並留下防止重複使用的核銷記錄。
- **“停用代金券”**會隱藏目錄條目。它不會銷燬餘額、取消代金券或消除發行方尚未履行的義務。
- **資金池流動性提取**允許資金池所有者轉移可用庫存。
- **費用收取**把累積的資金池費用傳送給已配置的接收方。

完整生命週期見[代金券實用示例](/zh-Hant/introduction/example)。

## 當前、取決於部署以及擬議的功能

當前應用提供市場目錄，以及賬戶、錢包、代金券、商品或服務專案、資金池、轉移、直接資金池兌換、應用層路徑兌換和相關記錄的受支援流程。可用性取決於當前部署、資產、資金池配置、庫存、錢包型別、裝置、網路、資格、提供方、司法管轄區和公佈條款。

支付服務、支援方式、獎勵、擔保、出資安排和其他提供方整合均取決於部署。提供這些功能時，必須披露負責方、費用、限制、資格和法律條款。

Protocol v1.1.0 提供直接資金池執行和僅用於報價的 Solidity `SwapRouter`。生產環境中的 CLC App 和 CLC Core 在這些合約之上提供同鏈多跳路徑發現、權威報價、錢包批次準備、模擬、中繼和分組收據。Solidity `SwapRouter` 並未變成執行合約。跨鏈 HTLC 或託管路徑、自動資金池再平衡、批次淨額結算、共享保險、擬議治理資產、網路流動性計劃和受監管支付服務仍屬於擬議或取決於部署的功能，除非具體部署明確說明已啟用。

任何未來貸款或其他信貸產品都需要單獨提供的補充條款和交易條款。普通轉移、資金池存入、資金池交換、兌付出示、履約或核銷不會自動構成貸款、預付款或償還。
