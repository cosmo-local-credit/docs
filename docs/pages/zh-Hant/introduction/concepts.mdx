# 概念與詞彙

Cosmo-Local Credit 把提供商品或服務的人、需要這些商品或服務的人，以及支援代金券交換的獨立治理承諾資金池連接起來。本頁先介紹參與者會看到的詞語，再說明其背後的技術層面。

如果 App 介面使用了較短或可能有歧義的名稱，下文會用引號標出準確的介面標籤。

## 日常用語

| 術語 | 通俗解釋 |
| --- | --- |
| **代金券（Voucher）** | 一項可轉讓的承諾，很像禮品卡。發行方按照公佈的條款，承諾提供指定的商品、服務、權益或其他履約。 |
| **發行方（Issuer）** | 建立代金券，並繼續對其承諾負責的個人或組織。 |
| **商品或服務項目（Offering）** | 描述與代金券相關商品或服務的目錄記錄。它幫助人們發現相關內容，但不能證明有貨或已經履約。 |
| **需求（Want）** | 參與者公開說明自己正在尋找什麼。它本身不會接受商品或服務項目、預留商品、授權交換或產生義務。 |
| **市場（Market）** | App 中用於發現代金券、資金池、商品或服務項目、需求及其他公開資訊的目錄。它本身並不自動成為交換場所、賣方、認可或擔保。 |
| **承諾資金池（Commitment Pool）** | 一項受治理的安排：篩選受支援的代金券、公佈交換規則、持有庫存並支援交換。日常可以簡稱為 **資金池（Pool）**。 |
| **資金池管理者（Pool Steward）** | 公佈和管理資金池規則並對其負責的個人、合作社、公共機構、聯合會、多簽、服務或其他結構。 |
| **持有人（Holder）** | 控制某項代金券餘額的參與者。持有代金券不能證明已經履約、具有現金價值或受到擔保。 |
| **錢包（Wallet）** | 用於授權代幣轉帳和資金池交換的帳戶和憑證。 |

“社區成員”是非正式的社群用語，本身不會產生准入、所有權、治理、還款或其他法律權利。

## 發現並聯繫參與者

市場幫助人們查找代金券、商品或服務項目、需求和資金池。列入目錄只表示 App 可以顯示該記錄；它不能證明資訊準確、庫存可用或交易一定成功。

參與者可以發布需求，並透過可用的聯繫或訊息功能聯繫其他參與者。聯繫請求、訊息、預約討論或對需求的回應，本身不會：

- 接受代金券或商品或服務項目；
- 授權轉帳或資金池交換；
- 證明已交付或對方滿意；
- 履約或核銷代金券；或
- 使 GEF 成為參與者協議的一方。

評價是關於代金券或資金池的公開回饋。它不同於非公開的資格證據、營運方盡職調查、擔保或已經履約的認定。

## 代金券、代幣和商品或服務項目

**代幣（token）** 是鏈上餘額或數位資產。代幣機制可以記錄供應量、轉帳、到期和銷毀，但本身不會承諾商品、服務、現金兌換或贖回。

**代金券** 是發行方按照公佈條款表示為可兌換承諾的代幣或記錄。這些條款應說明承諾內容、責任方、可在何時何地出示、重要限制，以及履約和投訴流程。

**商品或服務項目（Offering）** 是與代金券相關商品或服務的目錄記錄。在一般文字中，“提供”只是指參與者提出的內容；**Offering** 是 App 中特定記錄的名稱。

應把以下四個層面分開：

1. 代幣合約和餘額；
2. 代幣作為代金券的標示和公佈條款；
3. 一項或多項商品或服務項目記錄；以及
4. 發行方在現實世界中的履約。

## 責任角色與技術控制

| 角色或權限 | 責任或權力 |
| --- | --- |
| **發行方** | 公布並履行代金券承諾。僅僅改變合約所有權，不會自動轉移這項責任。 |
| **資金池管理者** | 公佈和管理資金池規則，並對資金池明確宣傳的任何擔保負責。 |
| **資金池所有者** | 當前擁有 `SwapPool` 所有者權限的地址，包括配置、收取費用和提取可用流動性的權限。 |
| **多簽簽署人** | 共同使用分配給多簽錢包的技術權限。更改簽署人或門檻，不會自動轉移發行方責任、管理者問責或法律所有權。 |
| **代理管理員** | 可以升級代理合約的實現。該角色可能不同於資金池所有者。 |
| **依賴項控制者** | 控制 registry、limiter、quoter、oracle、費用政策或協議費用控制器。 |
| **目錄管理員** | 可以糾正、隱藏、停用或恢復目錄記錄，但不會刪除合約、餘額或鏈上歷史。 |
| **費用接收方** | 接收配置的資金池費用或協議費用，不一定是資金池管理者或所有者。 |
| **支持者或流動性提供者** | 按照另行披露的條款提供資產。當前 `SwapPool` 不會自動產生資金池份額、還款權、提款權、獎勵或治理權。 |

## 操作與生命週期

| App 或文件術語 | 含義 |
| --- | --- |
| **建立或發布代金券** | 部署或配置代幣，並公佈其目錄記錄和條款。 |
| **發行或鑄造** | 在配置的所有者或寫入者權限下建立代幣餘額。 |
| **發布商品或服務項目** | 在代金券下新增商品或服務記錄。 |
| **發布需求** | 說明一項需要，以便發現和聯繫；本身不會建立交易。 |
| **傳送（Send）** | 將代幣餘額轉移到另一個地址。 |
| **“兌付（Redeem）”** | 打開傳送流程並預填代幣所有者的地址。這屬於兌付出示，不能證明已經履約。 |
| **履約（Fulfill）** | 發行方提供承諾的商品、服務、權益或其他履約。 |
| **核銷（Discharge）** | 記錄已經履約的單位，使其不能再次出示，例如按照公佈條款接收、銷毀、取消或以其他方式停用。 |
| **“申請停用（Request retirement）”** | 當前所有者請求管理員停用代金券或資金池。請求待處理期間資源仍保持活躍；請求可以獲批、被拒絕或被取消。 |
| **代金券停用** | 獲批後，從活躍目錄中移除代金券。合約、餘額、義務和歷史仍然保留；停用並不等於銷毀或核銷。 |
| **資金池停用** | 獲批後，停止新的資金池交換和存款，同時允許可用的提款。此前的結算記錄仍然保留。 |
| **資金池存款或貢獻** | 將資產轉移到 `SwapPool`。只有在另行披露時，才會產生還款、提款、獎勵或治理權。 |
| **資金池交換** | 透過一個 `SwapPool` 交換受支援資產。這既不是發行方履約，也不會自動形成貸款。 |
| **路線發現** | 透過配置的資金池關係尋找可能的路徑。發現只是估算，不是可執行承諾。 |
| **路線報價** | 根據在一個固定區塊讀取的資金池狀態計算有時限的提案，並在簽署前進行模擬。 |
| **路由交換** | 把有序的資金池交換作為一個同鏈錢包批次提交。在當前流程中，只要一個呼叫失敗，所有呼叫都會還原。 |
| **路由交換收據** | 把追蹤狀態、交易雜湊、路線各跳、已結算數量和每一跳費用歸為一組。 |
| **提取資金池流動性** | 允許資金池所有者把可用庫存轉移到選定地址。 |
| **收取費用** | 把累計的資金池費用傳送給配置的接收方。 |

用 **交換結算（swap settlement）** 表示完成資金池交換的鏈上轉帳和費用核算。用 **兌付出示（redemption presentment）**、**履約（fulfillment）** 和 **核銷（discharge）** 表示彼此獨立的現實世界代金券生命週期。

## 產品和協議層面

| 術語 | 含義 |
| --- | --- |
| **Cosmo-Local Credit（CLC）** | 產品體系，包括 CLC App、相關文件以及更廣泛的承諾匯聚工作。 |
| **CLC App** | 位於 [cosmolocal.credit](https://cosmolocal.credit) 的漸進式網頁應用。GEF 營運該介面及其支援服務。 |
| **CLC Core** | 為目錄、索引後的鏈上狀態、路線發現、權威報價、relay 協調和路由交換收據提供支援的服務。它既不是智慧合約，也不是資金池管理者。 |
| **承諾匯聚協議（Commitment Pooling Protocol，CPP）** | 關於篩選、估值、限制、交換和責任治理的可重複使用模型。 |
| **Protocol v1.1.0** | [權威軟體參考](https://software.cosmolocal.credit/contracts/)中記錄的公開智慧合約版本（英文）。 |
| **`SwapPool`** | 當前持有代幣庫存並執行直接交換的協議合約。它是承諾資金池的一個技術組成部分。 |
| **Solidity `SwapRouter`** | Protocol v1.1.0 中為擬議的多資金池路徑提供報價的合約。它不託管資產，也不執行路線。 |
| **應用層路由流程** | App 和支援服務透過資金池尋找可能的路徑、為交換報價、請求參與者授權，並報告結果。 |
| **擬議的 CLC 治理代幣** | 白皮書中的未來治理設計，不是當前 App 或 Protocol v1.1.0 的資產。 |
| **擬議的 CLC 網路資金池** | 未來的網路級清算和協調設計，不等同於當前 `SwapPool`。 |

## 價值、信用、限額和費用

應區分以下價值術語：

- **商品或服務項目價格：** 列出商品或服務所要求的金額；
- **代金券標示價值：** 發行方在公佈條款中表示的價值；
- **資金池匯率或報價：** 資金池配置的 quoter 生成的交易參數；
- **oracle 參考：** 配置的估值模組使用的外部資料；以及
- **兌換條款：** 發行方承諾什麼，以及在什麼條件下履約。

App 中的 **信用（Credit，介面標籤為“可存入”）** 是指可達的承諾和交換容量，並不自動表示個人借款、貸款、發行方能力評估或擔保。

**“信用額度（Credit limit）”** 標籤是指資金池配置的代幣餘額上限，也就是存款後資金池最多可以持有的該代幣數量。白皮書中擬議的滾動限額、帳戶限額和全網路限額是不同機制。

Protocol v1.1.0 可以對每次資金池交換收取 **資金池費用** 和一項額外的 **協議費用**。路由交換會逐跳列出這兩種費用。當前 App 不收取單獨的路由服務費。擬議白皮書模型另行描述未來的網路抽成和可能的服務費用。

## 路線與流動性

**路線** 是透過一個或多個獨立治理資金池的有序路徑。**路線深度** 是該路徑中的資金池交換次數。

並非每張代金券、每個資金池或每種錢包都符合路由資格。出現在資金池中，不會使代金券自動透過所有路線可用。[軟體路由參考](https://software.cosmolocal.credit/contracts/routing)以英文維護當前資格規則和配置。

**可用流動性** 是資金池按照當前規則、限額和費用能夠提供的庫存。資金池之間存在連接，不能證明您想要的數量可用。請審核最終報價；資金池條件變化時，報價可能到期或失效。

當前路線執行由錢包發起並發生在同一條鏈上。它不會合併治理、自動重新平衡資金池庫存、在多方之間清算義務或證明履約。跨鏈 HTLC 或託管路由、自動再平衡和批次淨額結算仍屬於擬議功能或取決於具體部署。

## 保護與證據

篩選、納入 registry、限額、儲備、App 可見性、評價或區塊鏈交易，本身都不能證明認可、發行方能力、履約、擔保或保險。

任何保護安排都應說明義務方、承保事件、資金來源、上限、除外事項、期限、證據和索賠流程。鏈上記錄可以顯示地址、資產、金額、時間戳和合約事件。發行方表現、滿意程度、治理討論和社會影響需要單獨的證據。

## 狀態用語

- **當前：** 已在這些文件所述的 CLC App 或 Protocol v1.1.0 中驗證。
- **取決於部署：** 僅在特定部署、資金池、提供方、管轄區或公佈政策啟用時可用。
- **歷史：** 來自早期 Sarafu Network 服務的證據或功能。
- **擬議：** 未被表述為已經部署的設計或路線圖機制。
