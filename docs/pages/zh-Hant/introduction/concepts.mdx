# 概念和術語

Cosmo-Local Credit 將應用、開放協議、獨立治理的資金池，以及代金券所代表的現實世界承諾連線起來。這些層級相互配合，但它們並不是同一件事。

本頁定義整套文件所使用的術語。當應用介面使用較短或可能有歧義的名稱時，其精確標籤會放在引號中。

## 產品層和協議層

| 術語 | 含義 |
| --- | --- |
| **Cosmo-Local Credit (CLC)** | 產品體系：CLC App、其文件以及更廣泛的承諾匯聚工作。 |
| **CLC App** | 位於 [cosmolocal.credit](https://cosmolocal.credit) 的漸進式網頁應用。GEF 運營此介面及其配套服務。 |
| **承諾匯聚協議 (CPP)** | 一套可重複使用的篩選、估值、限制、交換和負責任治理模型。 |
| **Protocol v1.1.0** | [協議參考](/zh-Hant/protocol/overview) 中記錄的、經驗證的公開智慧合約版本。 |
| **承諾資金池 ** | 一項受治理的安排，用於篩選資產、公佈規則並實現交換。** 資金池**是通常使用的簡稱。 |
| **`SwapPool`** | 當前的協議合約，用於持有代幣庫存並執行直接交換。它是承諾資金池的一個技術組成部分。 |
| **擬議的 CLC 治理代幣** | 白皮書中的未來治理設計。它不是當前的應用資產或 Protocol v1.1.0 資產。 |
| **擬議的 CLC 網路資金池** | 未來的網路級清算和協調設計。它與當前的 `SwapPool` 不同。 |

## 代幣、代金券與商品或服務專案

**代幣** 是鏈上餘額或數字資產。代幣機制可以記錄供應量、轉移、過期和銷燬，但它本身並不承諾商品、服務、現金轉換或兌付。

**代金券** 是代幣或記錄，發行方將它表述為可按公佈條款兌付的承諾。這些條款應當明確所承諾的內容、負責方、可以出示的地點和時間、重要限制，以及履約和投訴流程。

**商品或服務專案 (Offering)** 是與代金券關聯的商品或服務目錄記錄。釋出專案不會鑄造代幣、證明可用性或表明已經履約。

以下是四個不同層級：

1. 代幣合約和餘額；
2. 代金券命名和公佈條款；
3. 一條或多條商品或服務專案記錄；以及
4. 發行方在現實世界中的履約。

## 負責任角色與技術控制

| 角色或許可權 | 責任或權力 |
| --- | --- |
| **發行方** | 釋出並履行代金券承諾。僅僅因為合約所有權發生變化，此責任不會自動轉移。 |
| **持有人** | 控制代金券餘額。這種控制不證明已經履約、具有現金價值或存在保證。 |
| **服務提供者** | 面向公眾的角色。服務提供者釋出代金券承諾時，就成為發行方。 |
| **資金池管理者** | 負責公佈和管理資金池規則的個人、合作社、公共機構、聯邦、多籤機制、服務或其他負責任結構。 |
| **資金池所有者** | 當前擁有 `SwapPool` 所有者許可權的地址，包括配置、收取費用和提取可用流動性。 |
| **代理管理員** | 可升級代理合約實現的許可權。它可能與資金池所有者不同。 |
| **依賴項控制者** | 控制登錄檔、限制器、報價器、預言機、費用政策或協議費用控制器的所有者或寫入方。 |
| **目錄稽核員** | 可以糾正、隱藏或恢復目錄記錄，而不改變鏈上餘額的應用運營方。 |
| **費用接收方** | 接收資金池費用或協議費用的已配置地址。它不一定是資金池管理者或所有者。 |
| **支持者或流動性提供者** | 按單獨披露條款注入資產的參與者。當前的 `SwapPool` 不會建立資金池份額，也不會自動賦予償還、提取、獎勵或治理權利。 |

“社群成員”是非正式的社會語言。它本身不會產生准入、所有權、治理、償還或其他法律權利。

## 操作與生命週期

| 應用或文件術語 | 含義 |
| --- | --- |
| **建立或釋出代金券** | 部署或配置代幣，併發布其目錄記錄和條款。 |
| **發行或鑄造** | 在已配置的所有者或寫入方許可權下建立代幣餘額。 |
| **釋出商品或服務專案** | 在代金券下新增商品或服務記錄。 |
| **傳送** | 將代幣餘額轉移到另一個地址。 |
| **“兌付”** | 在當前應用中，打開發送流程並預先填入代幣所有者的地址。這會向發行方出示或退還代幣；它不證明已履約。 |
| **履約** | 發行方提供承諾的商品、服務、福利或其他給付。 |
| **核銷** | 記錄已履約的單位，使其不能再次出示；例如，按公佈條款接收、銷燬、取消或以其他方式停用。 |
| **“停用代金券”** | 在應用目錄中隱藏代金券。餘額和歷史記錄仍會保留，管理員可以恢復上架。這不是銷燬或取消。 |
| **資金池存入或出資** | 將資產轉入 `SwapPool`。僅當單獨披露時，才存在償還、提取、獎勵或治理權利。 |
| **資金池交換** | 透過一個 `SwapPool` 將一種受支援資產換成另一種。這不是發行方履約，也不會自動構成貸款。 |
| **資金池流動性提取** | 資金池所有者將可用庫存轉移到選定地址。 |
| **費用收取** | 已配置的接收方收取累積的資金池費用。 |

**交換結算 ** 是完成資金池交換所需的鏈上轉移和費用記賬。** 兌付出示 **、** 履約 **和** 核銷**則屬於單獨的現實世界代金券生命週期。

## 市場、價值、限制與費用

應用中的 **市場** 是用於發現代金券、資金池、商品或服務專案和公開資訊的目錄。上架不會自動構成交換場所、賣方關係、認可、估值或保證。

請區分以下價值術語：

- **商品或服務專案價格：** 上架商品或服務所要求的金額；
- **代金券標明價值：** 發行方在公佈條款中表述的價值；
- **資金池匯率或報價：** 由資金池已配置報價器產生的交易引數；
- **預言機參考：** 已配置估值模組所使用的外部資料；以及
- **兌付條款：** 發行方承諾在何種條件下提供什麼。

應用標籤 **“信用額度”** 指資金池已配置的代幣餘額上限，即存入後資金池可持有的該代幣最大數量。它不是個人信用額度、發行方能力檢查或兌付保證。白皮書中擬議的滾動限制、賬戶限制和網路範圍限制是不同機制。

當前的 Protocol v1.1.0 可收取 **資金池費用 ** 以及額外的 ** 協議費用 **。白皮書中的擬議模型另行描述從資金池費用中提取的未來 ** 網路分成**，以及可能的路由費用或服務費用。說明當前收費或計算未來收入時，不得混合這些模型。

## 保護與證據

篩選、納入登錄檔、限制、儲備、應用可見性或區塊鏈交易，都不會自動構成認可、發行方能力、履約、保證或保險。

任何保護措施都應明確義務方、承保事件、資金、上限、除外責任、期限、證據和申請流程。鏈上記錄可以顯示地址、資產、金額、時間戳和合約事件。發行方履約、滿意度、治理討論和社會影響需要單獨的披露、報告、證明或其他證據。
