# CLC App 隱私聲明

本隱私聲明說明，當您造訪或使用 `cosmolocal.credit` 上的 Cosmo-Local Credit App 及 GEF 營運的相關服務（合稱**應用**）時，Grassroots Economics Foundation（以下簡稱 **GEF** 或 **本基金會**；本聲明中的 **我們** 和 **我們的** 均指 GEF）如何處理個人資料。

> **發布前請閱讀。** 您的私密個人資料並不是公開資料。但是，您輸入或複製到代金券、資金池、商品或服務專案、需求、目錄或帖文中的資訊，可能會隨該資源一起發布。資源的描述、條款、圖片、標籤、錢包地址和精確地圖座標可能無需登入即可檢視。代金券、資金池或需求中的聯絡方式僅透過登入後的資源資訊或聯絡功能顯示，但接收者仍可複製或分享這些資訊。

本聲明是對[服務條款](/zh-Hant/governance/terms)和[資料保護政策](/zh-Hant/governance/data-protection)的補充。

## 1. 誰負責您的資料？

Grassroots Economics Foundation 是該應用的營運方，也是本聲明所述應用資料的資料控制者；但另一方獨立決定如何使用資料的情況除外。

GEF 聯絡方式：

- 電子郵件：[privacy@grassecon.org](mailto:privacy@grassecon.org)
- 郵政地址：P.O. Box 1659-80108, Kilifi, Kenya

發行方、資金池管理者、支付服務提供商、錢包服務提供商、區塊鏈參與者和外部服務營運方，可能對其接收或發布的資訊構成獨立的資料控制者。他們各自的聲明和條款也可能適用。

## 2. 本聲明適用於誰和哪些資訊？

本聲明適用於訪客、帳戶持有人、使用應用功能的人，以及其資訊由獲授權使用者透過應用提交的人。它涵蓋 GEF 營運的應用介面、API、目錄、儲存、交易轉發、通知、內容稽核、支援和相關營運服務。

對於獨立發行方、資金池管理者、第三方服務提供商、公共區塊鏈、外部網站或其他使用者在 GEF 職責範圍之外處理資訊的方式，本聲明不具有控制力。該應用僅供符合《服務條款》資格要求的成年人使用。

## 3. 我們收集的資料

### 帳戶和個人資料資料

根據您使用的功能，我們可能收集：

- 您的使用者名稱和公共區塊鏈錢包地址；
- 您的姓名、電子郵件地址、電話號碼、國家和首選貨幣；
- 您的個人簡介、網站、頭像，以及已儲存的位置名稱和座標；
- 帳戶角色、狀態、資源限制，以及帳戶建立或更新時間；以及
- 您的設定、語言、通知偏好和其他選擇。

您的使用者名稱不同於私密個人資料中的姓名。使用者名稱用作接收者識別碼；已登入使用者輸入完整且準確的使用者名稱時，系統可能向其返回該使用者名稱和您的錢包地址。您的個人資料可用於預填表格，但只有在您選擇發布資源後，預填欄位才會隨資源發布。

獲授權的管理員可以按姓名、使用者名稱、電子郵件、電話號碼或錢包地址搜尋帳戶目錄，並可在營運、支援、稽核和保護應用所需的範圍內檢視帳戶身份和聯絡欄位、角色、狀態、資源限制及關聯資源。該目錄不公開。

### 身份驗證、錢包和交易資料

我們可能處理錢包地址、已簽名訊息、交易授權、簽名、通行金鑰憑證識別碼和公鑰座標、憑證狀態、會話識別碼和角色、交易請求、交易轉發記錄、替代交易資料和交易狀態。更換登入卡時，我們可以保留舊錢包地址和新錢包地址、所請求變更的證明、關聯的通行金鑰狀態，以及恢復或驗證該變更所需的營運記錄。

應用把瀏覽器登入卡的私密材料存放在該瀏覽器的本地儲存中，以便瀏覽器完成簽名。GEF 服務接收簽名和已簽名交易，而不接收原始私鑰。通行金鑰提供方保護通行金鑰的私鑰；應用及其服務使用註冊或驗證所需的憑證識別碼、公鑰材料、挑戰值和已簽名斷言。如果您使用紙錢包、登入卡、通行金鑰或其他憑證，您有責任保護裝置和私密材料。

當代金券或資金池由相容的多重簽名錢包控制時，我們可能處理多籤地址、簽名人錢包地址、批准門檻、擬議交易、確認記錄、執行狀態，以及顯示和操作多籤控制所需的權限。所有者地址、簽名人集合和批准門檻可以透過公開的所有權查詢返回，也可能在公共區塊鏈上顯示。

### 裝置、安全和使用資料

我們可能收集技術和營運資訊，例如 IP 地址、瀏覽器和裝置資訊、時間戳、請求的頁面或端點、會話和安全事件、驗證錯誤、速率限制資訊、通知訂閱和送達確認、服務活動及診斷記錄。

### 內容和支援資料

我們會處理您在代金券、資金池、商品或服務專案、需求、目錄、帖文、代金券與資金池評價、圖片、附件、條款、描述、標籤、位置、聯絡欄位、交易後的私密訊息或訂單、投訴、支援訊息及其他通訊中提交的資訊。

如果您使用 App 訊息功能，我們會處理：

- 對話請求及其狀態；
- 參與者的錢包地址、使用者名稱和頭像；
- 訊息文字、圖片和時間戳；
- 每位使用者的已讀標記、封鎖記錄和請求配額記錄；以及
- 服務台對話和濫用舉報。

私訊僅供對話雙方查看。GEF 管理員可以閱讀服務台訊息。只有當參與者將某則私訊附在濫用舉報中時，管理員才能閱讀該私訊。

除非您具有合法理由並已取得任何必要許可，否則請勿發布他人的個人資料、圖片、聯絡方式或精確位置。

## 4. 哪些資訊會公開？

應用包含五種重要的資訊可見性級別。

| 可見性 | 這意味著什麼 |
| --- | --- |
| 私密個人資料和帳戶資料 | 個人資料姓名、電子郵件、電話號碼、已儲存位置、偏好、身份驗證記錄和類似帳戶資訊用於營運應用，不會自動出現在公開資源回應中。獲授權的 GEF 人員和服務提供商可在工作需要時存取這些資訊。獲授權管理員也可搜尋和管理非公開帳戶目錄。 |
| 精確的接收者查詢 | 已登入使用者輸入您的完整且準確的使用者名稱或完整電話號碼時，可能會獲得您的公開使用者名稱和錢包地址。輸入部分使用者名稱不會返回使用者。用於查詢的電話號碼，以及您的私密個人資料姓名、電子郵件、電話號碼和已儲存位置，均不會出現在接收者查詢結果中。 |
| 公開目錄和資源資料 | 已發布的描述、條款、圖片、標籤、錢包和合約地址、位置、精確座標、商品或服務專案、需求、帖文、評價、資金池規則和技術設定，可能無需登入即可檢視。公開欄位可能被索引、複製、分享，或與某個錢包或其他資源相關聯。 |
| 登入後可見的資源聯絡方式 | 主動新增到代金券、資金池或需求中的電子郵件、電話、網站或聯絡說明，會從未登入使用者獲得的目錄和詳情回應中移除。已登入使用者可請求包含完整聯絡方式的代金券或資金池記錄，或獲取某項活躍需求所選擇的聯絡方式。接收者仍可複製、使用或分享這些資訊。已下架資源僅允許所有者或管理員在更有限的範圍內存取。 |
| 公共區塊鏈記錄 | 錢包地址、合約、餘額、持有資產、轉賬、金額、交易對手、時間戳、簽名和合約操作，可能透過公共網路和獨立區塊瀏覽器永久可見。GEF 無法刪除或改寫公共區塊鏈。 |

App 訊息並不公開。對話雙方可以看到彼此的錢包地址、使用者名稱、頭像、訊息、圖片、對話狀態和時間戳。已讀標記、封鎖清單和請求配額屬於營運記錄，不會公開。

從應用目錄中移除資源，不會刪除其他人、搜尋服務、檔案服務、獨立索引器或公共區塊鏈已經儲存的副本。

## 5. 公共資源領域

隨著應用發展，資源可用欄位可能發生變化。發布前顯示的表單，是對您選擇公開哪些資訊最直接的說明。

| 資源 | 可能公開的資訊 |
| --- | --- |
| 代金券 | 公開：合約和鏈上識別碼；代金券名稱、符號、描述、標明的單位和價值；發行方或所有者的錢包地址；條款；位置名稱和精確座標；圖片；標籤；視覺標記；以及活躍目錄狀態。登入後可見：主動填寫的電子郵件、電話和網站。已下架記錄只能由獲授權的所有者或管理員透過完整資訊端點存取，但鏈上歷史仍可能公開。 |
| 資金池 | 公開：合約和鏈上識別碼；資金池名稱和描述；所有者、費用接收方、依賴項或其他技術控制方的錢包地址；支援的代金券；庫存或可用性資訊；估值方法；費用、限額、規則及其他配置；位置名稱和精確座標；圖片；標籤；時間戳；以及相容多籤的所有者地址、簽名人地址和批准門檻。登入後可見：主動填寫的電子郵件、電話和網站。已下架資金池記錄與已下架代金券一樣，只能透過權限更嚴格的完整資訊端點存取。 |
| 商品或服務專案 | 關聯代金券的詳細資訊；賣方或來源錢包地址；所提供的商品或服務；描述、數量、單位、頻率、價格和可用性；位置名稱及精確座標或繼承的座標；圖片；標籤；以及時間戳。 |
| 需求 | 公開：所需商品或服務；描述；標籤；圖片；狀態和日期；位置名稱和精確座標。登入後可見：僅限為該活躍需求主動選擇的聯絡說明、電子郵件或電話。公開的需求回應會省略這些聯絡欄位，也不會識別建立者的私密個人資料；但關聯的代金券或資金池仍可能形成間接關聯。 |
| 目錄 | 目錄名稱、描述、圖片、標籤、所有者錢包地址、列出的成員或資源、數量、位置名稱和精確座標，以及時間戳。 |
| 已發布帖文 | 標題、摘要、正文、主辦方名稱、參與者資訊、日期、圖片、圖片說明、附件、嵌入連結、標籤、關聯的代金券或資金池，以及精確座標。作者的錢包地址和工作流狀態會保留用於管理和問責，但不會出現在公開帖文回應中。關聯資源或內容本身仍可能暴露這種關聯。 |
| 代金券或資金池評價 | 評分、評論，以及代金券或資金池所有者的任何公開回復。公開的評價回應不包含評價者的錢包地址，也不包含兌付或兌換證據。服務會保留評價者地址及必要證據，用於驗證資格、防止重複評價、支援回覆和舉報、稽核內容並執行評價期限。評價被舉報時，管理員可以收到舉報理由和被舉報的評價內容。 |

聯絡方式和精確座標可能帶來人身安全風險。請儘可能使用適當的公開聯絡方式，並選擇安全的公共會面地點，而不是私人住所。

## 6. 公共區塊鏈資訊

應用會與公共區塊鏈網路互動。交易可能披露相關錢包、Token 或代金券合約、金額、時間、狀態、簽名及相關合約事件。資金池合約還可能披露支援的資產、餘額、存款、支出、兌換、流動性提取、費用、限額、估值、所有者、管理員、依賴關係及其他配置。相容的多籤錢包可能披露簽名人集合、批准門檻、提案、確認記錄及已執行操作。

區塊鏈資訊可能由網路驗證者、節點營運方、索引器、錢包軟體、分析服務和任何讀取該網路的人處理。交易可能不可逆。關閉應用帳戶、更改個人資料、更換登入卡、移除或下架目錄資源、銷燬代金券單位，或要求 GEF 刪除鏈下資料，都不會刪除早先的區塊鏈記錄或由獨立機構索引的副本。

## 7. 我們使用資料的原因和法律依據

我們僅在具有適用法律依據時使用個人資料。具體依據可能因個人、功能和司法管轄區而異。

| 目的 | 典型的法律依據 |
| --- | --- |
| 建立和營運帳戶、驗證使用者身份、提供所請求功能、提交已授權交易，以及提供支援 | 履行我們與您的協議，以及應您的請求採取措施 |
| 發布您主動提交用於公開展示的資源或聯絡方式 | 履行我們的協議、您主動採取的公開行為，以及在法律要求時取得的同意 |
| 保護帳戶和服務、防止欺詐或濫用、執行限額、調查事件並維護可靠記錄 | 營運安全且可問責服務的合法利益、履行我們的協議，以及法律義務 |
| 稽核內容、處理投訴、執行《服務條款》並保護使用者或公眾 | 合法利益、履行我們的協議，以及法律義務 |
| 儲存財務、交易、治理、合規、稅務和爭議記錄 | 法律義務，以及問責和法律主張方面的合法利益 |
| 傳送可選通訊或通知 | 法律要求時取得同意；對於服務訊息，則依據我們的協議和合法利益 |
| 改進服務並開展研究或編制彙總統計資料 | 合法利益、法律要求時取得的同意，以及具有適當保障的其他合法研究依據 |

我們不會把您決定發布某一欄位，視為您同意發布與其無關的私密個人資料欄位。

## 8. 要求的和可選的資料

應用會在相關表單中標明必填欄位。目前，引導式帳戶建立要求提供錢包地址和身份驗證證明、姓名、個人資料圖片、國家和已儲存位置、首選貨幣，以及至少一個電子郵件地址或電話號碼。使用者名稱為可選。其他登入或帳戶恢復流程可能先建立臨時系統值，直到使用者完成或更正個人資料。特定功能可能需要額外的交易、聯絡、位置、資格或資源資訊。

除非表單另有說明，其他個人資料和資源欄位均為可選。如果您不提供必填資訊，我們可能無法建立帳戶、驗證您的身份、提交交易、發布資源、提供支援、滿足法律要求或提供所請求的功能。

“可選”並不表示發布後仍然私密。如果您把可選的聯絡方式、圖片、描述或地圖示記新增到資源併發布該資源，這些資訊就會公開。

## 9. 我們如何獲取資料

我們透過以下來源接收資料：

- 直接來自您，或獲授權代表您行事的人；
- 來自您的瀏覽器、裝置、錢包、通行金鑰或通知服務；
- 來自公共區塊鏈網路、合約、節點和索引器；
- 來自發行方、資金池管理者、交易對手、支付或服務提供商，以及參與某項功能或交易的其他使用者；
- 來自可依法收集的公開來源；以及
- 來自安全、內容稽核、支援和合規流程。

## 10. 誰會接收資料？

我們只披露為所述目的、適用法律或您要求的公開行為所合理需要的資訊。接收者可能包括：

- 當您發布資源或使用公共區塊鏈時，應用的訪客和使用者；
- 當已登入的應用使用者請求您主動附加到活躍代金券、資金池或需求上的聯絡方式時，這些已登入使用者；
- 私訊對話中的另一位參與者；
- 處理服務台對話或濫用舉報的 GEF 授權管理員，但其存取須受第 3 節所述限制；
- 完成交易、兌付、投訴或所請求服務所需的發行方、資金池管理者、交易對手和其他參與者；
- 提供託管、資料庫、儲存、內容分發、安全、身份驗證、支援、電子郵件、通知、地圖、地理編碼、區塊鏈存取、索引、交易轉發和監控的基礎設施服務商；
- 您選擇使用的獨立錢包、區塊鏈、支付、穩定幣、現金出入金或其他第三方服務提供商；
- 在承擔適當義務並具備適當保障的情況下，專業顧問、審計師、保險機構、研究人員、資助方和合作伙伴；以及
- 法律要求披露或為保護權利、安全和服務完整性而合理需要披露時的監管機構、法院、執法機關或其他人員。

生產環境的網頁應用透過 Cloudflare Pages 提供。當前瀏覽器配置使用 MapTiler 提供地圖樣式和基於 IP 的位置建議，使用 ArcGIS World Geocoding 進行地點搜尋和反向地理編碼，並使用已配置的 Gnosis Chain RPC 端點讀取鏈上資料。這些服務會接收回應請求所需的資料，其中可能包括 IP 地址、瀏覽器資訊、地圖區域、搜尋文字、座標，或錢包與合約查詢。

其他整合取決於具體功能。啟用並使用相關功能時：通知服務會處理推送訂閱端點、裝置狀態、關聯的錢包地址、送達和點選確認及收件箱狀態；交易轉發服務會處理已簽名請求和交易狀態；Safe 交易服務會處理多籤地址、提案、簽名、確認和執行狀態；支付或現金出入金服務商會處理該功能所需的電話號碼、錢包地址、資產、金額、服務商識別碼、匯率和交易狀態。圖片儲存、應用 API、資料庫、區塊鏈索引器和基礎設施監控會處理其功能所需的內容和營運記錄。第三方服務也可能依據自己的隱私聲明直接收集資料。

## 11. 國際處理

應用、公共區塊鏈網路、服務提供商、合作伙伴和使用者可能在多個國家營運。因此，個人資料可能在肯亞或資料收集國以外被存取或處理。

當資料傳輸需要保障措施時，GEF 會採用適合該傳輸並符合適用法律的措施，其中可能包括合同、存取限制、傳輸中加密、對接收者和目的地的評估、適當情況下的同意，或其他法律認可的傳輸依據。公開資訊和區塊鏈交易可在全球存取，無法限制在單一國家內。

## 12. 我們儲存資料的時間

GEF 僅在實現資料收集目的所合理需要的期間內保留個人資料，包括：

- 帳戶、資源、交易、對話、封鎖、濫用舉報、投訴或支援事項仍處於活躍狀態期間；
- 為滿足安全、防欺詐、對賬、審計、治理、研究完整性和服務連續性需要；
- 為滿足稅務、會計、監管、合同、爭議、時效期限或其他法律要求；以及
- 在按計劃刪除或替換前，於受保護備份和日誌中保留的有限期間。

因此，不同記錄具有不同的保留期限。當資料不再需要時，我們會刪除、彙總、去標識化或限制使用，除非法律要求或允許繼續儲存。公共區塊鏈記錄和由他人控制的副本不屬於 GEF 可以刪除的範圍。

## 13. 安全

GEF 採用與風險相稱的技術和組織措施來保護個人資料。這些措施可能包括存取控制、身份驗證、職責分離、安全傳輸、系統更新、監控、備份、事件處理程序、員工職責和服務提供商保障。

任何線上系統、公共區塊鏈、憑證或傳輸都無法保證絕對安全。您必須保護自己的裝置、會話、通行金鑰、私鑰、紙錢包和恢復資訊，並在公開資訊前仔細檢查。

## 14. 您的權利和選擇

根據適用法律,您可能有以下權利:

- 獲知您的個人資料如何被使用；
- 請求存取 GEF 持有的與您有關的個人資料；
- 請求更正不準確或具有誤導性的資料；
- 對特定處理提出異議或請求限制處理；
- 在處理以同意為依據時撤回同意；
- 請求刪除 GEF 無須或無權繼續保留的資料；
- 在該權利適用時，以可攜帶的形式接收資料；以及
- 向 Office of the Data Protection Commissioner（**ODPC**）或其他主管機關投訴。

請將請求傳送至 [privacy@grassecon.org](mailto:privacy@grassecon.org)。我們可能需要在採取行動前驗證您的身份和權限。您的權利可能受到他人權利、公共記錄、法律義務、技術必要性或公共區塊鏈永久性的限制。

您也可以選擇不填寫可選的個人資料欄位、在發布前刪除可選資訊、使用適當的公開聯絡方式、選擇安全的公共地圖點、管理通知權限，以及避免使用要求提供您不願提供之資料的功能。

關於肯亞資料主體權利的資訊可從 [ODPC](https://www.odpc.go.ke/rights-of-a-data-subject/) 獲取。
