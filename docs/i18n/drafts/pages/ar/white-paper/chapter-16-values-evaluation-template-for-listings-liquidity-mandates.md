## **16. نموذج التقييم المقترح**

يمكن لبرنامج السجل أو المجموعة أو برنامج السيولة المستقبلي تكييف هذا الشكل. إنها ليست معايير أو ضمانات عالمية حالية للتسجيل.

1. **الحقائق الملاحظة:** هوية المصدر وتاريخها، شروط البطاقات، العروض، دليل القدرة، تشكيل المجموعة، المراقبين، المخزون، الحدود، الاحتياطيات، الضامنين، الحوادث، والتزامات غير الحل.
2. **الغرض والأطراف المتضررة:** الفائدة المقصودة والخطر والصراعات والآثار البيئية والاجتماعية، ومن يحمل الخسارة أو المسؤولية.
3. **التقييم:** سعر العرض، القيمة المعلنة على البطاقة، طريقة سعر الصرف في المجموعة، مرجع الأوراقل، الوحدات، العلامات الزمنية، والأسباب لأي اختلاف.
4. **الحدود:** التأهل، الاستخدامات المحظورة، التركيز، أقصى مستويات الميزان، التوقفات، القيود الجغرافية أو القانونية، والتحفيزات للمراجعة.
5. **الحماية:** يتم تحديد الطرف الملتزم، والحدث المغطى، والتمويل، والحد الأقصى، والإقصاءات، والمدة، والأدلة، وعملية المطالبة، والعلاج.
6. **القرار:** الموافقة على المراجعة أو مراجعتها أو رفضها أو توقفها أو تصاعدها من أجل مراجعة بشرية؛ تحديد صانع القرار والأسباب والشروط وتاريخ المراجعة وعملية الاستئناف أو التصحيح.

لا ينبغي أن يصف الناتج الاحتياطي أو الحدود أو الاحتياطيات أو التحقق على أنه تأكيد أو قدرة المصدر أو التأمين أو الوفاء المضمون ما لم يثبت الطرف المسؤول صراحة هذه الحماية.
